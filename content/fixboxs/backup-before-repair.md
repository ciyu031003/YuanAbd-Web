# 换硬盘 / 重装系统前，怎么把数据备份全

> ℹ️ 本教程全部是只读性质的备份操作，不会改动、删除你的任何文件。唯一要提醒的是：**备份没做完之前，不要开始重装、分区或换盘**——"我先格式化了再想想备份"是数据事故的第一大来源。

## 一句话结论

备份的本质是**复制 + 验证**：把「文档、桌面、图片、下载、浏览器书签、微信聊天记录、软件配置」这七类东西拷到外置盘，再**随机打开 5 个文件确认能读**。别指望「我记得都存网盘了」——验证过才算备份。

## 30 秒快速排查

1. 插上移动硬盘，确认剩余空间大于 C 盘已用数据量。**期望结果**：空间够，不会被中途打断。
2. 新建一个以日期命名的文件夹（如 `backup-20261024`），把要备份的目录整个拖进去复制。**期望结果**：复制开始，进度条走完无报错。
3. **随机打开 5 个复制过去的文件**（一个文档、一张图、一段视频、一个 Excel、一个 PDF）。**期望结果**：全部正常打开，备份才算成立。

## 适用 / 不适用

**适用**

- 明天要换硬盘、重装系统、送修机器，今天做备份。
- 硬盘开始报警（咔咔响、SMART 警告），抢数据。
- 定期备份习惯养成，防勒索、防误删。

**不适用**

- 电脑已经开不了机：看[「硬盘咔咔响 / 识别不到硬盘怎么办」](./disk-clicking-failure.html)的抢救部分，或[「文件误删了怎么恢复」](./deleted-file-recovery.html)。
- 手机备份：本教程针对电脑；手机走各自官方的云备份。
- 公司域控环境：可能有统一备份策略，先问 IT，别双份备份把配额挤爆。

## 开始前确认

- [ ] 移动硬盘剩余空间 ≥ 需要备份的数据总量（先算一下「文档/桌面/下载/图片」四个目录的属性大小）。
- [ ] 知道自己的账号密码（备份完要重装，得能重新登录微软/Apple 账户）。
- [ ] 微信/QQ 的聊天记录决定要保留——它们**不在系统备份里**，要单独导。
- [ ] 笔记本插着电源，防止备份到一半没电。
- [ ] 关掉正在跑的杀毒全盘扫描之类的大 IO 任务，备份更快也更稳。

## 分步骤

### 步骤 1：清点「七类必备」清单

1. **文档/桌面/下载/图片/视频** 五个用户目录。
2. **浏览器书签与密码**：Chrome/Edge 登录账号开启同步即可；不放心就再导出一份 HTML 书签文件。
3. **聊天记录**：微信「设置 → 通用 → 聊天记录备份与迁移 → 备份到电脑」；QQ 用自带的「消息管理器 → 导出」。
4. **软件清单**：拍一张「已安装应用列表」的截图（Windows：设置 → 应用；macOS：应用程序文件夹），重装后照单重装。
5. **工作配置**：代码目录、SSH 密钥（`.ssh`）、输入法词库、hosts 文件等隐藏目录，用「显示隐藏文件」翻一遍。
6. **邮箱本地数据**（Outlook 的 .pst 之类，若有）。
7. **驱动与安装包**：品牌机去官网对应型号页下载好驱动包放进备份盘。
**期望结果**：清单七项都有明确的「已备份 / 本来没有」。**失败了怎么办**：某项找不到位置 → 搜索该软件的帮助文档，不要跳过它赌运气。

### 步骤 2：Windows 用「文件历史记录」或直接复制

1. 直接复制法（最直观）：把步骤 1 清单里的目录全部拖到移动硬盘的日期文件夹里。
2. 进阶：控制面板 → 文件历史记录 → 启用，选移动硬盘为备份盘，点「立即运行」。它做增量且保留历史版本。
3. 要连系统一起备份（连软件带配置，重装后直接还原）：「控制面板 → 备份和还原 → 创建系统映像」。
**期望结果**：复制完成无报错，抽 5 个文件能打开。**失败了怎么办**：某个文件复制报错跳不过去 → 记下文件名，多为损坏文件，单独处理，别让一个坏文件中断整场备份。

### 步骤 3：macOS 用「时间机器」

1. 插上移动硬盘 → 系统设置 → 通用 → 时间机器 → 添加备份硬盘。
2. 点「立即备份」，等第一次全量完成（可能 1-2 小时）。
3. 备份是整盘性的：新 Mac/新硬盘上用「迁移助理」可以直接把账号、应用、设置原样搬回来。
**期望结果**：时间机器显示最近备份时间，随机抽查文件可打开。**失败了怎么办**：备份报「空间不足」→ 换更大硬盘，或先排除视频素材等特大目录单独手动备份。

### 步骤 4：验证 + 异地副本（3-2-1 的最后一步）

1. 随机打开备份盘里 5 个文件，确认内容完整、能打开。
2. 把**最要命的那一小部分**（工作文档、证件扫描件、财务表格）再传一份到网盘或另一块盘——这就是 3-2-1 原则的「异地/介质 2」。
3. 给备份文件夹写一个 `README.txt`，注明备份日期和包含内容，未来的你会感谢现在的你。
**期望结果**：本地 + 异地两份都验证过。**失败了怎么办**：网盘传不上 → 至少确认本地备份完整，并把移动硬盘放在远离电脑的位置。

## 怎么确认修好了

- 备份盘拔下来插到另一台电脑上，能读到所有目录。
- 清单七项逐项打钩，无「以后再补」项。
- 重装/换盘完成后，数据如数归位，聊天记录也能导回。

## 还是不行？

- 备份中硬盘突然掉线、异响 → 立刻停止对该盘的一切写入，看[「硬盘咔咔响 / 识别不到硬盘怎么办」](./disk-clicking-failure.html)；重要数据交专业恢复机构，不要反复通电。
- 备份完了才发现漏了某个软件的数据 → 大多数软件支持重启后再导出，重装前窗口还在。
- 不确定「隐藏目录」还有没有漏 → 重装后缺什么再从旧盘挂载找，换盘时**保留旧盘两周**再处理。

## 预防

- 养成 3-2-1：3 份数据、2 种介质、1 份异地。每月月底花 20 分钟增量备份一次。
- 大文件（视频素材）单独一块盘，不要和系统备份混在一起。
- 网盘当「第二份」而不是「唯一一份」，账号异常时你还有底。
