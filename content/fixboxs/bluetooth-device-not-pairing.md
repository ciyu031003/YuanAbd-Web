# 蓝牙耳机 / 键鼠连不上、一直配对失败怎么修

> ℹ️ 本教程只涉及系统设置、驱动与服务，不会删除你的文件。唯一注意点：删除设备重新配对后，原有的自定义设置（如耳机的降噪档位偏好）可能需要重设一遍。

## 一句话结论

蓝牙配对失败，**八成出在「设备还连着别人 / 系统蓝牙服务假死 / 驱动抽风」**：先把设备从旧设备上断开（手机）并放进充电盒重置，再重启电脑的蓝牙服务，最后才动驱动。顺序对了基本都是小问题。

## 30 秒快速排查

1. 把耳机放回充电盒、**关盖等 10 秒再开盖**，或长按功能键重置到配对模式（看说明书）。**期望结果**：设备进入「未连接」的干净状态，而不是「挂在手机上不肯走」。
2. 关掉**手机**上与该设备的蓝牙连接（耳机通常只能同时服务一台主机）。**期望结果**：电脑这边马上能搜到/连上。
3. 电脑蓝牙关开一次（设置 → 蓝牙和其他设备 → 关，再开）。**期望结果**：蓝牙栈小卡死就此恢复。

## 适用 / 不适用

**适用**

- 以前能连，现在搜不到 / 配对转圈后报失败。
- 换了新耳机、新鼠标，第一次配不上。
- 蓝牙键鼠连上了但频繁卡顿、断连。
- 蓝牙开关整个不见了（更多是驱动/服务问题）。

**不适用**

- 2.4G 接收器（USB 小狗）型无线键鼠连不上——那不是蓝牙，走 USB 排查，参考[「U 盘 / 移动硬盘不识别怎么办」](./usb-drive-not-recognized.html)的接口排查思路。
- 打印机走 Wi-Fi/USB 连接：看[「打印机脱机 / 打印没反应」](./printer-offline.html)。
- 设备说明书明确写着「不支持蓝牙，需接收器」。

## 开始前确认

- [ ] 设备有电（耳机开盖有灯、鼠标底部灯亮）。
- [ ] 设备已从手机/平板断开，或干脆关闭手机蓝牙 2 分钟。
- [ ] 电脑蓝牙开关是开着的，且飞行模式没开。
- [ ] 距离 1 米内重试——蓝牙 5 米理论距离在有墙情况下会腰斩。
- [ ] 周围没有微波炉、USB3.0 集线器正对着用（2.4G 干扰源）。

## 分步骤

### 步骤 1：设备端重置到配对模式

1. 耳机：放回盒中，开盖长按盒上按钮直到指示灯快闪；或按说明书执行「恢复出厂配对」。
2. 键鼠：底部开关关开一次，长按配对键 3 秒以上。
**期望结果**：设备处于快闪的「配对等待」状态。**失败了怎么办**：灯不亮 → 充电 20 分钟再试；快闪但电脑仍搜不到 → 步骤 2。

### 步骤 2：删除旧配对记录，重新配对

1. Windows：设置 → 蓝牙和其他设备 → 找到该设备 →「删除设备」；macOS：系统设置 → 蓝牙 → 悬停该设备 → 断开连接并移除。
2. 让设备重新进入配对模式，点「添加设备 / 连接」重新走一遍。
**期望结果**：配对成功。**失败了怎么办**：还是失败 → 步骤 3。

### 步骤 3：重启蓝牙支持服务（Windows）

1. `Win + R` 输入 `services.msc` 回车。
2. 找到「蓝牙支持服务（Bluetooth Support Service）」→ 右键「重新启动」；顺便确认启动类型为「自动」。
3. 再试一次配对。
**期望结果**：服务重启后配对成功。**失败了怎么办**：进步骤 4 检查驱动。

### 步骤 4：驱动检查与恢复（Windows）

1. 设备管理器 →「蓝牙」分类，看有没有黄色感叹号。
2. 右键蓝牙适配器（名字含 Bluetooth / Intel Wireless / Realtek）→「卸载设备」（勾选删除驱动则更彻底）→ 重启电脑，系统会自动装回通用驱动。
3. 台式机根本没蓝牙分类 → 加一个 USB 蓝牙适配器（几十块，即插即用）是最省事的解法。
**期望结果**：驱动重装后蓝牙分类正常，配对成功。**失败了怎么办**：驱动装回后仍带感叹号 → 去笔记本/主板厂商官网下载对应型号的蓝牙驱动手动装。

### 步骤 5：卡顿 / 断连的专项处理

1. 把 USB 3.0 设备（U 盘、移动硬盘）插到离蓝牙天线远的接口，或换 USB 2.0 口——USB 3.0 的射频噪声是蓝牙断连的惯犯。
2. 路由器 Wi-Fi 信道与蓝牙同在 2.4G：把 Wi-Fi 切到 5GHz 频段试。
3. macOS 卡顿可在终端跑 `sudo pkill bluetoothd` 重启蓝牙守护进程。
**期望结果**：卡顿明显缓解。**失败了怎么办**：仍频繁断连 → 用「设备管理器 → 蓝牙适配器 → 属性 → 电源管理」取消「允许计算机关闭此设备以节约电源」。

## 怎么确认修好了

- 连接一次成功，播放音乐 10 分钟不断连、无卡顿。
- 键鼠闲置 5 分钟后动一下，1 秒内恢复响应。
- 重启电脑后自动重连，无需重新配对。

## 还是不行？

- 换一台手机/电脑测试同一设备：能连 → 锅在电脑（驱动/适配器）；不能连 → 设备本身故障，走保修。
- 设备连接成功但没有声音 → 输出设备选错了，右下角音量图标里手动切到该耳机；Mac 在「系统设置 → 声音」里切。
- 台式机距离远、隔墙多 → 加装蓝牙 5.0 带外置天线的适配器，比反复折腾驱动划算。

## 预防

- 适配器驱动随系统更新保持最新（厂商官网版本通常比 Windows Update 新）。
- 蓝牙设备和微波炉、无线路由保持 1 米以上距离。
- 长期不用的蓝牙设备从已配对列表里删掉，列表越长越容易出「抢连」怪事。
