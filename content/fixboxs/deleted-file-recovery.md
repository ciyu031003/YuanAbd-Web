# 文件误删了怎么恢复（先做这一步，别写磁盘）

> ⛔ 有数据风险：**删除文件后，最重要的一步不是找工具，而是立刻停止向这块磁盘写入任何数据。**
> 在 Windows/macOS 上，删除只是把文件的"位置"标记为可用，内容可能还在原地；一旦有新数据写进去，就可能被覆盖，**再也恢复不了**。

## 一句话结论

文件刚删掉时数据大概率还在，**关键动作是马上停止写入**（能关机就关机，至少别下载、别装软件、别存新文件），然后按"回收站 → 云盘/以前的版本 → 恢复工具"的顺序找回来。

## 30 秒快速排查

1. **立刻停手**：不要往那块盘里存任何东西，不要再下载、不要安装恢复软件到那个盘。**期望结果**：数据保持原样，没被覆盖。
2. 打开**回收站**（桌面图标），用右上角搜索框搜文件名或后缀。**期望结果**：找到就右键"还原"，文件回到原位置。
3. 如果文件在 OneDrive、iCloud 云盘、企业网盘里，打开对应**网盘的回收站/版本历史**找一找。**期望结果**：云端通常保留 30 天，多数情况能直接找回。

## 适用 / 不适用

**适用**

- 刚删除不久（几分钟到几天）、那张盘还在正常使用。
- 清空了回收站、用了 `Shift + Delete` 直删。
- 文件在云盘里被删除、被覆盖、被别人改动过。

**不适用**

- 硬盘有异响、电脑识别不到这块盘：先看[「硬盘咔咔响 / 电脑识别不到硬盘，是不是要坏了」](./disk-clicking-failure.html)，**那不是恢复软件能解决的问题**。
- 是整个分区/磁盘不见了、被格式化过：看[「格式化后数据还能恢复吗 / 分区不见了怎么找回」](./partition-manager.html)。
- U 盘提示"需要格式化"：看[「U 盘 / 移动硬盘不识别、提示格式化怎么办」](./usb-drive-not-recognized.html)。
- 文件是被**勒索病毒加密**的（后缀被改、有勒索说明文件）：看[「文件被加密了 / 弹出勒索要比特币怎么办」](./malware-first-response.html)，不要自行尝试"解密工具"。

## 开始前确认

- [ ] **已经停止对该磁盘的一切写入**（这是所有后续步骤生效的前提）。
- [ ] 系统盘上的文件：能关机就关机，把硬盘拆下来接到另一台电脑上操作最保险。
- [ ] 非系统盘/外接盘上的文件：**拔下来**，等准备好恢复软件和另一块存盘后再接上。
- [ ] 准备一块**容量足够、且健康**的盘（或 U 盘）用来存放恢复出来的文件，恢复目标**绝不能是原盘**。
- [ ] 想清楚：删除时间、原文件夹路径、文件类型（.docx / .jpg / .mp4），这些能让恢复更精准。
- [ ] 如果是公司电脑或含公司数据：**先联系 IT**，不要自行操作，可能影响后续取证与恢复。

## 分步骤

### 步骤 1：先看回收站（最省事、成功率最高）

**目的**：普通删除的文件都先进回收站，这一步能解决大半问题。

**操作**：

1. 双击桌面"**回收站**"（Windows）或"**废纸篓**"（macOS）。
2. 在右上角搜索框输入文件名关键词或后缀（如 `报告`、`.xlsx`）。
3. 找到后右键 → **还原**（Windows）；macOS 右键 → **放回原处**。
4. 如果回收站里东西太多，点表头按"**删除日期**"排序，快速定位。

**预期结果**：文件回到它原来的文件夹，能正常打开。

**失败怎么办**：回收站里没有，或回收站已被清空，继续步骤 2；`Shift + Delete` 删除的**不会进回收站**，直接跳到步骤 3。

### 步骤 2：查云盘与版本历史（很多人忽略的救命路径）

**目的**：云盘通常保留删除记录和旧版本，找回速度最快且无损。

**操作**：

- **OneDrive**：浏览器打开 `onedrive.live.com` → 左侧"**回收站**"，可恢复 30 天内的文件；单个文件的历史版本：右键文件 → **版本历史记录**。
- **企业/学校 OneDrive/SharePoint**：同样有"回收站"和"版本历史记录"，具体保留时长**以单位 IT 的配置为准**。
- **iCloud 云盘**：登录 `icloud.com` → **最近删除**。
- **Office 未保存的文件**：Word/Excel 里点"文件 → 信息 → 管理文档 → 恢复未保存的文档"，或打开"文件 → 打开 → 最近"里带"(当我没保存就关闭时)"的条目。
- **微信/QQ 收到的文件**：在对应聊天记录里重新下载一次，往往比恢复工具更快。

**预期结果**：在云盘回收站或版本历史里找到文件并下载回来。

**失败怎么办**：没有云端副本，继续步骤 3。

### 步骤 3：用"以前的版本"/文件历史记录（Windows）

**目的**：Windows 的卷影副本（还原点/文件历史）可能保留着文件的旧拷贝。

**操作**：

1. 打开文件原来所在的文件夹，在**空白处**右键 → 看是否有"**还原以前的版本**"；有就点开，在列表里选一个**早于删除时间**的版本 → **还原**（或"复制"，先复制到别处更保险）。
2. 如果右键没有这一项：打开**控制面板**（`Win + R` 输入 `control` 回车）→ 系统和安全 → **文件历史记录** → "还原个人文件"，按时间轴找。
3. 只对**用户文件夹**（桌面/文档/图片）生效；且需要事先开启过文件历史记录或存在还原点，没开过就没有这一项。

**预期结果**：找到旧版本文件并恢复出来。

**失败怎么办**：文件历史记录未开启、也没有卷影副本，就继续步骤 4；Windows 家庭版默认不提供完整的"以前的版本"入口，**以微软官方文档为准**，不要为此去改注册表。

### 步骤 4：确认真的要用恢复工具之前的最后检查

**目的**：恢复工具是"写入型"操作，用错可能顶掉原数据，先排除其他可能。

**操作**：按下面这张表自查一遍：

| 情况 | 更该做的事 |
|---|---|
| 文件在"最近使用"里还能看到，但打不开 | 右键 → 属性，确认文件是否真实存在；可能只是快捷方式失效 |
| 文档在 Office 里没保存就关了 | 看 Office 的"恢复未保存的文档"与自动恢复目录 |
| 文件被同步软件"删除"了 | 登录同步网盘网页版查回收站与版本历史 |
| 整个文件夹不见了 | 先用资源管理器搜索框搜全盘文件名，再排查是否被移到了别处 |
| 病毒导致文件被加密 | 看[「文件被加密了 / 弹出勒索要比特币怎么办」](./malware-first-response.html) |

**预期结果**：确认"回收站 + 云盘 + 旧版本"都没有，才进入工具恢复。

**失败怎么办**：以上都确认没有，进入步骤 5。

### 步骤 5：用系统自带工具恢复（Windows File Recovery / winfr）

**目的**：用微软官方免费的命令行工具扫描未覆盖的删除数据。

> ⛔ 有数据风险：**恢复出的文件必须保存到另一块盘**（`E:` 或 U 盘）。保存回原盘会覆盖你想恢复的数据，等于亲手毁掉机会。另外：**不要把 Windows File Recovery 安装到需要恢复的那块盘上。**

**操作**：

1. 到 **Microsoft Store** 搜索并安装"**Windows File Recovery**"（微软官方应用，仅 Windows 10/11）。
2. 从开始菜单以管理员身份启动它，会打开一个命令提示符窗口。
3. 命令格式为（**下方命令中的目标盘必须是另一块盘**）：

> ⛔ 有数据风险：目标盘写成源盘（例如 `winfr C: C:`）会直接覆盖你要恢复的数据。执行前再核对一次盘符。

```bat
winfr 源盘: 目标盘: [/模式] [/开关]
```

4. 常用两档模式：
   - `/regular`：用于 **NTFS** 盘、**刚删除不久**的情况（速度快）。
   - `/extensive`：用于 **非 NTFS**（如 exFAT 的 U 盘）、删除较久或格式化后的情况（慢，但更彻底）。

5. 实际例子（C 盘误删的文档恢复到 E 盘，注意路径末尾的反斜杠）：

```bat
winfr C: E: /regular /n \Users\你的用户名\Documents\
```

按文件名模糊恢复（比如所有 PDF 和 Word）：

```bat
winfr C: E: /regular /n *.pdf /n *.docx
```

**预期结果**：工具扫描后在目标盘生成"恢复"文件夹，里面有找回的文件。

**失败怎么办**：报"权限不足"就用管理员身份重开；提示目标盘不能与源盘相同，就换一块盘；模式选错（NTFS 用了 extensive）可以换模式再跑一次；**参数与模式的含义以微软官方文档为准**，不要凭记忆写。

### 步骤 6：macOS 上的恢复顺序

**目的**：Mac 的路径与 Windows 不同，但顺序原则一致。

**操作**：

1. **废纸篓**：双击打开，右键 → **放回原处**。
2. **时间机器**：接入备份盘后，点菜单栏时间机器图标 → "**浏览时间机器备份**"，找到删除文件的时间点 → 选中文件 → **恢复**。
3. **本地快照**：在访达里打开目标文件夹，进入时间机器浏览界面，也能看到本机的 APFS 本地快照。
4. **iCloud 云盘**：`icloud.com` → **最近删除**。
5. 以上都没有，才考虑第三方恢复工具——**优先选择有口碑的厂商产品**，并把恢复结果保存到**另一块盘**。

**预期结果**：文件从废纸篓或时间机器备份中恢复出来。

**失败怎么办**：时间机器从未开启过就没有备份可恢复，只能走工具恢复或接受损失；**具体操作以 Apple 支持文档为准**。

### 步骤 7：验证恢复结果并立刻补上备份

**目的**：恢复出来的文件常常是"部分损坏"的，要逐个确认，并避免第二次踩坑。

**操作**：

1. 逐个打开恢复的文件，特别是大文件（视频、压缩包要试解压、Office 文档要看内容是否完整）。
2. 文件名可能变成 `$Rxxxxx`、`文件(1)` 这类，按内容识别再改回名字。
3. **立刻**把找回的文件再备份一份到另一块盘/云盘。

**预期结果**：文件能正常打开，并且已经有第二份副本。

**失败怎么办**：文件名对了但打不开（内容全 0 或被截断），说明原数据已被部分覆盖；如果是极其重要的文件，此时停止一切操作并考虑**专业数据恢复机构**（先检测后报价）。

## 怎么确认修好了

恢复出来的文件**能被对应软件正常打开且内容完整**（能看、能编辑、能播放），并且已经复制到另一块盘或云盘上；同时确认原盘上没有再做任何写入。

## 还是不行？

- **分区/整个磁盘不见了或被格式化** → 看[「格式化后数据还能恢复吗 / 分区不见了怎么找回」](./partition-manager.html)。
- **磁盘有异响、识别不到** → 看[「硬盘咔咔响 / 电脑识别不到硬盘，是不是要坏了」](./disk-clicking-failure.html)，先断电保数据。
- **是被勒索病毒加密的** → 看[「文件被加密了 / 弹出勒索要比特币怎么办」](./malware-first-response.html)，**不要付赎金、不要下载来路不明的"解密工具"**。
- **数据是唯一副本、价值很高、自己恢复失败** → **停止操作**，联系正规数据恢复机构；公司电脑**请联系 IT**，由 IT 决定是否送专业恢复。

## 预防

1. 开启并定期检查**文件历史记录**（Windows）或**时间机器**（macOS）——这是"删了也能找回来"的底气。
2. 重要文件同时放在本地 + 云盘，云盘的回收站与版本历史是第二道保险。
3. 确认工作文件已保存再整理磁盘，删除前多看一眼路径。
4. 不要把唯一一份重要数据放在 U 盘或移动硬盘上长期保存。
5. 定期做一次"假删除演练"：随机删一个小文件试试自己能不能找回，验证备份真的可用。
