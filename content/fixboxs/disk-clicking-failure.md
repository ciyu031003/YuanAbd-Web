# 硬盘咔咔响 / 电脑识别不到硬盘，是不是要坏了

> ⛔ 有数据风险：**听到规律的咔咔声、哒哒声、金属摩擦声，请立刻断电，不要再反复开机尝试。**
> 这类声音通常代表机械硬盘的磁头或盘片已经受损，每一次通电都可能让坏区扩大，甚至变成"完全读不出"。
> 正确顺序永远是：**先断电 → 再备份 → 最后才检测和更换**，而不是先跑修复工具。

## 一句话结论

**规律性的咔咔/哒哒/刮擦声，基本可以判定机械硬盘已经出现物理故障**；此时第一件事是断电并把重要数据备份到别的盘，而不是运行检测或修复——修复工具在坏盘上只会加重损伤。

## 30 秒快速排查

1. **立刻关机断电**（长按电源键 5 秒），拔掉外接硬盘的数据线和电源。**期望结果**：停止对异常盘的任何通电和读写。
2. 判断声音来源：拔掉所有硬盘电源线后只给主机通电（不进系统也行），看声音还在不在。**期望结果**：声音消失 = 来自硬盘；声音还在 = 可能是风扇（风扇异响见"不适用"里的分流）。
3. 电脑还能进系统的话，打开**磁盘管理**看这块盘是否显示"未知/未初始化/RAW"。**期望结果**：确认系统在什么层面上"看不到"它——是 BIOS 看不到，还是系统看不到分区。

## 适用 / 不适用

**适用**

- 机械硬盘（台式机 3.5 寸盘、笔记本 2.5 寸盘、移动硬盘）出现规律咔咔/哒哒/嗡嗡异响。
- BIOS 里能看到硬盘，但进不了系统、报"找不到启动设备"。
- 系统里磁盘占用长期 100%、文件打开卡很久、复制大文件报错。
- 固态硬盘（SSD）突然"掉盘"，重启才能看到，用一会儿又消失。

**不适用**

- 听到的是机箱风扇、CPU 风扇、电源风扇或水冷泵的声音：这类异响通常随转速变化，拆开侧板用手轻按风扇停转来确认，清灰或换风扇即可。
- U 盘/移动硬盘只是提示格式化、没有异响：看[「U 盘 / 移动硬盘不识别、提示格式化怎么办」](./usb-drive-not-recognized.html)。
- 只是误删了文件、盘本身健康：看[「文件误删了怎么恢复（先做这一步，别写磁盘）」](./deleted-file-recovery.html)。
- 电脑开机完全没反应、风扇转但屏幕不亮：看[「电脑开机没反应 / 主机亮灯但显示器没信号」](./psu-no-power-check.html)。

## 开始前确认

- [ ] 已经**断电**，没有在对异常盘做任何读写。
- [ ] 准备好另一块容量足够的硬盘（或云盘）作为备份目标，且**目标盘健康**。
- [ ] 想清楚哪些数据是最要紧的（文档、照片、财务、工作文件），备份时优先拷这些。
- [ ] 接受一个事实：**继续通电检测一次，成功恢复的概率就可能下降一点**；数据不可替代时优先考虑专业恢复。
- [ ] 如果是公司/单位电脑：**立即联系 IT**，不要自行拆盘或反复尝试。

## 分步骤

### 步骤 1：确认声音到底来自哪里

**目的**：别把风扇噪音当硬盘故障，也别把硬盘故障当风扇问题。

**操作**：

1. 台式机：打开侧板，通电后用手（**注意不要碰扇叶**）轻按各个风扇中心让其停转，逐个排除 CPU 风扇、机箱风扇、显卡风扇、电源风扇。
2. 笔记本/移动硬盘：把移动硬盘拿在手里通电，听声音是否随它一起出现；拔掉它再看电脑是否还有声音。
3. 记录声音特征：规律"咔—咔—咔"（磁头反复复位）与"嗡—嗡"（电机/风扇）含义完全不同。

**预期结果**：明确是硬盘在响，还是风扇/其他部件在响。

**失败怎么办**：判断不了就把所有硬盘的数据线拔掉只留系统盘，逐一接回寻找；笔记本不便拆机时，把耳朵贴近键盘托掌区域听大致方位（**拆机有风险，保修期内送修**）。

### 步骤 2：看 BIOS/UEFI 里能不能认到这块盘

**目的**：区分"硬盘本身没被识别"和"硬盘能被识别但数据坏了"。

**操作**：重启电脑，开机时按 **Del / F2 / F10 / F12**（不同品牌不同，**以电脑或主板厂商手册为准**）进入 BIOS/UEFI，找 **Storage / SATA Configuration / NVMe** 一类的页面，看是否列出了这块硬盘的型号与容量。

| BIOS 里 | 系统里 | 说明 |
|---|---|---|
| 看得到 | 看得到，但打不开/RAW | 多为文件系统/分区表问题，重点备份数据 |
| 看得到 | 完全看不到 | 可能是分区表损坏、驱动问题或接口问题 |
| 看不到 | 看不到 | 硬盘本体、数据线或供电问题，属于硬件层 |

**预期结果**：知道问题在硬件层还是数据层。

**失败怎么办**：BIOS 里看不到时，先换一根 SATA 数据线、换一个主板 SATA 口、换一路电源线再试；M.2 固态可换另一个 M.2 插槽（注意插槽支持的协议是 SATA 还是 NVMe 要匹配）。

### 步骤 3：读一次 SMART 健康数据（有异响的先跳过这步）

**目的**：SMART 能给出"盘自己报告的"健康指标，是判断去留最直接的依据。

> ⛔ 有数据风险：如果这块盘**已经发出咔咔声**，**不要**为了跑检测而反复通电。**先做步骤 4 的备份**，SMART 放在备份之后再看。

**操作（Windows 自带方式）**：以管理员身份打开 **PowerShell**，执行：

```powershell
Get-PhysicalDisk | Select-Object FriendlyName, MediaType, HealthStatus, OperationalStatus, Size
```

看 `HealthStatus`（Healthy / Warning / Unhealthy）与 `OperationalStatus`。想读更细的可靠性计数（这一条**需要管理员权限**，普通权限会报 "Access to a CIM resource was not available"）：

```powershell
Get-PhysicalDisk | Get-StorageReliabilityCounter | Select-Object DeviceId, Wear, ReadErrorsTotal, WriteErrorsTotal, Temperature, PowerOnHours
```

也可以使用**知名厂商工具**（如硬盘厂商自家的检测工具，或 CrystalDiskInfo 这类被广泛使用的 SMART 查看工具）读取 05/C5/C6 等属性值——**只作为"知名工具"提及，请务必从官方渠道获取，不要用来源不明的下载站**。

**常见 SMART 属性对照**（名称因厂商与工具而异，**具体含义以硬盘厂商文档为准**）：

| 属性 | 通俗含义 | 危险信号 |
|---|---|---|
| 05 重映射扇区计数 | 已被替换掉的坏扇区数 | 数值 > 0 且持续增长 |
| C5 当前待处理扇区 | 读不稳、等确认的扇区 | 数值 > 0 |
| C6 无法修正的扇区 | 彻底读不出来的扇区 | 数值 > 0 |
| C7 接口 CRC 错误 | 数据线/接口传输错误 | 数值大 → 先换线 |
| C2 温度 | 盘体温度 | 长期高于厂商标称上限 |
| 通电时间 Power-On Hours | 累计通电小时 | 参考寿命，不是唯一判据 |
| SSD 磨损 Wear / 剩余寿命 | 闪存写入寿命 | 接近耗尽即更换 |

**预期结果**：拿到健康结论，能判断是"立即更换"还是"可继续观察"。

**失败怎么办**：PowerShell 报 `Get-StorageReliabilityCounter` 不可用，说明这块盘/驱动不支持通过该命令读计数，改用厂商工具；**不要因为工具读不出来就认为盘是好的**。

### 步骤 4：只读抢救数据（最重要的一步）

**目的**：数据是唯一不可替代的东西，盘可以换，数据换不回来。

**操作**：

1. 把故障盘接到电脑上（优先用**外置硬盘盒/USB 转接线**，避免它再当系统盘被反复读写）。
2. **一次只拷要紧的数据**，不要整盘全拷；拷完一批就拔下来让它休息。
3. 命令行分批复制（把盘符换成实际值，目标必须是另一块健康的盘）：

```bat
robocopy X:\重要文件夹 E:\backup\重要文件夹 /E /R:1 /W:1 /XJ
```

> ⛔ 有数据风险：源和目标写反会覆盖数据；`/R:1` 表示出错只重试 1 次，避免在坏块上反复撕扯。拷贝过程中**尽量不要再打开该盘里的其他文件**。

4. 拷不动就**跳过报错的文件**，先保住其余的，最后再单独处理那几个。

**预期结果**：重要数据出现在健康的盘上，并能正常打开。

**失败怎么办**：拷到一半掉盘，把盘断电冷却后再试一次，能拷多少算多少；报 CRC 错误就绕过该文件。**数据是唯一副本且拷不出来时，停止尝试，找专业数据恢复机构**（优先有实体门店、可签保密协议、先检测后报价）。

### 步骤 5：确认"不要做什么"

**目的**：很多盘是被错误的"修复操作"彻底弄废的。

**操作**：

| 不要做 | 原因 |
|---|---|
| 对异响盘跑 `chkdsk /f` 或 `/r` | 会强制读取坏区、加重损伤，可能让盘彻底不认 |
| 对识别不到的盘做"格式化/初始化" | 直接破坏分区表与文件索引，数据几乎不可逆 |
| 用来源不明的"坏道修复""一键分区修复"工具 | 常捆绑木马，且会写入原盘 |
| 反复开机、反复插拔尝试 | 机械盘每次通电都是一次磨损 |
| 自己拆开盘体（机械盘） | 需要在洁净环境下操作，拆开即报废，且失去专业恢复的可能 |
| 把冷冻、敲击等"土办法"用在盘上 | 有冷凝水与二次损伤风险，无法预测 |

**预期结果**：明确知道哪些操作必须避开。

**失败怎么办**：已经误操作过，就按步骤 4 重新尝试只读拷贝；仍拷不出来就交给专业机构，别再加码。

### 步骤 6：固态硬盘（SSD）"掉盘"怎么处理

**目的**：SSD 的故障表现和机械盘完全不同，往往没有预警。

**操作**：

1. 掉盘后先**关机断电 1 分钟**再开机，看能否恢复识别（有时是主控过热或固件异常）。
2. 检查散热：M.2 固态长期超过 70℃ 可能掉盘，加装散热马甲、改善机箱风道。
3. 到**固态硬盘厂商官网**查看该型号是否有固件更新与已知问题说明（**以厂商文档为准**）。
4. 用厂商工具（如各家 SSD 工具箱）查看"剩余寿命/写入量"，判断是否接近寿命终点。
5. Windows 下可执行 TRIM 优化（正常使用无需频繁操作）：

```powershell
Optimize-Volume -DriveLetter C -ReTrim -Verbose
```

**预期结果**：温度下降后掉盘不再复现，或确认是固件/寿命问题。

**失败怎么办**：反复掉盘且已备份完毕，就尽快更换——SSD 从"偶发掉盘"到"彻底不认"可能只隔几天。

### 步骤 7：决定修还是换，并做收尾

**目的**：把不确定的"也许还能用"变成明确结论。

**操作**：

- 属于**下列任一情况**：机械盘有异响 / SMART 出现 05、C5、C6 且增长 / 反复掉盘 / 通电时间很长且频繁读写错误 → **立即更换**，不要继续存重要数据。
- 只是**C7 接口 CRC 错误**且数值不再增长 → 换一根 SATA 线、换接口，观察一周。
- 更换后：把旧盘上的数据再验证一遍（随机打开若干文件确认完整），旧盘如果要留存，标记"仅作离线备份、不可依赖"。

**预期结果**：有明确结论并已执行。

**失败怎么办**：不确定是否该换，就不要把重要数据留在它上面——**换一块新盘的成本远低于数据丢失的成本**。

## 怎么确认修好了

分两种情况：**数据层已解决** = 重要文件全部在健康盘上、随机打开 10 个都能正常显示；**硬件层已解决** = 换了新盘后系统连续运行一周没有掉盘、没有异响、SMART 中 05/C5/C6 保持为 0。

## 还是不行？

- **盘上数据是唯一副本、自己拷不出来** → 停手，找正规数据恢复机构；公司设备**请联系 IT** 并保留现场。
- **盘识别不到，BIOS 里也没有** → 硬件层故障，台式机可换线换口再确认一次，笔记本/一体机的硬盘更换**建议送修**（保修期内自行拆机可能失去保修）。
- **只是文件误删、盘还健康** → 看[「文件误删了怎么恢复（先做这一步，别写磁盘）」](./deleted-file-recovery.html)。
- **电脑能开机但特别卡、磁盘占用 100%** → 先按本文步骤 3 看 SMART；如果盘健康，看[「电脑越来越卡怎么办：一张表定位是哪里卡」](./win-slow-diagnose.html)与[「CPU 或内存占用 100%，电脑卡到不能用」](./win-slow-diagnose.html)。
- **是单位电脑、或盘上有公司数据** → **立即联系 IT**，由 IT 决定是否做取证实盘恢复。

## 预防

1. 重要数据坚持"**3-2-1**"：3 份副本、2 种介质、1 份异地（云盘或另一地点）。
2. 用知名工具（厂商工具或 CrystalDiskInfo 这类）每季度看一眼 SMART，**05/C5/C6 一有非零值就开始准备换盘**。
3. 机械盘使用中不要移动主机、不要让移动硬盘悬空或被震动。
4. 机械硬盘用到 4-5 年后主动更换，别等它报错——那时往往已经拷不动了。
5. 笔记本避免长期高温运行（散热垫、清灰），高温会加速盘体与主控老化。
