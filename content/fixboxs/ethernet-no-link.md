# 网线插着却提示「网络电缆被拔出」怎么修

> ⚠ 需谨慎：本文的「网络重置」会把所有已保存的 Wi-Fi 密码和自定义网络配置清掉（需要重新连 Wi-Fi），「驱动卸载」后系统会自动装回但可能拿到精简版驱动——两处都有提示，按步骤走即可。其他操作都是只读检查。

## 一句话结论

「电缆被拔出」是网卡在说「**我在物理层没看到对端**」，所以先查物理层：**网口指示灯亮不亮**。灯不亮九成是网线/水晶头/对端口的问题；灯亮却报错才是系统层（驱动、节能选项、网络栈），按「换线换口 → 重置适配器 → 重装驱动 → 网络重置」的顺序走，别一上来就重装系统。

## 30 秒快速排查

1. 看电脑网口和路由器网口的**指示灯**。**期望结果**：两端至少一端亮/闪 → 链路在，问题在系统层，跳步骤 3；全不亮 → 物理层问题，进步骤 2。
2. 换一根网线、换路由器上另一个 LAN 口，把两端重新插紧（听到咔哒）。**期望结果**：灯亮、报错消失——八成是水晶头氧化或线芯断。**失败了怎么办**：换线换口都不亮，进步骤 3。
3. 设备管理器看网卡状态：`Win + X` → 设备管理器 → 网络适配器，看有线上网卡有无黄色感叹号或设备消失。
**期望结果**：设备正常在列 → 进步骤 4；设备消失或报错 → 直接进步骤 4 重装驱动。

## 小白一键修复

- 下载：[重启有线网卡（.bat）](../scripts/restart-ethernet-adapter.bat)
- 适合：网口指示灯亮/闪，但电脑仍显示「网络电缆被拔出」「未识别的网络」，或以太网适配器出现黄色感叹号。
- 脚本会：重新扫描即插即用设备，重启除 Wi-Fi 外的物理网卡，然后打开网络连接面板确认「以太网」状态。
- 运行前：正在远程控制这台电脑时不要运行（网卡重启会掉线）；保存好正在传输的文件。
- 注意：脚本不会重装驱动；若设备管理器里网卡仍有感叹号，请继续按正文回退或重装驱动。

## 适用 / 不适用

**适用**

- 任务栏以太网图标显示红色叉、提示「网络电缆被拔出」。
- 换过房间/工位之后有线突然不通。
- 网口灯亮但就是拿不到 IP / 提示未识别的网络。

**不适用**

- Wi-Fi 也不通、全屋断网：看[「家里所有设备都上不了网怎么办」](./home-network-all-offline.html)。
- 灯亮、有 IP 但上不了外网：看[「Wi-Fi 有信号但上不了网」](./wifi-connected-but-no-internet.html)的分层思路。
- 网口机械损坏（针脚歪、卡扣断）：直接送修或加装 USB 网卡，不要自己掰针脚。

## 开始前确认

- [ ] 确认插的是**路由器/光猫的 LAN 口**而不是光猫的 IPTV 口（机顶盒口）。
- [ ] 手边有一根备用网线或至少能换一个 LAN 口。
- [ ] 记下当前 Wi-Fi 密码（做「网络重置」后要重连）。
- [ ] 笔记本用户确认没有开启「飞行模式」（部分机型飞行模式会一并关闭有线）。

## 分步骤

### 步骤 1：物理层排查（换线、换口、看灯）

1. 换一根确认正常的网线，或把现在的线插到路由器另一个 LAN 口。
2. 插紧两端，观察电脑网口与路由器口的指示灯（绿灯=链路正常，橙灯/闪烁=有流量）。
3. 检查水晶头有无发黑氧化、线体有无被门夹/压扁的痕迹。
**期望结果**：灯亮且报错消失。**失败了怎么办**：灯始终不亮，跳到步骤 4 查驱动与网卡状态。

### 步骤 2：重置以太网适配器

1. `Win + R` 输入 `ncpa.cpl` 回车，右键「以太网」→ 先「禁用」，等 5 秒再「启用」。
2. 拔掉网线等 10 秒再插回。
**期望结果**：图标转成已连接。**失败了怎么办**：继续步骤 3。

### 步骤 3：关闭网卡节能选项（笔记本高发）

1. 设备管理器 → 网络适配器 → 找到有线网卡（名字含 Realtek/Intel Ethernet）→ 属性。
2. 「高级」选项卡：把 **Energy Efficient Ethernet（节能以太网）/ Green Ethernet** 设为「关闭」；「电源管理」选项卡：取消「允许计算机关闭此设备以节约电源」。
3. 确定后重插网线。
**期望结果**：链路恢复稳定，不再间歇性「电缆被拔出」。**失败了怎么办**：间歇断连依旧 → 换更短的优质网线（劣质长线在节能模式下协商不稳），仍不行进步骤 4。

### 步骤 4：重装网卡驱动

1. 设备管理器 → 右键有线网卡 → 「卸载设备」（如果弹窗有「删除此设备的驱动程序」就勾上）→ 重启电脑，系统自动装回通用驱动。
2. 更稳的做法：去**笔记本/主板厂商官网**按型号下载有线网卡驱动手动安装（微软社区对这类问题的官方回复也是建议用厂商原版驱动，不要用第三方驱动工具）。
**期望结果**：设备管理器无感叹号，插线即连。**失败了怎么办**：厂商驱动装完仍报错 → 进步骤 5。

### 步骤 5：网络重置（大杀器，最后用）

1. 设置 → 网络和 Internet → 高级网络设置 → 「网络重置」→ 立即重置，电脑会重启。
2. 重启后所有网络适配器恢复出厂、已存 Wi-Fi 清空，重新连 Wi-Fi / 插网线。
**期望结果**：以太网恢复。**失败了怎么办**：重置后仍然「电缆被拔出」且灯不亮 → 基本可以判定**网口硬件损坏**，送修或花几十块加一块 USB 有线网卡是最省事的解法。

## 怎么确认修好了

- 插线即连，任务栏以太网图标正常，`ipconfig` 拿到正常 IP（不是 169.254 开头）。
- 连续使用半小时无「电缆被拔出」闪断。
- 重启电脑后依然正常。

## 还是不行？

- 换线换口重装驱动全试过、灯也不亮 → 网口硬件问题：台式机可加 PCIe/USB 网卡顶替，笔记本用 USB 网卡。
- 灯亮但拿不到 IP（169.254）→ 是 DHCP 层问题，看[「获取到 169.254 地址怎么办」](./dhcp-no-ip-169-254.html)。
- 公司环境插网线不通 → 可能是端口准入（802.1X）没认证，看[「公司电脑上不了网？企业代理环境排查」](./enterprise-proxy.html)或找 IT。

## 预防

- 网线水晶头是易耗件，氧化/松动高发；重插紧、定期检查是最便宜的维护。
- 笔记本关掉网卡节能选项，能避开一大类「间歇掉线」玄学。
- 驱动只从厂商官网拿，别用「一键驱动大师」类工具。
