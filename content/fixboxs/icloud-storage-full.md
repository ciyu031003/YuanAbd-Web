# iCloud 储存空间不足怎么办：先看谁在吃空间，再决定清还是升

> ℹ️ 本教程只做查看与清理决策，不删任何本机文件。唯一要提醒的是：**关闭 iCloud 照片/同步时，选「从 iPhone 移除」之前务必确认照片已经有另一份备份**——云端和本机二选一的删除，是「照片没了」这类事故的主要来源。

## 一句话结论

iCloud 空间不足只有三条路：**清掉占大头的旧备份/废文件、把「优化储存」打开让大文件留在云端、或者升级/共享套餐**。先打开「管理储存空间」看清楚是照片、备份还是微信数据在吃空间，再做决定——不看就清，清的多半是不该清的。

## 30 秒快速排查

1. 打开「系统设置 → Apple 账户（头像）→ iCloud → 管理」（iPhone 在「设置 → 你的名字 → iCloud → 管理账户储存空间」）。**期望结果**：看到按占用排序的清单——照片、备份、各类 App 数据各占多少。
2. 看备份清单里有没有**旧设备**（换机前的老 iPhone/iPad 还留在备份列表里）。**期望结果**：删掉旧设备的整份备份，通常一次腾出几个 GB。
3. 回到 iCloud 主页，确认「照片」的「优化 Mac 储存空间」已勾选（iPhone 是「优化 iPhone 储存空间」）。**期望结果**：本机只留小图，原图存云端，本机空间立刻缓解。

## 适用 / 不适用

**适用**

- 反复弹「iCloud 储存空间不足 / 无法备份」，免费 5GB 用满。
- 照片库几十 G，Mac/iPhone 本机空间也被照片吃掉。
- 换机后旧设备备份还挂在账户里。

**不适用**

- 是 **Mac 本机硬盘**满而不是 iCloud 满（看[「Mac 储存空间不足 /「系统数据」占了上百 G」](./mac-storage-system-data.html)，两者经常被混淆）。
- 忘记 Apple ID 密码：先走[「Mac 忘记开机密码怎么办」](./mac-forgot-password.html)里的 Apple 账户找回路径。
- 家庭共享里其他成员的乱账：管理员账户先看共享方案再分摊。

## 开始前确认

- [ ] 本机照片能正常打开（iCloud 照片开着时，缩略图能看就说明云端还在）。
- [ ] 知道自己当前的套餐：免费 5GB / 50GB / 200GB / 2TB。
- [ ] 记住 Apple ID 密码（清理备份时可能要求验证）。
- [ ] 想清楚底线：哪些数据绝对不能丢（一般是照片 + 微信聊天记录 + 备忘录）。

## 分步骤

### 步骤 1：看清楚谁在吃空间

1. 系统设置 → Apple 账户 → iCloud → 管理。
2. 按占用从大到小记下前三名（通常是：设备备份 / 照片 / 某个 App 如微信）。
**期望结果**：清单在手，目标明确。**失败了怎么办**：清单加载不出来 → 换浏览器登录 icloud.com 看储存页，或稍后重试（服务器偶尔慢）。

### 步骤 2：清掉旧设备备份和无用备份

1. 在「管理」里点「备份」（iPhone 在「管理账户储存空间 → 备份」）。
2. 留下**正在用的设备**，把旧设备、报废设备的备份删掉。
3. 注意「这台设备正在备份的应用」列表：把不需要云端备份的大 App（如大型游戏）关掉，下次备份立刻瘦身。
**期望结果**：可用空间明显回升（旧备份动辄 10-60GB）。**失败了怎么办**：删除按钮灰色 → 先关该设备的「iCloud 云备份」开关再删。

### 步骤 3：给照片减负（大头通常在这）

1. 确认「iCloud 照片」开着且设备上选了「优化储存空间」——这是官方的冷热分层：本机存小图，原图在云端。
2. 清空「最近删除」相册（照片删了还会占位 30 天）。
3. 视频是大头：把几年前的长视频导到移动硬盘后，再从相册删除并清空最近删除。
**期望结果**：本机与云端占用同步下降。**失败了怎么办**：删了照片空间没变 → 最近删除没清；清了还没变 → 等 24 小时（iCloud 计量有延迟）。

### 步骤 4：处理 App 数据和其他占用

1. 「管理」清单里逐个看大 App：微信/QQ 的聊天记录备份、备忘录、第三方网盘缓存。
2. 微信之类进 App 内部清理（App 内的「储存空间 → 清理缓存」），比在 iCloud 层面硬删安全。
3. 邮件占用大 → 清理「废纸篓」「已删除」和超大附件。
**期望结果**：占用清单里没有明显异常项。**失败了怎么办**：某项数据不敢动 → 保留，用升级套餐兜底，别赌。

### 步骤 5：决定「清」还是「升」+ 备份兜底

1. 清完仍紧张（比如照片库常年 >100GB）→ 升级套餐：50GB（¥6/月）起步，或开「家人共享」让 200GB/2TB 全家分摊。
2. 无论升不升，给**照片和重要文件**加一层本地备份（移动硬盘 + 时间机器），看[「换硬盘 / 重装系统前，怎么把数据备份全」](./backup-before-repair.html)。
3. 免费 5GB 用户优先保「备份」而不是照片原图：换机时备份的价值更高。
**期望结果**：不再弹空间不足，且有两份数据兜底。**失败了怎么办**：升级后仍不足 → 大概率是某台设备的备份设置没瘦身，回到步骤 2。

## 怎么确认修好了

- 「管理」页顶部显示的可用空间 > 1GB，且 24 小时后不再弹不足提示。
- 照片能正常上传（新拍一张，几分钟内 icloud.com 里能看到）。
- 设备夜间备份成功一次（设置里看「上次成功备份」时间）。

## 还是不行？

- 删了东西空间迟迟不减 → iCloud 计量延迟，等 24-48 小时；仍不减就联系 Apple 支持。
- 照片上传一直转圈 → 检查网络与「低数据模式」，充电 + 锁屏状态下会自动续传。
- 想整体换方案（如全家合租 2TB）→ 在「家人共享」里由组织者开通并邀请成员，成员各自隐私互不可见。

## 预防

- 每季度打开一次「管理储存空间」看趋势，别等满了才清。
- 换机当天就删旧设备备份，这是最大的一块「隐形占用」。
- 重要照片永远保持「云端 + 本地硬盘」两份，云不是备份的唯一答案。
