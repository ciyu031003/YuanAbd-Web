# Mac 应用打不开：提示「已损坏」或「无法验证开发者」怎么修

> ⚠ 需谨慎：本文的「仍要打开」和移除隔离属性，本质都是绕过苹果的应用安全审查。**只对来源可信的安装包使用**（官网、公司内部渠道）；来路不明的「破解版」「绿色版」就算能打开，也可能携带窃密程序——打不开反而是 Gatekeeper 在保护你。

## 一句话结论

「已损坏」「无法验证开发者」是 Gatekeeper（门禁）在拦截没有公证签名的应用，**不是应用真的坏了**。macOS 15 起右键「打开」的老办法被收走了，官方途径是「系统设置 → 隐私与安全性 → 仍要打开」；确认来源可信后走这条路，绝大多数都能解决。

## 30 秒快速排查

1. **看提示原文**：「无法打开，因为无法确认其来自身份不明的开发者」或「Apple 无法检查是否包含恶意软件」→ 是 Gatekeeper 拦截，走步骤 2。「应用"xxx"已损坏，无法打开」→ 可能是下载不完整，先走步骤 3 重新下载。
2. **系统设置放行**：苹果菜单 →「系统设置」→「隐私与安全性」→ 滚动到「安全性」区，会看到「"xxx"已被阻止」一行 → 点「仍要打开」→ 输密码。**期望结果**：应用正常启动。
3. **重新下载安装包**：删掉 dmg/app，从软件官网重新下载（别用下载站的加速器版本）。**期望结果**：完整下载后能打开。
**失败了怎么办**：两条都试过仍报错 → 进步骤 4（老系统）或步骤 5（终端方案）。

## 适用 / 不适用

**适用**

- 双击应用弹出「已损坏，无法打开，建议将它移到废纸篓」。
- 提示「无法验证开发者」/「无法确认其来自身份不明的开发者」。
- 从官网下载的 dmg 安装后，第一次启动就被拦。
- 同一个安装包在别的 Mac 上能装，这台不行。

**不适用**

- App Store 下载的应用打不开 → 看[「Mac App Store 下载卡住 / 无法更新应用」](./mac-app-store-download-stuck.html)。
- 应用能打开但用着用着闪退 → 是应用本身的问题，先重装该应用。
- 提示「应用不在此 Mac 上受支持」→ 架构不符（老 Intel 应用装在 Apple Silicon 上），找该应用的 Apple Silicon 版本。
- 企业 MDM 管理的电脑被策略拦截 → 联系公司 IT。

## 开始前确认

- [ ] 知道安装包的来源，且认为它可信。
- [ ] Mac 有管理员密码。
- [ ] 安装包不是从聊天工具「传文件」过来的半截文件（大小和官网标注一致）。

## 分步骤

### 步骤 1：用「隐私与安全性」放行（macOS 15/14 官方途径）

1. 双击应用，让拦截弹窗出现一次（哪怕提示「移到废纸篓」也先别删，点「完成」）。
2. 苹果菜单 →「系统设置」→「隐私与安全性」→ 滚动到「安全性」。
3. 找到「"xxx"已被阻止，使用前需要验证开发者」→ 点「仍要打开」→ 输入管理员密码 → 确认。
**期望结果**：应用启动，此后不会再拦这个应用。**失败了怎么办**：安全性区没有那一行 → 说明该应用被系统判定为高风险（常见于伪装的假安装包），直接删掉换官方下载源。

### 步骤 2：右键「打开」（macOS 13 及更早）

1. 在访达里**按住 Control 点按**（或右键）应用图标 → 选「打开」。
2. 弹窗里再点「打开」确认。
**期望结果**：绕过首次验证，应用启动。**失败了怎么办**：macOS 15 已移除此入口，回到步骤 1。

### 步骤 3：排除「下载不完整」

1. 删除已下载的 dmg 和已安装的 app（拖进废纸篓并清空）。
2. 用浏览器从软件官网重新下载，对比文件大小是否与官网标注一致。
3. 重新安装后再打开。
**期望结果**：完整安装包不再报「已损坏」。**失败了怎么办**：报错依旧 → 走步骤 4。

### 步骤 4：用终端移除隔离属性（高级，确认来源可信再用）

1. 打开「终端」（启动台 → 其他 → 终端）。
2. 输入：`xattr -dr com.apple.quarantine /Applications/应用名.app`（把「应用名」换成实际名称；输入 `/Applications/` 后可以把应用图标拖进终端自动补全路径）。
3. 回车后再双击打开。
**期望结果**：隔离标记被清除，应用正常打开。**失败了怎么办**：提示 `Operation not permitted` → 给终端授权：系统设置 → 隐私与安全性 → 完全磁盘访问权限 → 打开「终端」；仍不行说明应用本身有问题，别再折腾，回到步骤 3 换下载源。

### 步骤 5：还不行就换安装包来源

1. 官网下载总是报错 → 换浏览器（Safari ↔ Chrome）下载，排除下载中途断流。
2. 某些国产软件官网把 Intel/Apple Silicon 安装包混在一起 → 确认下载的是本机架构版本。
3. 以上全部无效且你确信安装包没问题 → 到「磁盘工具」跑一次「急救」修复系统盘权限异常，再重装应用。
**期望结果**：换源后正常安装。**失败了怎么办**：依旧「已损坏」→ 大概率这个包真的有问题（被篡改或版本太老不兼容新系统），放弃它，找该应用的官方现行版本。

## 怎么确认修好了

- 双击应用直接启动，不再出现任何 Gatekeeper 弹窗。
- 重启 Mac 之后再打开一次，依然正常（确认放行已持久生效）。
- 「系统设置 → 隐私与安全性」里不再出现新的拦截记录。

## 还是不行？

- 应用是公司内部工具 → 找 IT 出签名版或走 MDM 下发，不要自己绕过安全策略。
- 怀疑系统安全组件异常 → 重启进安全模式（Apple Silicon：关机后长按电源键到出现启动选项，选中启动盘并按住 Shift 点「以安全模式继续」）再装一次。
- 同类问题在多台 Mac 上出现且都指向同一个安装包 → 这个包发布方需要重新公证签名，等官方更新。

## 预防

- 只从官网或 App Store 拿软件；「已损坏」提示本身就是一道防线，不要养成见弹窗就绕的习惯。
- 大型软件下载后先看文件大小对不对得上官网标注。
- macOS 升级大版本后，老应用可能重新被拦——那是它们没跟上新的公证要求，去官网拿新版。
