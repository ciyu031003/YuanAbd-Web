# Mac 外接显示器 / 扩展坞不识别怎么修

> 本文只检查线材、接口和显示设置，不会修改磁盘或系统安全设置。使用非原装扩展坞时，注意其供电和接口规格，避免边充边用导致反复掉线。

## 一句话结论

Mac 外接屏没信号，先分清是显示器没被识别、被识别但没有画面，还是分辨率/镜像设置错误。优先直连、换线、换口，再看系统设置；扩展坞必须同时满足协议、带宽和供电，接口长得一样不代表功能一样。

## 30 秒快速排查

1. 确认显示器输入源切到正确的 HDMI/DisplayPort/USB-C 接口。
2. 拔掉扩展坞，用一根支持视频传输的线直连 Mac 与显示器。
3. 打开系统设置 → 显示器，按住 `Option` 键查看是否出现“检测显示器”。

## 适用 / 不适用

**适用：**
- Mac 外接屏黑屏、提示无信号或只充电不传画面
- 系统设置里完全看不到第二台显示器
- 扩展坞接显示器偶发闪烁、唤醒后不恢复
- 合盖后外接屏没有成为主屏

**不适用：**
- Windows 台式机也没有信号 → [显示器无信号怎么排查](./monitor-no-signal.html)
- 想无线投屏到电视 → [屏幕投射 / Miracast 排查](./screen-cast-miracast.html)
- Mac 自己也无法开机或花屏 → 先处理系统或显卡故障
- 显示器电源灯不亮 → 先检查显示器电源线和开关

## 开始前确认

- [ ] 知道 Mac 的准确型号和接口
- [ ] 知道显示器支持的接口、分辨率和刷新率
- [ ] 扩展坞有独立供电或符合 Mac 所需功率
- [ ] 有一根可以确认支持视频的线材

## 分步骤

### 步骤 1：确认显示器与线材是否正常

**目的**：很多“Mac 不识别”其实是显示器输入源、线材或扩展坞故障。

**操作**：
1. 显示器菜单里手动选择当前接口，不要只依赖自动检测。
2. 换一根已知支持视频的线；很多 USB-C 线只支持充电和数据。
3. 把同一根线和显示器接到另一台电脑测试。
4. 清理接口灰尘，换 Mac 上另一个 USB-C/HDMI 口。

**预期结果**：显示器能显示另一台电脑画面，线材和显示器基本正常。

**失败怎么办**：另一台电脑也无信号 → 先修显示器或线材；另一台正常 → 问题在 Mac、扩展坞或兼容性。

### 步骤 2：优先直连，绕过扩展坞

**目的**：扩展坞的协议转换、带宽和供电最容易造成偶发无信号。

**操作**：
1. 用合适的转接器或线材把 Mac 直接接到显示器。
2. 如果必须使用扩展坞，拔掉其他 USB 硬盘和读卡器，只留显示器测试。
3. 给扩展坞接上官方要求的电源，不要仅靠 Mac 电池供电。
4. 换一个明确支持 DisplayPort Alt Mode 的 USB-C 口。

**预期结果**：直连能出画面，说明问题在扩展坞供电、兼容性或负载。

**失败怎么办**：直连也没有画面 → 继续步骤 3；扩展坞更新固件只能使用厂商官方工具。

### 步骤 3：检查显示器设置

**目的**：系统已识别但处于镜像、错误分辨率或排列在屏幕外时，看起来也像黑屏。

**操作**：
1. 打开系统设置 → 显示器。
2. 确认能看到两个显示器名称；看不到时按住 `Option` 键再查看“检测显示器”。
3. 选择“扩展显示器”或“镜像显示器”，先测试最基本模式。
4. 点“排列”，把第二块屏幕拖到可见区域，再设为“主显示器”测试。
5. 把刷新率改为 60 Hz、分辨率改为默认值，避免超出线材带宽。

**预期结果**：显示器出现桌面或镜像画面，鼠标能移动到第二块屏幕。

**失败怎么办**：能用低分辨率但默认分辨率黑屏 → 线材或扩展坞带宽不足；需要转接器官方规格。

### 步骤 4：测试合盖模式与唤醒状态

**目的**：笔记本合盖外接屏需要电源、键盘鼠标和更严格的兼容性。

**操作**：
1. 接上 Mac 电源和有线/蓝牙键鼠。
2. 合盖前先确认外接屏已正常显示，再合盖。
3. 如果唤醒后不显示，拔掉显示器线等待 5 秒再插回。
4. 重新打开上盖，检查显示器是否恢复。

**预期结果**：合盖后外接屏正常显示，唤醒后自动恢复。

**失败怎么办**：合盖才失败 → 检查扩展坞供电与 macOS 设置；不要使用会阻断视频的信号切换器。

### 步骤 5：读取系统信息并做交叉验证

**目的**：判断 macOS 是否看到显示器、接口和分辨率，给售后提供明确证据。

**操作**：
1. 打开“系统信息”，选择“图形卡/显示器”。
2. 或在终端运行只读命令：

```bash
system_profiler SPDisplaysDataType
```

3. 查看是否列出外接显示器和当前分辨率。
4. 用另一台 Mac 或另一台显示器交叉测试，确认故障跟随哪一件设备。
5. 有系统更新时安装 macOS 更新并重启，再测试。

**预期结果**：明确是 Mac 口、线材、扩展坞还是显示器的问题。

**失败怎么办**：系统信息能看到显示器但无画面 → 换线材/降低分辨率；完全看不到 → 联系 Apple 支持或扩展坞厂商并提供型号。

## 怎么确认修好了

显示器能在默认分辨率和 60 Hz 下稳定显示；扩展模式、镜像模式、主显示器切换都正常；合盖、睡眠唤醒和拔插线材 3 次后仍能自动恢复。

## 预防

1. 看清 USB-C 线是否支持视频、DisplayPort Alt Mode 和目标分辨率。
2. 扩展坞选择有独立供电、明确标注 Mac 兼容和带宽的产品。
3. 不在 macOS 更新后立刻依赖未经测试的第三方显示驱动。
4. 拔插线材时不要用力扭动接口，扩展坞异常发热时停止使用。
