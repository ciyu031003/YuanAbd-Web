# Mac 忘记开机密码怎么办（Apple Silicon / Intel 都覆盖）

> ⚠ 需谨慎：密码重置本身不删文件，但**旧账户的「登录钥匙串」不会跟着解锁**——重置后首次登录会提示创建新钥匙串，旧的已存密码（Wi-Fi、网页保存的密码）可能读不出来。这也是为什么先试 Apple 账户重置，它能把钥匙串一起带走。

## 一句话结论

macOS 自带密码重置：**在登录窗口输错三次，就会冒出「用 Apple 账户重置」的入口**；Apple Silicon 机器还可以在恢复模式里跑「重置密码助理」。不需要重装系统，也不需要进任何第三方工具。

## 30 秒快速排查

1. 在登录窗口连续输错密码 **3 次**。**期望结果**：提示框出现「使用 Apple 账户重置密码」或「重置密码」选项（恢复密钥/文件保险箱开启的机器会先要恢复密钥）。
2. 点它，输入 Apple 账户邮箱和密码，按提示设置新密码。**期望结果**：用新密码直接进桌面，文件都在。
3. 如果重启后仍然要求旧密码（常见于刚改完密码）：先输**旧密码**试一次，或直接联系本机其他管理员账户改。

## 适用 / 不适用

**适用**

- 本人的 Mac，忘记登录密码，知道 Apple ID。
- 机器上有第二个管理员账户，或家人知道另一个管理员密码。
- Apple Silicon Mac 开机卡在需要密码但忘了。

**不适用**

- 不是你的机器 / 二手买来前机主没退 Apple ID：**无法也不应绕过**，找前机主解绑（这是防盗机制，不是故障）。
- 开了 FileVault 但 Apple ID 和恢复密钥都没有：数据基本无解，这是加密的代价；到 Apple 官方授权点咨询，不要信网上「破解工具」。
- 公司配的电脑：先问 IT，企业管理的设备有统一流程。

## 开始前确认

- [ ] 这是本人或已获授权的机器。
- [ ] Apple ID 的密码你自己记得（不记得先去 iforgot.apple.com 找回 Apple ID）。
- [ ] 手机在旁边，能收双重认证验证码。
- [ ] 电源插着，别在重置中途断电。

## 分步骤

### 步骤 1：登录窗口的 Apple 账户重置（优先试这个）

1. 停在登录窗口，密码随便输 3 次错的。
2. 出现「使用 Apple 账户重置密码」→ 点击 → 输入 Apple ID 和密码。
3. 按屏幕提示设置新密码，等待重置完成，用新密码登录。
**期望结果**：直接进桌面，桌面上文件原样都在。**失败了怎么办**：没出现该选项，进步骤 2。

### 步骤 2：恢复模式里的「重置密码助理」

- **Apple Silicon**：关机 → 长按电源键到「载入启动选项」→ 选「选项」→ 继续 → 菜单栏「实用工具」→ **终端**，输入 `resetpassword` 回车；或直接在恢复界面选「忘记所有密码？」。
- **Intel**：关机 → 开机按住 **Command + R** 进恢复 → 菜单栏「实用工具」→ **终端**，输入 `resetpassword` 回车。
1. 在「重置密码助理」里选你的启动盘 → 选用户 → 输入新密码两遍。
2. 点「保存」并重启。
**期望结果**：新密码可登录。**失败了怎么办**：列表里没有你的用户，说明系统卷异常，先看[「Mac 开不了机 / 卡在苹果标志怎么办」](./mac-wont-boot.html)把系统救回来。

### 步骤 3：用第二个管理员账户改密码

1. 用另一个管理员账户登录。
2. 打开「系统设置 → 用户与群组」（旧版在「系统偏好设置」）→ 选中忘记密码的账户 → 「重置密码」。
**期望结果**：设好新密码。**失败了怎么办**：没有第二个管理员账户，回到步骤 1/2。

### 步骤 4：登录后处理钥匙串提示

1. 用新密码首次登录时，系统问「无法解锁登录钥匙串」→ 选**「创建新钥匙串」**。
2. 桌面文件、照片、文档完全不受影响；丢的只是旧钥匙串里存的 Wi-Fi / 网站密码，需要重新输一遍。
3. 有「时间机器」备份的话，网页密码可从旧备份的 Safari 数据里部分找回，看[「换硬盘/重装前怎么把数据备份全」](./backup-before-repair.html)。

## 怎么确认修好了

- 重启一次，用新密码能正常进桌面。
- 「系统设置 → 用户与群组」里账户状态正常，无红色感叹号。
- iCloud「钥匙串」若开启，其他设备的已存密码会自动同步回来。

## 还是不行？

- 步骤 2 里终端报「无法找到用户」→ 系统卷损坏，先修卷再重置。
- 提示需要「固件密码 / 恢复密钥」而你都没有 → 带购买凭证联系 Apple 官方支持。
- 一切成功但担心下次再忘 → 把密码放 iCloud 钥匙串 + 密码管理器，并给自己设一个提示问题。

## 预防

- Apple ID 开启双重认证并绑定手机号，重置入口永远可用。
- 本机再建一个管理员账户，密码写在纸上锁抽屉（很多小工作室就是这么救场的）。
- 开 FileVault 时把恢复密钥存进 iCloud，不要截图放本机。
