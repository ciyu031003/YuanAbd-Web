# Mac 打印机没反应 / 显示离线怎么修

> ⚠ 需谨慎：文末的「还原打印系统」会**清空这台 Mac 上已配置的所有打印机与打印队列**（有别的打印机在用的办公环境要注意），属于最后手段。其余步骤都是无风险的查看与重添加。

## 一句话结论

Mac 打印问题九成出在「**链路**」而不是驱动：打印机没连上和 Mac 同一个网、打印队列里任务被暂停、或打印机 IP 变了导致离线。按「打印机自身 → 网络 → 队列 → 重新添加」的顺序查，绝大多数不用装任何驱动就能修好（macOS 内置 AirPrint 已覆盖近年的打印机）。

## 30 秒快速排查

1. **看打印机本身**：面板/指示灯有无报错（缺纸、卡纸、盖板未合）；曾有卡纸先处理——见[「打印机卡纸与打印质量差」](./printer-jam-quality.html)。**期望结果**：打印机待机、无报错。
2. **看网络**：打印机面板的「网络设置」页确认它连的 Wi-Fi 名和 Mac 一致（打印机常被接进访客/5G 隔离网络）。**期望结果**：同一网络。
3. **看打印队列**：系统设置 →「打印机与扫描仪」→ 选中打印机 →「打印队列」——若有任务显示「暂停」，右键恢复或删掉任务。**期望结果**：队列清空后能重新打印。
**失败了怎么办**：打印机显示离线/队列正常仍打不出 → 进步骤 2 重新添加。

## 适用 / 不适用

**适用**

- 打印时无反应，队列里任务一直「正在打印」不动。
- 打印机在列表里但标记「离线」。
- 「添加打印机」列表里搜不到打印机。
- 更新 macOS 后打印机突然不能用。

**不适用**

- 打印出来有横纹/褪色/拖影 → 是喷头与耗材问题，看[「打印机卡纸与打印质量差」](./printer-jam-quality.html)。
- Windows 电脑打印这台打印机正常、只有 Mac 不行 → 走本文；两台都不行 → 看[「打印机连不上网/经常离线」](./printer-network-ip-fixed.html)。
- 公司共享打印机报 0x0000011b 之类错误码 → 那是 Windows 共享层的问题，看对应文章。
- 打印机面板自己报硬件错误码 → 按品牌手册处理或送修。

## 开始前确认

- [ ] 打印机型号（面板标签上），后面找驱动/核对 AirPrint 支持用。
- [ ] 打印机连的是主 Wi-Fi 而非访客网络；若是有线接路由器，确认网线灯亮。
- [ ] Mac 已更新到最新 macOS（Apple 会随系统更新内置打印机驱动）。

## 分步骤

### 步骤 1：让打印机「上线」——网络与休眠

1. 打印机深度休眠时对 AirPrint 广播会消失：按一下打印机面板把它唤醒再试。
2. 打印机面板里重连一次 Wi-Fi（多数机型：设置 → 网络 → 无线设置向导）。
3. 路由器若开了「AP 隔离 / 访客网络隔离」，打印机与 Mac 互相看不见——关掉隔离或都挪到主网络。
**期望结果**：Mac「添加打印机」列表重新出现这台打印机。**失败了怎么办**：仍搜不到 → 步骤 2。

### 步骤 2：删掉重加打印机（官方推荐动作）

1. 系统设置 →「打印机与扫描仪」→ 选中这台打印机 → 「−」删除。
2. 点「＋」→ 在弹出列表中选中打印机。名字旁标「AirPrint」的优先选 **AirPrint 通用驱动**（不依赖厂商驱动，最稳）。
3. 添加后打一张测试页。
**期望结果**：添加成功并打出测试页。**失败了怎么办**：列表里搜不到 → 步骤 3；能添加但打印仍出错 → 步骤 4。

### 步骤 3：搜不到打印机时——按 IP 添加

1. 在打印机面板网络页查出它的 IP 地址（如 192.168.1.105）。
2. 系统设置 → 打印机与扫描仪 → ＋ → 工具栏「IP」图标 → 输入该 IP，协议选 **IPP**（或 HP Jetdirect-Socket，视机型）。
3. 驱动选「AirPrint」或厂商对应型号 → 添加 → 测试页。
**期望结果**：按 IP 直连成功。**失败了怎么办**：浏览器打开 `http://<打印机IP>` 也进不去面板 → 打印机根本没连上网，回到步骤 1 重配网络，或看[「打印机连不上网/经常离线」](./printer-network-ip-fixed.html)。

### 步骤 4：清卡住的打印任务与打印中心

1. 系统设置 → 打印机与扫描仪 → 选中打印机 →「打印队列」。
2. 全选任务 → 删除；若有任务反复「正在打印」，在打印中心里停止后再试。
3. 打印中心（应用程序 → 实用工具）里确认打印机未处于「暂停」状态。
**期望结果**：新任务正常出纸。**失败了怎么办**：队列反复卡死 → 步骤 5。

### 步骤 5：还原打印系统（最后手段，会清空所有打印机配置）

1. 前提：记下这台 Mac 上**所有**打印机的型号（之后要重新添加）。
2. 系统设置 → 打印机与扫描仪 → 在打印机列表内右键（或按住 Control 点按）任意空白处 →「还原打印系统」→ 确认。
3. 按步骤 2 重新添加各台打印机。
**期望结果**：打印子系统回到出厂状态，重新添加后正常。**失败了怎么办**：还原后重加仍离线 → 到打印机官网装 macOS 版全功能驱动/固件升级打印机，仍不行换 USB 线直连测试（直连正常则纯网络问题）。

## 怎么确认修好了

- 连续打印 3 份文档（含 1 份带图片的）全部正常出纸。
- 打印机重启、Mac 重启各一次后再打，仍然正常（确认不是靠「重加」续命）。
- 「打印队列」里任务完成后自动清空，不残留离线状态。

## 还是不行？

- 按了 IP 也连不上 → 打印机与 Mac 不在同一网段（路由器子网隔离），看[「打印机连不上网/经常离线」](./printer-network-ip-fixed.html)把打印机 IP 固定下来。
- 老打印机没有 AirPrint → 去厂商官网下 macOS 驱动；厂商已停止支持的老型号考虑换机。
- 公司打印机走打印服务器 → 找 IT 拿 Mac 版打印配置（多数需要装服务器证书与专用队列）。

## 预防

- 在路由器里给打印机固定 IP（DHCP 静态分配），IP 一变就是一次「离线」——见[「打印机固定 IP」](./printer-network-ip-fixed.html)。
- 打印机固件和 macOS 保持更新，AirPrint 兼容性靠两边一起维护。
- 别把打印机接进访客 Wi-Fi——隔离网络是「搜不到打印机」的头号原因。
