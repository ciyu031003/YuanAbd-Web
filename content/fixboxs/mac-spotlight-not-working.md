# Mac 聚焦搜索搜不到文件 / Spotlight 不工作怎么修

> 本文会检查聚焦索引并可能重建索引。重建不会删除文件，但完成后一段时间内 Mac 可能更费电、更热，这是系统重新扫描磁盘的正常现象。

## 一句话结论

Spotlight 搜不到东西，先分清是快捷键失效、某个磁盘没有索引，还是索引数据库损坏。快捷键失效在键盘设置里修；只有某些文件搜不到，检查“聚焦隐私”和结果分类；所有内容都搜不到，再用 `mdutil` 重建索引。

## 30 秒快速排查

1. 点屏幕右上角菜单栏的放大镜，输入一个应用名。**菜单栏能搜到、快捷键没反应**，问题在快捷键冲突。
2. 找到文件原来所在文件夹，用访达右上角搜索框搜一次。**访达能搜到、聚焦搜不到**，更像索引问题。
3. 重启 Mac 后再试。刚更新系统、刚迁移数据或外接硬盘刚接入时，聚焦需要时间重新扫描。

## 适用 / 不适用

**适用：**
- `Command+Space` 无法打开聚焦，或输入后一直没有结果
- 应用能搜到，但文档、图片、邮件搜不到
- 外接硬盘中的文件完全不在结果里
- 系统更新或迁移助理完成后，聚焦长期只转圈

**不适用：**
- 文件已经被删除 → 聚焦不是恢复工具，先看数据恢复
- 只有访达某个网络卷挂载失败 → 先修网络和共享连接
- 整台 Mac 卡顿、鼠标转圈 → 先处理性能或磁盘空间
- 公司 Mac 由 MDM 禁用 Spotlight → 联系组织管理员

## 开始前确认

- [ ] 确认文件确实存在，并且不是只在 iCloud 云端、尚未下载到本机
- [ ] 接上电源，避免重建索引时 Mac 休眠
- [ ] 知道管理员密码，`sudo` 命令需要
- [ ] 记录是“所有磁盘”还是“某个外接卷”搜不到

## 分步骤

### 步骤 1：先确认快捷键和菜单栏搜索

**目的**：快捷键被输入法、截图工具占用时，聚焦本身可能完全正常。

**操作**：
1. 点菜单栏右上角放大镜，测试应用和文件名。
2. 打开系统设置 → 键盘 → 键盘快捷键 → 聚焦。
3. 确认“显示聚焦搜索”已勾选，并把快捷键改为未被其他软件占用的组合。
4. 退出最近安装的启动器、剪贴板工具和快捷键工具后再试。

**预期结果**：`Command+Space` 能稳定打开聚焦，菜单栏搜索也有结果。

**失败怎么办**：菜单栏也没有结果 → 继续索引排查；快捷键可打开但没有结果 → 跳到步骤 3。

### 步骤 2：检查聚焦结果分类与隐私排除

**目的**：某一类结果被关闭，或磁盘被列进隐私列表，文件存在也不会被收录。

**操作**：
1. 打开系统设置 → Siri 与聚焦（旧版 macOS 为“聚焦”）。
2. 在搜索结果分类里确认“应用程序”“文稿”“文件夹”等需要的类别已勾选。
3. 滚动到底部打开“聚焦隐私”。
4. 如果整块磁盘被误加入，选中后点 `-` 移除；若要强制重新收录，可先把磁盘拖入再移除。

**预期结果**：系统磁盘不在隐私排除列表，常用结果类别已启用。

**失败怎么办**：退出聚焦隐私后仍无结果 → 继续步骤 3 查看索引状态。

### 步骤 3：查看索引是否启用

**目的**：`mdutil` 会直接显示每个卷的索引状态，避免盲目重建。

**操作**：
1. 打开“终端”。
2. 输入以下命令并按回车：

```bash
mdutil -s /
```

3. 正常状态应显示 `/:\n\tIndexing enabled.`。
4. 外接硬盘可用 `ls /Volumes` 看卷名，再运行 `mdutil -s "/Volumes/磁盘名称"`。

**预期结果**：系统和目标磁盘都显示索引已启用。

**失败怎么办**：显示 `Indexing disabled` → 运行 `sudo mdutil -i on /`；没有管理员权限时联系设备管理员。

### 步骤 4：重建系统磁盘索引

**目的**：索引数据库损坏时，删除并从文件重新生成是标准修复方式。

**操作**：
1. 在终端运行：

```bash
sudo mdutil -E /
```

2. 输入管理员密码。输入时终端不显示星号，这是正常现象。
3. 保持 Mac 接电，等待数分钟到数小时。文件越多，重建越久。
4. 可以正常使用 Mac，但不要连续重复执行重建命令。

**预期结果**：命令提示索引正在重建，之后 `mdutil -s /` 仍显示启用。

**失败怎么办**：报 `Error: unable to perform operation` → 先重启再试；磁盘空间不足或磁盘检查异常 → 先备份并处理磁盘。

### 步骤 5：检查 iCloud、外接盘和磁盘空间

**目的**：未下载到本机的云端文件、未挂载的外接盘和几乎写满的磁盘都不会正常出现在结果里。

**操作**：
1. 在访达中进入 iCloud Drive，找到文件并确认已下载到本机。
2. 打开访达侧边栏确认外接盘已经挂载，不要只检查桌面图标。
3. 打开系统设置 → 通用 → 储存空间，确认至少还有 10%-15% 可用空间。
4. 外接盘索引重建可用：`sudo mdutil -E "/Volumes/磁盘名称"`。

**预期结果**：目标文件所在磁盘已挂载、有足够空间，索引能够完成。

**失败怎么办**：iCloud 文件始终不下载 → 检查网络与 Apple 账户；外接盘反复掉线 → 先备份并检查线材/硬盘健康。

### 步骤 6：安全模式确认第三方软件干扰

**目的**：某些清理、同步或安全软件会阻止索引读取文件。

**操作**：
1. Apple 芯片 Mac：关机后长按电源键，出现“正在载入启动选项”后选启动磁盘并按住 `Shift` 进入安全模式。
2. Intel Mac：开机时按住 `Shift`，直到看到登录窗口。
3. 在安全模式中测试聚焦能否打开并返回结果。
4. 正常重启，退出第三方清理、同步和安全软件后再测试。

**预期结果**：安全模式正常，说明登录项或第三方软件干扰；两种模式都不正常，更像系统索引或磁盘问题。

**失败怎么办**：不确定安全模式操作 → 先备份；仍无结果可更新 macOS，或在完整备份后联系 Apple 支持。

## 怎么确认修好了

菜单栏和 `Command+Space` 都能打开聚焦；分别搜索一个应用、一个文档和一张图片都有结果；重启 Mac 后仍正常。刚重建完只搜到部分文件是正常的，等待索引完成再判断。

## 还是不行？

- 访达整体卡死、窗口无响应 → [Mac Finder 卡死 / 转圈怎么修](./mac-finder-unresponsive.html)
- 磁盘几乎写满、系统数据异常 → [Mac 储存空间不足](./mac-storage-system-data.html)
- 文件实际不存在或刚被删除 → 重点转为备份与数据恢复
- 外接盘不显示 → 换线换口，先确认磁盘是否挂载
- 公司 Mac 设置被统一管理 → 联系 IT，不要绕过 MDM 策略

## 预防

1. 系统更新和迁移完成后先接电等待索引跑完。
2. 不要把整块系统盘误加进“聚焦隐私”。
3. 保留足够储存空间，避免索引数据库不断失败。
4. 少装需要读取全部文件的来源不明清理工具。
