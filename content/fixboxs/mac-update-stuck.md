# macOS 更新卡住：下载不动 / 安装进度条不动怎么办

> ⚠ 需谨慎：**正在安装（屏幕黑底白字、带进度条）时最忌强制断电**——半途打断可能损坏系统分区。只有「确认真卡死」（见步骤 3 的判断标准）才允许长按电源键关机。恢复模式「重新安装 macOS」不会删除个人文件，但操作前有 Time Machine 备份永远更稳。

## 一句话结论

macOS 更新分三个阶段，**卡的位置不同，解法完全不同**：下载卡住查网络和储存空间；安装进度条不动先耐心等（大版本 1-2 小时属正常）；重启后卡在苹果标志才是真出事——长按电源键关机、进恢复模式修磁盘或重装。

## 30 秒快速排查

1. **现在卡在哪？** 下载/准备中（软件更新界面转圈）→ 步骤 2；安装进度条（已重启、黑底白字）→ 步骤 3；重启后卡在苹果标志/进度条进不了桌面 → 步骤 4。
2. **下载卡住**：检查 Wi-Fi 是否正常（别的设备能上网）、Mac 储存空间是否 ≥25 GB（系统设置 → 通用 → 储存空间）。**期望结果**：网络正常、空间够，暂停后重新下载。
3. **进度条不动**：看时间——大版本更新等 60-90 分钟很常见，期间屏幕可能多次黑屏重启。**期望结果**：等完自动进桌面。
**失败了怎么办**：等超过 2 小时进度条纹丝不动、或风扇狂转后完全静止 → 判定真卡死，进步骤 4。

## 适用 / 不适用

**适用**

- 软件更新界面下载百分比长时间不动。
- 安装时进度条在同一位置停留超过 2 小时。
- 更新重启后卡在苹果标志或满进度条，进不了桌面。
- 更新中途报错（如「安装 macOS 出错」）。

**不适用**

- 更新完成后某功能异常（如 Wi-Fi 断连）→ 看[「Mac 的 Wi-Fi 反复断连」](./mac-wifi-keeps-dropping.html)。
- 更新后提示密码错误 → 看[「Mac 忘记开机密码」](./mac-forgot-password.html)。
- 更新后储存空间异常变大 → 看[「Mac 储存空间被系统数据占满」](./mac-storage-system-data.html)。
- 公司 MDM 管理的 Mac → 更新由 IT 统一推送，不要自行恢复模式重装。

## 开始前确认

- [ ] **有 Time Machine 备份**（没有的话，如果 Mac 还能进系统，先插外接硬盘备份再折腾——见[「Time Machine 备份失败/恢复」](./mac-time-machine-troubleshoot.html)）。
- [ ] 充电器已插上（全程不许断电）。
- [ ] 记住 Wi-Fi 密码（恢复模式联网要用）。
- [ ] 知道机型年份（恢复模式按键不同：Apple Silicon 长按电源键；Intel 开机按 Command+R）。

## 分步骤

### 步骤 1：下载阶段卡住——查网络与空间

1. 确认 Wi-Fi 正常：打开个网页试试；公司/校园网常限速大流量下载，换手机热点试（注意流量）。
2. 检查储存空间：系统设置 → 通用 → 储存空间，留出 25 GB 以上。
3. 软件更新里点小「ⓘ」，若卡住超过 30 分钟，重启 Mac 再进「软件更新」重新下载。
**期望结果**：下载继续并完成。**失败了怎么办**：反复卡在同一点 → 跳过系统内下载，直接从 App Store 搜「macOS <版本名>」下载完整安装器（见[如何下载和安装 macOS](https://support.apple.com/zh-cn/102662)），或换网络环境。

### 步骤 2：确认这是「慢」而不是「卡」

1. 大版本更新（如 14→15）安装 1-2 小时、期间黑屏重启数次，都是正常流程。
2. 观察进度条与硬盘灯/风扇：进度条在极慢挪动、或风扇间歇转 → 系统还在干活，继续等。
3. 什么都不动且屏幕完全静止超过 2 小时 → 判定卡死，进步骤 3。
**期望结果**：等来了重启进桌面的「设置助手」。**失败了怎么办**：确认卡死 → 步骤 3。

### 步骤 3：真卡死的处理——强制关机再开机

1. 长按电源键 **最长 10 秒**，直到 Mac 熄屏关机（Apple 官方做法）。
2. 等 10 秒，按电源键正常开机。
**期望结果**：这次能继续完成安装或正常进桌面。**失败了怎么办**：又卡在苹果标志/进度条 → 步骤 4，进恢复模式。

### 步骤 4：恢复模式修磁盘 + 重装

1. 进恢复模式：Apple Silicon——关机后长按电源键到「载入启动选项」，点「选项」→「继续」；Intel——开机立即按住 Command+R。
2. 选择 Wi-Fi 并连接网络。
3. 打开「磁盘工具」→ 选「Macintosh HD」→ 点「急救」，跑完再对整个容器跑一次。
4. 退出磁盘工具 → 选「重新安装 macOS」→ 按提示装到原磁盘。**这一步不会删除你的个人文件**，只是把系统文件重铺一遍。
5. 安装完成重启，可能需要 30 分钟以上。
**期望结果**：重装完成，正常进桌面，文件都在。**失败了怎么办**：磁盘工具报错无法修复、或重装反复失败 → 用 Time Machine 恢复（恢复模式主界面 →「从时间机器恢复」），仍不行联系 Apple 支持/天才吧。

### 步骤 5：验证系统状态

1. 进桌面后再看一次「软件更新」，确认没有再弹同一个版本。
2. 磁盘工具再跑一次「急救」确认无错。
**期望结果**：更新完成且系统自检干净。**失败了怎么办**：同一版本反复失败 → 到 Apple 官网查该版本与你的机型是否兼容，或等下一个补丁版本再更。

## 怎么确认修好了

- 「系统设置 → 通用 → 软件更新」显示「macOS 已是最新版本」。
- 重启一次，直接进桌面，不再卡苹果标志。
- 个人文件、应用都在，Wi-Fi 与声音正常。

## 还是不行？

- 恢复模式里看不到磁盘 / 急救无法修复 → 磁盘可能已物理或深层损坏，立即停止尝试、送修（数据恢复优先级高于修复系统）。
- Intel 机型反复失败 → 顺便重置一次 SMC 与 NVRAM（官方文档按机型操作）再试。
- 每次更新都卡在同一进度 → 记下机型与目标版本，到 Apple 社区搜同机型案例，或等 Apple 撤回/重发该版本。

## 预防

- 大版本更新前跑一次 Time Machine；等发布后 1-2 周再更，让第一批用户替你踩坑。
- 更新前清理储存空间到 ≥30 GB。
- 更新全程插电源，笔记本合盖别让系统睡眠打断下载。
