# 显示器无信号 / 分辨率不对 / 外接屏不亮

> ℹ️ 本文只做连接与显示设置的排查，不涉及拆机、不涉及重装系统，操作可随时还原，属于安全操作。

## 一句话结论

八成是**显示器的输入源选错了**（线插在 HDMI1，显示器却停在 HDMI2/USB-C），或者线材/接口接触不良；先按显示器上的 Source/Input 键切换到正确输入源，再换线换口交叉验证。

## 30 秒快速排查

1. 按显示器边框上的 **Source / Input / 信号源** 键，逐个切一遍输入源，每个停留 3-5 秒。**期望结果**：切到正确那一路时画面出现。
2. 把显示线**拔下来重插**，并换电脑上另一个视频接口（比如从主板的 HDMI 换到显卡的 DP，或反之）。**期望结果**：画面恢复，说明是接触或接口问题。
3. Windows 上按 `Win + P`，选择"**复制**"或"**扩展**"。**期望结果**：如果之前被设成了"仅电脑屏幕"，外接屏这时会亮。

## 适用 / 不适用

**适用**

- 显示器亮电源灯但显示"No Signal""无信号""检查信号线"。
- 笔记本接外接屏不亮、投影到电视没反应。
- 分辨率突然变得很大/很小、字发虚、屏幕显示"超出范围(Out of Range)"。
- 换过电脑或换过显示器之后出现的画面异常。

**不适用**

- 笔记本**自带屏幕**完全没画面、开机只有风扇转：看[「电脑开机没反应 / 主机亮灯但显示器没信号」](./psu-no-power-check.html)。
- 画面能显示但花屏、有彩色条纹、不定时闪：看[「电脑花屏 / 显示器闪屏，显卡还是线的问题」](./monitor-no-signal.html)。
- 是打印机之类的设备连不上：看[「打印机显示脱机 / 打印没反应怎么修」](./printer-offline.html)。

## 开始前确认

- [ ] 显示器**电源线**已插紧，电源灯亮着（有通电反应）。
- [ ] 电脑主机已开机（听风扇声、看主机电源灯），不是"没开机自然没信号"。
- [ ] 手上有一根**已知良好**的显示线（HDMI/DP/Type-C）可以替换测试。
- [ ] 笔记本用户确认已按 `Win + P` 或 Mac 的"侦测显示器"，不是被设成"仅电脑屏幕"。
- [ ] 如果有独显，分清楚线插在**主板接口**还是**显卡接口**（台式机两者不能混用）。

## 分步骤

### 步骤 1：先确认电脑到底开机了没有

**目的**：很多人以为"显示器无信号 = 显示器坏了"，实际是主机没启动。

**操作**：

1. 看主机电源灯是否常亮、风扇是否在转、键盘的 Num Lock/Caps Lock 灯按一下会不会亮。
2. 如果键盘灯按了不亮、风扇转但没有任何反应，说明主机本身没完成启动。

**预期结果**：确认主机是正常开机运行状态，还是根本没起来。

**失败怎么办**：主机没启动，别在显示器上找原因——看[「电脑开机没反应 / 主机亮灯但显示器没信号」](./psu-no-power-check.html)。

### 步骤 2：切换显示器输入源

**目的**：这是"无信号"里出现频率最高的原因。

**操作**：用显示器边框上的物理按键（或摇杆/触摸键）打开 OSD 菜单，找到 **Input / Source / 信号源**，列出 HDMI1、HDMI2、DisplayPort、USB-C、VGA 等选项，逐个切换，每个停留几秒。同时看清显示器上标注的接口编号，和线实际插的口对应。

**预期结果**：切到线所插的那一路时，画面立刻出现。

**失败怎么办**：切了一圈都没画面，记下每个输入源提示的文字（有的会显示"未检测到信号"），进入步骤 3。

### 步骤 3：换线、换口、换设备交叉验证

**目的**：用替换法把"线 / 接口 / 显示器 / 电脑"四个嫌疑对象逐个排除。

**操作**：按下表的顺序试，每次只改一个变量：

| 测试 | 做法 | 结果说明 |
|---|---|---|
| 换线 | 用另一根 HDMI/DP 线 | 好了 = 原线坏了 |
| 换接口 | 换到电脑上另一个视频接口 | 好了 = 原接口/接口通道问题 |
| 换显示器 | 接到电视或另一台显示器上 | 好了 = 原显示器问题 |
| 换主机 | 显示器接到另一台电脑上 | 好了 = 原电脑显卡/输出问题 |

**预期结果**：能锁定到底哪个环节坏了。

**失败怎么办**：全都试过还是无信号，且主机能正常启动，进入步骤 4、5 检查系统侧设置。

### 步骤 4：检查系统显示设置（Windows）

**目的**：系统可能把外接屏设成了"断开"，或者选了显示器不支持的分辨率。

**操作**：

1. 按 `Win + P`，选"**复制**"或"**扩展**"。
2. 桌面右键 → **显示设置**，在顶部"选择要查看或更改设置的显示器"里点"**检测**"；能看到 1 号和 2 号显示器就说明系统认到了。
3. 点 2 号显示器 → **显示分辨率**，选带"（推荐）"的那个值。
4. 点"**高级显示设置**" → 确认**刷新率**也是推荐值（常见 60Hz，高刷屏选显示器支持的档位）。
5. 多屏排列错乱时，在显示设置顶部拖动 1、2 号方框，让排列与桌面物理位置一致，并勾选"设为主显示器"。

**预期结果**：设置里能看到两块显示器，画面正常、字清晰。

**失败怎么办**：设置完黑屏但有倒计时→什么都不做等 15 秒会自动回滚；"检测"点不动且系统完全认不到外接屏，回到步骤 3 检查线材和显卡驱动，或更新显卡驱动后重试。

### 步骤 5：检查系统显示设置（macOS）

**目的**：Mac 的检测入口与 Windows 不同。

**操作**：

1. **系统设置 → 显示器**，按住 `Option` 键，右下角会出现"**检测显示器**"按钮，点它。
2. 在弹出的显示器窗口里设置分辨率（选"默认"或"更多空间/更大文字"），外接屏建议先用"默认"。
3. 排列设置里可以拖动两块屏的相对位置，并把菜单栏拖到主屏。
4. 如果是通过扩展坞/转接头连接，先**直连**测试一次。

**预期结果**：外接屏出现画面，分辨率可选、刷新率可选。

**失败怎么办**：Mac 上完全检测不到，检查线材与转接头是否支持该分辨率与刷新率（4K@60Hz 需要 DP1.2/HDMI2.0 以上规格），必要时重启 Mac 并把外接屏**先开电源再连电脑**（以 Apple 支持文档为准）。

### 步骤 6：处理 Type-C / 扩展坞导致的供电与带宽问题

**目的**：Type-C 一线连既传视频又供电，供电不足或转接芯片带宽不够都会变成"无信号"。

**操作**：

1. 确认转接头/扩展坞支持**视频输出（DP Alt Mode）**，不是纯充电/纯 USB 数据的头子。
2. 需要外接供电的扩展坞，把它的电源适配器接上。
3. 能直连就直连：把显示线直接插到电脑的视频输出口上，绕开扩展坞测试。
4. 4K 高刷屏信号不稳时，把刷新率降到 60Hz、分辨率降到 2560×1440 试一次，判断是不是带宽不够。

**预期结果**：绕开扩展坞后信号正常，或接上供电后恢复。

**失败怎么办**：直连也不行，说明是电脑输出口或显示器接口问题，按步骤 3 的表格继续替换验证；扩展坞本身故障就换一个（选购时确认支持的视频规格）。

### 步骤 7：处理"分辨率不对 / 字发虚 / 超出范围"

**目的**：这类问题多是用错分辨率或刷新率，或接了不支持该模式的显示器。

**操作**：

1. 分辨率：设成"推荐"值。显示器原生分辨率才是清晰的（例如 2560×1440 的屏就设 2560×1440）。
2. 刷新率：在"高级显示设置"里选显示器支持的档位；屏幕显示"**超出范围 / Out of Range**"时，通常需要进**安全模式**把分辨率/刷新率降回保守值（如 1920×1080 @60Hz）。
3. 台式机插在主板的 HDMI 上、用的是核显，而游戏/绘图需要独显：把线改插到**显卡**的接口上。
4. 显卡驱动异常也会导致分辨率选项缺失：到**显卡厂商官网**（NVIDIA/AMD/Intel）下载对应驱动更新。

**预期结果**：字迹锐利、比例正常、可选分辨率里出现原生分辨率。

**失败怎么办**：安全模式下也不给调，重装显卡驱动后再设置；"超出范围"发生在**进入系统之前**（BIOS 画面就出现），则需要在开机时进安全模式或低分辨率模式调整（不同品牌进入方法**以电脑厂商官网说明为准**）。

### 步骤 8：收尾确认与固定设置

**目的**：让配置在多屏之间不再"自己变来变去"。

**操作**：把显示设置调好后，拔插一次线、重启一次电脑，确认配置仍生效；多屏用户把主显示器固定好并记住 `Win + P` 的常用模式。

**预期结果**：重启/拔插后仍保持正确配置。

**失败怎么办**：配置总是丢失，检查是不是用了切换器（KVM）、延长线或不同协议的转接头，改用直连；仍反复丢失就走步骤 7 的驱动更新。

## 怎么确认修好了

显示器在**不按任何按键、不改任何设置**的情况下，冷启动电脑后 30 秒内自动出现正常画面；分辨率是原生推荐值；多屏场景下两块屏都亮且排列与物理位置一致；拔插一次线后画面能自动恢复。

## 还是不行？

- **画面能显示但花屏、有条纹、间歇闪黑** → 看[「电脑花屏 / 显示器闪屏，显卡还是线的问题」](./monitor-no-signal.html)。
- **主机开机没反应、显示器从头到尾没亮过** → 看[「电脑开机没反应 / 主机亮灯但显示器没信号」](./psu-no-power-check.html)。
- **笔记本外接屏不亮，但自带屏幕正常，且换线换屏都试过** → 可能是笔记本的视频输出口或显卡故障，按电脑厂商官网的保修流程报修。
- **显示器在所有电脑上都不亮、屏上一直没有信号提示，或面板有物理损伤** → 显示器硬件故障，联系**显示器厂商售后或送修**；公司设备**请联系 IT**。

## 预防

1. 显示线不要长期折死弯，尤其是 HDMI/DP 接头根部，这是最常见的断线位置。
2. 拔插显示线时先握住接头外壳再拔，别拽线身。
3. 记住自己电脑哪个口接哪块屏，换位置时对照显示器上的接口编号。
4. 更新显卡驱动只从 NVIDIA/AMD/Intel 官网或电脑厂商官网下载。
5. Type-C 一线连场景使用带供电的扩展坞，并保留一根直连线作为备份。
