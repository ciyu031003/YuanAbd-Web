# 硬盘怎么分区 / C 盘不够想扩容怎么办

> ⛔ 有数据风险：**调整分区前必须先完成完整备份**。压缩卷、扩展卷、合并分区都会移动分区表与文件数据，中途断电、强制关机或工具崩溃都可能让整个磁盘「未初始化」。没有备份就不要动手——这是分区操作唯一的铁律。

## 一句话结论

C 盘扩容的本质是「**把相邻右侧分区的空地挪给 C 盘**」：先用压缩卷在 D 盘头部挤出一块「未分配空间」，再对 C 盘做扩展卷。系统自带的磁盘管理就能做；但**相邻**和**未分配在右侧**这两个条件缺一不可，不满足时用 DiskGenius 这类工具无损调整。

## 30 秒快速排查

1. 先确认真的需要扩容：C 盘爆红很多时候是缓存/休眠文件撑的，清理一下能再战半年，看[「C 盘爆红快满了，怎么安全清理出空间」](./win-c-drive-full-cleanup.html)。**期望结果**：先排除「假性不足」。
2. `Win + X` → 磁盘管理，看磁盘布局：C 盘右边紧邻的是什么分区、有没有未分配空间。**期望结果**：心里有分区地图，别上来就点压缩。
3. 插上移动硬盘做备份，再开始任何分区操作。**期望结果**：备份完成且抽查可读。

## 适用 / 不适用

**适用**

- C 盘和 D 盘在同一块物理硬盘上，想从 D 盘匀空间给 C 盘。
- 新装了一块硬盘，想分成 1-2 个区使用。
- 想把用不到的 E/F 盘合并掉、重新规划。

**不适用**

- C 盘是独立小容量系统盘 + 数据在另一块盘：扩不了，建议迁移数据或换盘。
- 双系统电脑（Linux/黑苹果共存）：分区工具会动引导，**不要**按本文操作，先查对应系统文档。
- 磁盘管理里磁盘显示「未知/未初始化/脱机」：先解决识别问题，参考[「U 盘 / 移动硬盘不识别、提示格式化怎么办」](./usb-drive-not-recognized.html)。

## 开始前确认

- [ ] 移动硬盘备份完成，抽查 5 个文件能打开（看[「换硬盘 / 重装系统前，怎么把数据备份全」](./backup-before-repair.html)）。
- [ ] 笔记本插着电源，台式机避开雷雨/电压不稳时段。
- [ ] 磁盘管理里确认 C 盘所在物理盘的布局（截图留底）。
- [ ] 关掉杀毒软件的全盘扫描、暂停 OneDrive/网盘同步（减少分区期间的写入）。
- [ ] 想清楚目标布局再动手：画个草图，标出每个区调整后的大小。

## 分步骤

### 步骤 1：读懂磁盘管理里的布局

1. `Win + X` → 「磁盘管理」。上半部分是卷列表，下半部分是**物理磁盘图形视图**。
2. 找到 C 盘所在那一条横条：从左到右依次是「恢复分区 | EFI | C: | …… | D:」之类的排布。
3. 记住三个关键事实：C 盘右侧紧邻的是什么；那块盘还有没有「未分配」黑块；磁盘是 MBR 还是 GPT（右键磁盘名 → 属性 → 卷）。
**期望结果**：能对着图形视图说出自己的布局。**失败了怎么办**：磁盘管理打不开或显示不全 → 用管理员身份重开；仍异常先修系统再分区。

### 步骤 2：从 D 盘压缩出「未分配空间」

1. 右键 D 盘 → 「压缩卷」→ 输入要让出的容量（MB）→ 压缩。
2. 压缩后 D 盘左侧（或右侧）出现黑色「未分配」。
**期望结果**：未分配空间出现，D 盘数据原样保留。**失败了怎么办**：可压缩空间远小于预期 → 是 D 盘里有「不可移动文件」（页面文件、系统还原点），先把系统还原关掉、重启再压；实在不行用 DiskGenius 调整。

### 步骤 3：把未分配空间并入 C 盘

1. 未分配空间**紧贴在 C 盘右侧**时：右键 C 盘 → 「扩展卷」→ 下一步走完。
2. 未分配空间在别的位置（比如 D 盘右侧）：磁盘管理的扩展卷会灰色——此时需要 DiskGenius 这类工具把 D 盘「向右挪」，让空地贴到 C 盘旁边，再扩展。挪动大分区可能要几十分钟，**期间绝对不能断电**。
**期望结果**：C 盘容量变大，D 盘变小且数据完好。**失败了怎么办**：扩展卷灰色且不想装第三方工具 → 备份 D 盘数据 → 删除 D 盘 → 扩展 C 盘 → 在剩余空间重建 D 盘并把数据拷回（这是最稳的人工路线）。

### 步骤 4：新硬盘分区（可选场景）

1. 新盘在磁盘管理里显示「未分配」：右键 → 「新建简单卷」→ 按向导指定大小、盘符、NTFS 文件系统。
2. 想分两个区：先建第一个（指定小于总容量的空间），再对剩余未分配空间重复一次。
3. 1TB 盘的常见分法：系统/软件区 300-500G + 数据区，或者干脆**整盘一个区**——有备份习惯的话单区更省心。
**期望结果**：新盘出现可用盘符。**失败了怎么办**：「新建简单卷」灰色 → 盘是 MBR 且已到 4 个主分区上限，或盘是 3TB 以上 MBR（认不全），改用 GPT（右键磁盘 → 转换为 GPT，需要先删掉全部分卷，是破坏性操作）。

### 步骤 5：收尾检查

1. 打开「此电脑」，确认各盘容量、盘符符合预期，抽查文件都能打开。
2. 若动过系统盘，重启一次确认能正常进系统。
3. 把分区布局截图存档，方便下次维护。
**期望结果**：系统正常、数据完好、布局清晰。**失败了怎么办**：重启进不去系统 → 别再乱点，用 PE 启动盘修复引导或找专业人员，数据优先。

## 怎么确认修好了

- C 盘剩余空间回到健康线（≥15% 总容量），此电脑里显示正确。
- D 盘/新分区数据完整，抽查可读。
- 连续重启 2 次、跑半小时高负载，无异常。

## 还是不行？

- 压缩卷/扩展卷持续灰色 → 用 DiskGenius 无损调整；仍然失败说明分区表有异常，备份数据后重建分区。
- 分区操作中断电/崩溃后磁盘消失 → 别初始化、别格式化，带着盘找数据恢复机构。
- 系统盘是 128G 及以下的小盘 → 扩容意义有限，直接换大 SSD 是更划算的解法，换盘流程看[「换硬盘 / 重装系统前，怎么把数据备份全」](./backup-before-repair.html)。

## 预防

- 装软件默认路径改到非 C 盘，新盘到手先规划好再塞数据。
- 每季度看一眼各盘剩余空间，别等爆红才动。
- 分区宁少勿多：每多一个区，就把同样大的空间切得更碎、更难调整。
