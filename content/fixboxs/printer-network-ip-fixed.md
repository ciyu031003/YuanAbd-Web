# 网络打印机 IP 变了就离线？固定 IP 与端口配置

> ℹ️ 本教程只做「给打印机一个固定身份 + 电脑指向正确端口」，全部可逆。改打印机 IP 前记下当前 IP 和网段（拍照即可），配置错了随时能改回来。

## 一句话结论

网络打印机「过一阵就离线」的经典剧本：打印机靠 **DHCP 自动拿 IP**，路由器重启或租约到期后 IP 变了，而电脑上的打印机端口还指着旧 IP——自然连不上。解法两选一：**路由器端做 DHCP 保留（MAC 绑定，推荐）**或**打印机端手动设静态 IP**；IP 稳定之后，电脑端把打印机端口指到这个固定 IP，一劳永逸。

## 30 秒快速排查

1. 打一张「网络配置页」（打印机控制面板：设置 → 报告 → 网络配置，或按住进纸键几秒），上面有当前 IP 与 MAC 地址。**期望结果**：拿到 IP（如 192.168.1.108）和 MAC（形如 AA:BB:CC:DD:EE:FF）——本文的主角。
2. 电脑上 ping 一下这个 IP：`ping 192.168.1.108`。**期望结果**：通 → 打印机活着，是电脑端口指向错 IP；不通 → 打印机断网/换网段，重新连网。
3. 对照你电脑自己的 IP（`ipconfig` / `ifconfig`）与打印机是否同网段（前三段一致）。**期望结果**：一致；不一致（如打印机 192.168.0.x、电脑 192.168.1.x）→ 打印机连到了别的 Wi-Fi/网段。

## 适用 / 不适用

**适用**

- 网线/Wi-Fi 直连路由器的打印机，隔三差五显示「离线」。
- 路由器换过/重启过后打印机集体失联。
- 新添网络打印机，想一次配好不再掉。

**不适用**

- 打印机插在某台电脑上「共享」出来的：看[「共享打印机连不上 / 报错 0x0000011b 怎么修」](./printer-shared-error-11b.html)。
- 打印机完全不响应任何操作（面板黑屏）：先修硬件。
- USB 直连的单机打印问题：看[「打印机显示脱机 / 打印没反应怎么修」](./printer-offline.html)。

## 开始前确认

- [ ] 打印机支持网络（面板有 Wi-Fi 图标或机身有网口）。
- [ ] 手头有打印机的网络配置页（IP + MAC 都在上面）。
- [ ] 能登录路由器后台（不知道怎么进看[「路由器后台打不开怎么办」](./router-admin-page-unreachable.html)）。
- [ ] 想好给打印机的固定 IP（建议选网段里靠后的地址，如 192.168.1.200，避开自动分配范围）。

## 分步骤

### 步骤 1：拿到打印机的 IP 与 MAC

1. 控制面板打「网络配置页」（各品牌路径：HP 设置→报告；爱普生按住网络键；兄弟菜单→网络→报告）。
2. 记下 IPv4 地址、子网掩码、网关、**MAC 地址（硬件地址）**四个值。
3. Wi-Fi 机型顺便确认连接的 SSID 是主路由的（不是访客网络——访客网络常开 AP 隔离，与电脑不通）。
**期望结果**：四个值在手。**失败了怎么办**：面板上找不到 → 在机身网口贴纸或菜单「关于/序列号」页找 MAC；IP 用路由器后台「已连接设备」里按厂商名（HP/Epson/Brother/Canon）辨认。

### 步骤 2：路由器端 DHCP 保留（推荐，不动打印机）

1. 登录路由器后台（如 192.168.1.1 / 192.168.31.1），找「DHCP 静态 IP 分配 / 地址保留 / MAC 绑定」（华为路由在「更多功能 → 网络设置 → DHCP 静态 IP 分配」）。
2. 添加条目：MAC 填打印机的，IP 填你选定的固定地址（就用它当前占用的 IP 最省事）。
3. 保存后重启打印机（或在后台对它重新下发租约）。
**期望结果**：打印机重启后 IP 与绑定值一致。**失败了怎么办**：路由器没这功能 → 步骤 3 在打印机端设。

### 步骤 3：打印机端手动设静态 IP（备选）

1. 浏览器打开打印机当前 IP（如 `http://192.168.1.108`）进它的 Web 管理页（EpsonNet / HP EWS / Brother Web 管理），或用厂商配置工具（爱普生 EpsonNet Config）。
2. 网络/TCP/IP 设置：由「自动（DHCP）」改为「**手动**」，照抄当前 IP/掩码/网关（用当前值最稳，别发明新地址——除非确认避开 DHCP 池）。
3. 保存重启打印机，再打一张网络配置页核对。
**期望结果**：IP 固定不再漂移。**失败了怎么办**：改完 ping 不通 → 手滑改错网关，用 USB 线连电脑或面板恢复网络默认重来。

### 步骤 4：电脑端把端口指向固定 IP

1. Windows：设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 你的打印机 → 属性 → 「端口」选项卡。
2. 看现有端口类型：
   - 已是 **Standard TCP/IP Port**：点「配置端口」→ 打印机名/IP 字段填固定 IP → 确定。
   - 是 WSD/mDNS 类端口（名字很长带一串字母）：删除打印机，按步骤 5 用 TCP/IP 方式重加（WSD 端口正是「时灵时不灵」的根源）。
3. macOS：系统设置 → 打印机与扫描仪 → 删掉旧条目 → 重新添加，选中 IP 一栏出现的那台（或手动按 IP 添加，协议 IPP）。
**期望结果**：端口牢牢指向固定 IP。**失败了怎么办**：端口灰色改不了 → 用管理员身份打开「设备和打印机」再试。

### 步骤 5：按 TCP/IP 方式重新添加（一次到位）

1. Windows 添加打印机 → 「我需要的打印机不在列表中」→「使用 TCP/IP 地址或主机名添加」。
2. 类型选「自动检测」，地址填固定 IP → 下一步装驱动（型号驱动官网下）。
3. 打印测试页，成功后把旧的 WSD 版打印机条目删除，避免同事点错。
**期望结果**：一台「IP 版」打印机，从此不掉线。**失败了怎么办**：向导检测失败 → 手动选设备类型「TCP/IP Device」、去掉「自动检测」勾再试。

## 怎么确认修好了

- 重启路由器和打印机各一次，打印测试页仍一次成功。
- 电脑上 ping 打印机固定 IP 稳定通。
- 连续两周无「离线」报告。

## 还是不行？

- 固定 IP 后反而 ping 不通 → IP 与网内其他设备冲突，换一个更冷门的地址（如 x.x.x.250）。
- Wi-Fi 打印机隔天掉一次网 → 打印机无线模块省电太激进：Web 管理页找「休眠/节能」设置调长或关闭；仍不行改网线直连（一劳永逸）。
- 换了新路由器全体失联 → 新网段与固定 IP 不符，按本文步骤 1-4 重配一遍。

## 预防

- 新打印机上线当天就做 DHCP 保留——「先能用再优化」的最后总是「某天集体离线」。
- 办公室网络改造/换路由器后，把「打印机 IP 检查」列入收尾清单。
- 团队里所有电脑统一用 TCP/IP 端口，禁用 WSD 添加。
