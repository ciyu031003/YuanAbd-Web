# 浏览器提示「代理服务器无响应」怎么修

> 📌 **合规提示**
> 本文只讲**本机代理设置的故障排查与恢复**：把被改乱、已失效的代理设置改回正常，让电脑重新能上网。
> 本文不涉及任何跨境访问方法，不提供、不推荐任何用于绕过网络管理措施的工具或配置。
> 请遵守《中华人民共和国网络安全法》及所在单位网络管理规定，仅对**你本人拥有或已获授权**的设备进行操作。设备由单位统一管理的，请先联系单位 IT。

> ⚠️ 本文会修改系统网络设置。动手前建议把当前的代理设置页**截图保存**（设置 → 网络和 Internet → 代理），改错了可以照原样填回去。

## 一句话结论

九成是**本机代理设置里留着一条已经失效的代理地址**（装过加速器、抓包工具或公司的代理脚本之后没清干净）；先到「设置 → 网络和 Internet → 代理」把开关关掉试一次，再清 WinHTTP 代理。

## 30 秒快速排查

1. 按 `Win + I` 打开设置 → **网络和 Internet → 代理**，把「使用代理服务器」和「自动检测设置」都关掉，回到浏览器刷新页面。**期望结果**：网页能打开，说明就是残留的代理设置。
2. 如果设置里本来就是关的，打开无痕/隐私窗口再试一次。**期望结果**：无痕能开、正常窗口不能开，是浏览器扩展在管代理（见步骤 5）。
3. 打开微信或 QQ 看能不能收发消息。**期望结果**：聊天软件正常、只有浏览器不行 = 浏览器侧问题；所有软件都不行 = 系统级代理或网络本身有问题。

## 适用 / 不适用

**适用**

- 浏览器报"代理服务器无响应""无法连接到代理服务器""ERR_PROXY_CONNECTION_FAILED"。
- 刚卸载过加速器、抓包工具、公司 VPN 客户端，之后浏览器就打不开网页。
- 昨天还好、今天突然上不了网，但你**没改过**任何网络设置。

**不适用**

- 只有某一个网站打不开，其他都正常：看[「只有某个网站打不开，其他都正常」](./dns-broken-but-app-works.html)。
- 网页打不开但 QQ / 微信能用：更可能是 DNS 问题，看[「网页打不开但 QQ / 微信能用：DNS 问题怎么修」](./dns-broken-but-app-works.html)。
- 公司电脑上代理设置是灰的、改不动：那是单位的管控策略，不要尝试绕过，看[「公司电脑改不了代理/网络设置，该怎么办」](./enterprise-proxy.html)。
- 装完加速器/抓包工具后**整台电脑**都断网了：看[「装了抓包/加速工具后全网断网怎么恢复」](./proxy-tool-broke-network.html)，那篇有完整的恢复顺序。

## 开始前确认

- [ ] 确认这台电脑是**你本人**的设备；公司/学校配发的设备请先联系 IT。
- [ ] 已连上 Wi-Fi 或网线，右下角网络图标不是"无 Internet"红叉。
- [ ] 有一台能正常上网的手机，可以随时对比"是不是只有电脑不行"。
- [ ] 记得自己**是否**配置过代理（公司代理、加速器、抓包工具、浏览器插件），这决定后面该保留还是清除。
- [ ] 如果单位要求必须走代理才能访问内网系统，请先向 IT 确认代理地址，**不要擅自删除**。

## 分步骤

### 步骤 1：先分清是"系统代理"还是"浏览器自己的代理"

**目的**：决定后面改哪里，避免白折腾。

**操作**：依次做两个测试：

1. 打开**另一个浏览器**（比如平时用 Edge，就试 Chrome 或系统自带的 Edge）访问同一个网站。
2. 用微信/QQ 发一条消息给自己。

| 测试结果 | 说明 | 往下看 |
|---|---|---|
| 两个浏览器都不行，但微信正常 | 系统级代理设置被改 | 步骤 2、3、4 |
| 只有一个浏览器不行，另一个正常 | 这个浏览器的扩展或设置问题 | 步骤 5 |
| 所有联网软件都不行 | 不只是代理问题 | 先看[「装了抓包/加速工具后全网断网怎么恢复」](./proxy-tool-broke-network.html) |

**预期结果**：能明确说出问题范围。

**失败怎么办**：手机连同一个 Wi-Fi 也上不了网，说明问题不在电脑上，先看[「家里所有设备都上不了网：先分清是谁的问题」](./home-network-all-offline.html)。

### 步骤 2：关闭 Windows 的系统代理

**目的**：清掉最表层、也最常见的一处残留。

**操作**：按 `Win + I` → **网络和 Internet → 代理**，把这几项都处理掉：

| 设置项 | 该怎么做 |
|---|---|
| 自动检测设置 | 关闭 |
| 使用设置脚本（PAC） | 关闭（除非公司明确要求） |
| 手动设置代理 → 使用代理服务器 | 关闭 |

关完按 `Win + R` 输入 `cmd`，执行下面这条刷新一下：

```bat
ipconfig /flushdns
```

**预期结果**：三项都是"关闭"状态，浏览器刷新后能正常打开网页。

**失败怎么办**：开关是灰的、点不动，说明被组策略或安全软件锁定了——公司设备**请联系 IT**；个人设备检查是不是装了带"上网保护"的安全软件，退出它再试。

### 步骤 3：检查 PAC 自动配置脚本地址是否失效

**目的**：PAC 脚本地址一旦失效，浏览器就会报代理错误。

**操作**：在步骤 2 的同一个页面，看"**使用设置脚本**"里填的地址（形如 `http://某地址/proxy.pac`）。把这个地址直接粘到浏览器地址栏访问：

- 能下载到一个文本文件、里面是 `function FindProxyForURL(...)` 这类内容 → 脚本还在，问题在别处。
- 打不开、404、一直转圈 → 脚本已失效，关掉这个开关。

**预期结果**：确认脚本可用就保留，不可用就关闭。

**失败怎么办**：这是**公司下发的**脚本地址，**不要自行修改或删除**，联系 IT 确认新地址，详见[「PAC 自动配置脚本 / 自动检测设置要不要开」](./browser-proxy.html)。

### 步骤 4：清除系统级 WinHTTP 代理（容易漏掉的一处）

**目的**：Windows 有些程序（含部分系统组件和更新）不走"设置"里的代理，而是走 WinHTTP 代理，卸载工具后常留在这里。

**操作**：以**管理员身份**打开命令提示符（开始菜单搜 cmd → 右键 → 以管理员身份运行），先查看：

```bat
netsh winhttp show proxy
```

如果输出里出现了你不认识的代理地址，再执行：

```bat
netsh winhttp reset proxy
```

> ⚠️ 只有在**你确认自己不需要这个代理**时才执行重置。公司设备上如果 IT 配置了 WinHTTP 代理，重置会导致内网系统访问不了。

**预期结果**：`show proxy` 的输出变成"直接访问(没有代理服务器)"。

**失败怎么办**：提示"需要提升权限"，就用管理员身份重开命令行；如果重置后内网系统打不开了，把原来的地址用 `netsh winhttp set proxy <地址:端口>` 填回去，或联系 IT。

### 步骤 5：排查浏览器扩展（SwitchyOmega 一类）

**目的**：浏览器插件可以单独接管代理，优先级高于系统设置。

**操作**：

1. 打开**无痕窗口**访问网站（无痕默认禁用扩展）。能打开 → 就是扩展问题。
2. 在正常窗口进入浏览器的扩展管理页（Chrome/Edge 地址栏输入 `chrome://extensions` 或 `edge://extensions`）。
3. 把代理类、VPN 类、"网络加速"类扩展**逐个关闭**，每关一个刷新一次页面，定位到出问题的那一个。
4. 找到后卸载，或打开它的设置把情景模式切回"**直接连接 / 系统代理**"。

**预期结果**：关掉那个扩展后网页立刻恢复，且不再报代理错误。

**失败怎么办**：关掉所有扩展还是不行，回到步骤 2-4；如果你登录了浏览器账号，扩展会被自动同步回来，卸载后记得在同步设置里也删掉一次。

### 步骤 6：macOS 上关闭各代理开关

**目的**：Mac 的代理设置藏在每个网络服务的"详细信息"里，位置和 Windows 不同。

**操作**：**系统设置 → 网络 → 选中当前在用的服务（Wi-Fi 或以太网）→ 详细信息 → 代理**，把不需要的开关全部关掉：网页代理(HTTP)、安全网页代理(HTTPS)、SOCKS 代理、自动代理配置、自动发现代理。

命令行也可以核对与清理（终端执行，需要输入密码）：

```bash
scutil --proxy
networksetup -listallnetworkservices
```

要清掉某个服务（把 Wi-Fi 换成你在上一步列出的服务名）的 HTTP 代理：

```bash
sudo networksetup -setwebproxystate "Wi-Fi" off
sudo networksetup -setsecurewebproxystate "Wi-Fi" off
```

**预期结果**：`scutil --proxy` 输出里 `HTTPEnable`、`HTTPSEnable` 都是 0。

**失败怎么办**：命令提示找不到服务名，就用 `networksetup -listallnetworkservices` 的原文（注意大小写和空格）；公司 Mac 上这些设置可能被描述文件（MDM）锁定，**请联系 IT**。

### 步骤 7：重启并做最终验证

**目的**：让代理相关设置彻底生效。

**操作**：重启电脑和浏览器，然后同时做三件事：

1. 浏览器访问任意网站；
2. 命令行 `ping www.baidu.com`（Windows）或 `ping www.baidu.com`（macOS）；
3. 打开一个必须联网的应用（比如网盘客户端）。

**预期结果**：三处都能正常工作，且不再出现代理相关提示。

**失败怎么办**：如果 ping 域名失败但能 ping 通 IP，是 DNS 问题，看[「网页打不开但 QQ / 微信能用：DNS 问题怎么修」](./dns-broken-but-app-works.html)。

## 怎么确认修好了

关掉浏览器再重开，连续访问 3 个不同网站（含一个视频网站）都能正常加载，并且**再也不会弹出代理相关的错误提示**，就算修好了。命令行 `netsh winhttp show proxy` 显示"直接访问"是更硬的一条判据。

## 还是不行？

- **只有某一个浏览器不行** → 看[「只有浏览器上不了网，其他软件都正常」](./browser-proxy.html)。
- **改完全部设置，联网软件还是全都不通** → 看[「装了抓包/加速工具后全网断网怎么恢复」](./proxy-tool-broke-network.html)，按那篇的顺序清理虚拟网卡和路由表。
- **能上内网系统、上不了外网，或反过来** → 这是代理分流策略问题，公司设备请联系 IT，个人设备看[「PAC 自动配置脚本 / 自动检测设置要不要开」](./browser-proxy.html)。
- **公司/学校配发的电脑，代理设置改不动或不让改** → 不要尝试绕过管控，看[「公司电脑改不了代理/网络设置，该怎么办」](./enterprise-proxy.html)并按单位流程提交工单。

## 预防

1. 卸载加速器、抓包工具、VPN 客户端后，顺手检查一遍"设置 → 网络和 Internet → 代理"，把残留开关关掉。
2. 不要安装来源不明的"网络加速""一键代理"插件，它们常在后台改系统代理。
3. 把当前正常的代理设置页截图存到手机相册，出问题时对照恢复。
4. 公司办公电脑上的代理、脚本地址一律按 IT 下发的填写，不自行改动。
5. 定期执行一次 `netsh winhttp show proxy` 留个底，出问题时能立刻判断是不是被改了。
