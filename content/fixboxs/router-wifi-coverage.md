# 某些房间 WiFi 信号差 / 一进卧室就断流怎么优化

> ℹ️ 本教程全部是摆放、设置与组网层面的优化，不改宽带、不动数据。判断信号好坏用一个标准：手机 WiFi 图标旁的信号强度（dBm），-50 优秀 / -60 良好 / -70 及格 / -80 以下基本不可用。

## 一句话结论

WiFi 信号差，八成不是路由器「功率不够」，而是**位置不对、频段选错、信道打架**三件事：路由器挪到房子中心并抬高，经常用的房间连 5GHz（近处快），远隔两堵墙的房间连 2.4GHz（穿墙好），一个路由器实在覆盖不了就上 Mesh——这是华为官方排障指南与主流方案一致给出的优化顺序。

## 30 秒快速排查

1. 在信号差的房间看手机连的是 **2.4G 还是 5G**：隔两堵墙连着 5G（名字常带 _5G）→ 切到 2.4G 试试，5G 穿墙能力天生弱。**期望结果**：切完立刻能用。
2. 看**路由器的位置**：塞在弱电箱/电视柜角落/地上 → 挪到房屋中心、离地 1 米以上、四周空旷。**期望结果**：同一房间信号格数上涨。
3. 进路由器后台看 **2.4G 信道**是「自动」还是挤在 1/6/11 之外的值：邻居家的 WiFi 都挤在同一信道会互相拖慢，手动固定到 1、6 或 11。

## 适用 / 不适用

**适用**

- 家里大部分房间正常，个别房间/卫生间信号差。
- 信号满格但刷视频转圈（连接速率被拉低）。
- 一梯两户/复式/跃层，单路由器怎么调都覆盖不全。

**不适用**

- 所有房间都慢、连近距离也慢 → 是带宽/路由器性能问题，看[「网速慢怎么定位：是宽带、路由器还是电脑的问题」](./slow-network.html)。
- 完全搜不到自家 WiFi → 看看[「Wi-Fi 列表里找不到自家网络」](./wifi-ssid-not-found.html)。
- 疑似被人蹭网拖慢 → 看[「怎么查谁在蹭网 / 给设备限速与拉黑」](./router-wifi-leech-check.html)。

## 开始前确认

- [ ] 手机装一个 WiFi 分析 App（或用笔记本看信号 dBm），能记录不同房间的强度。
- [ ] 知道路由器品牌型号，能找到对应后台地址。
- [ ] 画出户型草图，标出路由器位置和信号差的房间。
- [ ] 记录当前 WiFi 名称与密码（改设置时别把自己踢下线）。

## 分步骤

### 步骤 1：把路由器搬到正确的位置（零成本，收益最大）

1. 房屋**几何中心**优先，别贴外墙、别进弱电箱（金属箱体 = 屏蔽罩）。
2. 离地 1 米以上（桌面/架子顶），天线垂直直立。
3. 远离微波炉、蓝牙音箱、金属柜、鱼缸——微波炉工作频率直接砸在 2.4G 频段上。
4. 搬完在信号最差的房间测一次 dBm，对比之前。
**期望结果**：差房间信号改善 5-10 dBm。**失败了怎么办**：仍 -70 以下 → 步骤 2。

### 步骤 2：频段与信道调优（后台操作）

1. 2.4G：信道从「自动」改为手动 **1、6、11** 之一（用 WiFi 分析 App 看哪个信道周围最空）；频宽 20MHz（穿墙场景 40MHz 反而不稳）。
2. 5G：功率/模式若有「穿墙模式」选项就开启（华为官方建议项）；频宽 80MHz 提速率。
3. 关掉「双频合一」做一次测试：给 5G 单独命名，手机在近处手动连 5G、远处连 2.4G，比自动漫游更可控。
**期望结果**：各房间都能连上「当下最快的那一个」。**失败了怎么办**：远房间 2.4G 也只有 -75 以下 → 单路由器物理极限到了，进步骤 3。

### 步骤 3：Mesh 组网（覆盖不足的正解）

1. **优先有线回程**：预埋了网线的房子，主路由 + 子路由用网线连（稳定翻倍）。
2. 没有预埋线就选无线回程 Mesh（主流品牌华硕/小米/华为/TP 的套装都可以），子节点放在「主路由信号 -60 左右」的位置——放在信号已死的地方只会更差。
3. 中继器/电力猫是下位替代：便宜但会砍半速，Mesh 能全速漫游。
4. 组网后全屋走同一个 WiFi 名称，走路时设备自动切换。
**期望结果**：全屋各房间 dBm 都在 -65 以上。**失败了怎么办**：Mesh 子节点间仍频繁切换断流 → 缩小子节点间距，或改成有线回程。

### 步骤 4：终端侧小优化

1. 手机关掉「智能选网/自动切换网络」（部分手机会在 2.4G/5G 间反复横跳造成卡顿）。
2. 电脑无线网卡驱动更新到厂商最新版（旧驱动的漫游策略很笨）。
3. 智能家居设备固定连 2.4G（大多只支持 2.4G），别和手机抢 5G 带宽。
**期望结果**：漫游顺畅，设备各得其所。**失败了怎么办**：单台设备在他处正常、独在这房间差 → 该设备天线/驱动问题，按设备类型单独处理。

## 怎么确认修好了

- 全屋各房间信号均 ≥ -65 dBm（WiFi 分析 App 可测）。
- 从客厅走到卧室视频通话不断流。
- 近处测速接近宽带签约值的 70% 以上，远处不低于 50%。

## 还是不行？

- Mesh 后仍有个别死角 → 加第三个节点或改吸顶 AP 方案（装修期首选）。
- 信号好但速率上不去 → 回到带宽层排查，看[「网速慢怎么定位」](./slow-network.html)。
- 老房子墙体含金属/承重厚 → 无线方案性价比下降，直接走明线装面板 AP 最彻底。

## 预防

- 路由器每月重启一次；固件保持更新（厂商会持续优化漫游算法）。
- 换新设备/新增大功率电器后复测一次各房间信号。
- 装修阶段就预埋网线到每个房间——WiFi 再强也替代不了有线回程。
