# U 盘 / 移动硬盘不识别、提示格式化怎么办

> ⛔ 有数据风险：本文涉及磁盘与文件系统操作。**在把重要数据复制出来之前，绝对不要点"格式化"、不要初始化磁盘、不要跑全盘修复。**
> 那些操作会覆盖原始数据，之后再想恢复就难了。先把数据救出来，再谈修盘。

## 一句话结论

"需要格式化才能使用"通常是**文件系统损坏或分区表异常**，盘里的数据多数还在；先**停止写入**、换口换机确认，然后立刻把能读到的数据拷出来，最后才考虑修复文件系统。

## 30 秒快速排查

1. **什么按钮都别点**，尤其不要点"格式化"。把 U 盘拔下来，换到电脑**另一个 USB 口**（台式机优先机箱后置口）重插。**期望结果**：能打开就说明只是接触/供电问题。
2. 打开"此电脑"，看这个盘有没有盘符；如果没有，右键"开始"菜单 → **磁盘管理**，看它是否显示为 `RAW` 或"未分配"。**期望结果**：确认是"没有盘符"还是"文件系统坏了"。
3. 换一台电脑（或 Mac）再插一次。**期望结果**：只有一台电脑不认 = 电脑侧问题；两台都不认 = 盘本身问题。

## 适用 / 不适用

**适用**

- 插入后弹出"使用驱动器中的光盘之前需要将其格式化""需要格式化才能使用"。
- "此电脑"里能看到盘但打不开、提示"参数错误""无法访问"。
- 换电脑/换口后 U 盘时认时不认、传输中途断开。
- 盘能读但**不能写入**（复制时说"磁盘被写保护"）。

**不适用**

- 盘整个转都不转、有咔咔异响：**立刻断电**，看[「硬盘咔咔响 / 电脑识别不到硬盘，是不是要坏了」](./disk-clicking-failure.html)。
- 文件只是被你删了或清空了回收站，盘本身正常：看[「文件误删了怎么恢复（先做这一步，别写磁盘）」](./deleted-file-recovery.html)。
- 打印机、显示器等外设不识别：看[「打印机显示脱机 / 打印没反应怎么修」](./printer-offline.html)、[「显示器无信号 / 分辨率不对 / 外接屏不亮」](./monitor-no-signal.html)。

## 开始前确认

- [ ] **已经停止对该盘的一切写入**（不再往里存文件、不装软件到它上面）。
- [ ] 准备另一个**容量足够**的存储设备，用来接收拷出来的数据（不要拷回原盘）。
- [ ] 如果你没有第二块盘，先别动手修，优先去借一个——腾挪空间本身就是写入风险。
- [ ] 数据极其重要（工作资料、唯一一份照片）时，先明确：**继续操作可能降低专业数据恢复的成功率**，这种情况下直接考虑专业恢复机构（见"还是不行"）。
- [ ] 电脑上有管理员权限（要用磁盘管理、命令行）。
- [ ] U 盘上是否有写保护物理开关（很多 SD 卡和部分 U 盘侧面有个小拨片）。

## 分步骤

### 步骤 1：物理层确认——换个口、换根线、换台机器

**目的**：先用最无损的方式排除接触不良与供电不足，这类原因占比很高。

**操作**：

1. 拔下 U 盘，换电脑上**另一个 USB 口**（台式机优先机箱后置、直插主板的 USB 口）。
2. 移动硬盘用**原装数据线**，换一根已知良好的线再试；如果是 Type-C 硬盘盒，换一条支持数据（不是只充电）的线。
3. 换一台电脑或 Mac 交叉验证。
4. 插上时听声音、看提示：Windows 有"叮咚"提示音说明系统认到了设备，只是存储层有问题。

**预期结果**：换个口后盘正常识别并打开。

**失败怎么办**：所有口和电脑都不认，继续步骤 2；某台电脑认、某台不认，基本是电脑侧 USB 驱动/供电问题，可先看[「电脑没有 WLAN 选项 / 网络适配器不见了」](./wifi-adapter-missing.html)里更新驱动的思路。

### 步骤 2：在磁盘管理里看它是"没盘符"还是"RAW"

**目的**：这两种情况处理方式完全不同，别搞错顺序。

**操作**：右键"开始"菜单 → **磁盘管理**（或在"运行"里输入 `diskmgmt.msc`）。

| 看到的现象 | 含义 | 该怎么做 |
|---|---|---|
| 有分区，但**没有盘符**（只有卷标或"新加卷"） | 只是盘符丢了，数据完好 | 右键该分区 → **更改驱动器号和路径** → 添加一个字母 |
| 显示 **RAW** | 文件系统结构损坏 | 先拷数据，再修文件系统（步骤 3、5） |
| 显示"**未分配**" | 分区表丢失或未初始化 | **先不要初始化**，参考[「格式化后数据还能恢复吗 / 分区不见了怎么找回」](./partition-manager.html)，必要时找专业人员 |
| 完全不显示这块盘 | 系统在硬件层没认到 | 回步骤 1，或按[「硬盘咔咔响 / 电脑识别不到硬盘，是不是要坏了」](./disk-clicking-failure.html)处理 |

**预期结果**：知道自己这块盘属于哪一类。

**失败怎么办**：磁盘管理弹出"初始化磁盘"窗口时，**直接点取消**——初始化会破坏分区表；先按步骤 3 抢救数据。

### 步骤 3：立刻把能读到的数据拷出来（最重要的一步）

**目的**：不管后面修不修，数据先出来才有安全垫。

**操作**：

1. 在"此电脑"里双击该盘。能打开就把重要文件夹**复制**（不是剪切）到另一个盘。
2. 打不开时，用命令行**只读式**复制。以管理员身份打开命令提示符，先看盘符：

```bat
wmic logicaldisk get deviceid,volumename,size,freespace
```

然后整盘复制（把 `X:` 换成出问题的盘符，`E:\backup\` 换成你的备用盘目录，**目标盘绝不能是原盘**）：

```bat
robocopy X:\ E:\backup\ /E /R:1 /W:1 /XJ
```

> ⛔ 有数据风险：`robocopy` 的源和目标写反会覆盖数据；执行前把两个盘符再核对一遍。红色报错很多不要紧，能救多少救多少。

3. 硬盘读取很慢或报错时，**分批拷**：先拷最要紧的文档、照片，再拷其他。

**预期结果**：重要文件出现在备用盘里，能正常打开。

**失败怎么办**：读取时反复报 I/O 错误，不要反复重试同一批文件——换个目录先拷能读的部分；如果报"循环冗余检查(CRC)"，说明有物理坏块，请直接看[「硬盘咔咔响 / 电脑识别不到硬盘，是不是要坏了」](./disk-clicking-failure.html)的"只读抢救"部分。

### 步骤 4：解除写保护（能读不能写的情况）

**目的**：写保护会让所有复制/删除操作失败。

**操作**：按可能性从高到低查：

1. **物理开关**：SD 卡/U 盘侧面若有 `Lock` 拨片，拨到解锁位再试。
2. **只读属性**：管理员命令提示符执行（`X` 换成实际盘符）：

```bat
diskpart
```

在 diskpart 提示符下依次执行：

```text
list disk
select disk N
attributes disk
```

如果输出里有 `当前只读状态: 是`，执行：

```text
attributes disk clear readonly
exit
```

> ⚠️ `select disk N` 选错磁盘会破坏其他磁盘的分区表。先执行 `list disk`，按**容量**核对你要操作的那一块，确认无误再 select。

3. **注册表写保护**（部分 Windows 会设置 `WriteProtect`）：这一项**以微软官方文档与电脑厂商说明为准**，不确定就不要改注册表。
4. 若以上都不是，且盘在别的电脑上也不能写——是主控或闪存老化触发的自我保护，**该换盘了**，不要指望修好继续用。

**预期结果**：写保护解除，能正常复制文件进去。

**失败怎么办**：清只读后重启又恢复只读，说明是硬件层保护，停止写入、尽快备份并更换该盘。

### 步骤 5：修复文件系统（数据已备份之后再动手）

**目的**：把 RAW/损坏的文件系统修回可用状态。

> ⛔ 有数据风险：文件系统修复会改动分区结构。**只在步骤 3 已把重要数据拷出来后执行。** 如果这块盘有异响或明显坏块，**不要执行**，直接走备份和更换。

**操作**：管理员命令提示符执行（`X` 换成实际盘符）：

```bat
chkdsk X: /f
```

只有"扫描坏扇区"需求时才加 `/r`（**耗时可能数小时，中途不要断电**）：

```bat
chkdsk X: /r
```

**预期结果**：chkdsk 报告已修复文件系统错误，盘能正常打开。

**失败怎么办**：chkdsk 卡住不动或报"无法锁定驱动器"，先关掉所有占用该盘的窗口再试；反复失败就停手，改用下面步骤 6 或送去专业恢复。

### 步骤 6：macOS 上的处理顺序

**目的**：Mac 用户的修复工具与 Windows 不同，顺序原则一样——先数据后修复。

**操作**：

1. 先尝试把文件拷到 Mac 本地或另一块盘。**注意**：macOS 默认**不能写入 NTFS** 格式的盘，只能读，这属于正常现象，不是盘坏了。
2. 打开"**磁盘工具**"（应用程序 → 实用工具），左侧选中该磁盘的**卷**，点"**急救(First Aid)**" → 运行。
3. 急救失败时，先别点"抹掉"（抹掉 = 格式化），改用专业恢复工具或送修。

**预期结果**：急救完成并显示卷可用，盘能在访达里正常打开。

**失败怎么办**：急救报"无法修复"，且数据已经拷出来，才考虑重新格式化；数据没出来就停手，走下面的"还是不行"。

### 步骤 7：确认可用性并决定去留

**目的**：修好不代表可以放心长期用。

**操作**：修好后做一次小文件读写测试：拷入一个 10MB 文件再打开，重复 3 次，看速度是否稳定、是否掉盘。然后用 Windows 自带的错误检查（此电脑右键盘 → 属性 → 工具 → 检查）再验证一次。

**预期结果**：读写稳定，没有中途掉盘。

**失败怎么办**：一拷大文件就掉盘、速度忽高忽低，说明闪存/主控老化，**换新盘**，别拿它存唯一一份重要数据。

## 怎么确认修好了

盘能正常出现在"此电脑"里、能打开、能读能写；连续拷入并打开 3 个不同大小的文件都不报错；重要数据已经**同时存在于另外一块盘上**。

## 还是不行？

- **显示"未分配"、分区不见了** → 看[「格式化后数据还能恢复吗 / 分区不见了怎么找回」](./partition-manager.html)，**不要再做任何写入**。
- **读取时持续报 I/O 错误、有咔咔声或规律异响** → 立即断电，看[「硬盘咔咔响 / 电脑识别不到硬盘，是不是要坏了」](./disk-clicking-failure.html)。
- **只是误删了文件，盘本身好的** → 看[「文件误删了怎么恢复（先做这一步，别写磁盘）」](./deleted-file-recovery.html)。
- **数据是无法替代的唯一副本（毕业设计、公司财务、家人照片）且自己拷不出来** → **停止一切操作**，找正规的数据恢复机构（优先选择有实体门店、能签保密协议、先检测后报价的）；公司设备**请联系 IT**，不要自行反复尝试。

## 预防

1. 重要数据遵循"**3-2-1**"：3 份副本、2 种介质、1 份放在别处。
2. U 盘/移动硬盘不要用"直接拔"的方式断开，先点任务栏的"安全删除硬件"。
3. 移动硬盘工作时不要挪动、不要放在被子/沙发上（震动对机械盘是致命的）。
4. 别把唯一一份资料放在 U 盘里长期保存，闪存会老化、也会突然掉盘。
5. 每隔几个月插上跑一次小文件读写测试，发现速度异常就及时转移数据。
