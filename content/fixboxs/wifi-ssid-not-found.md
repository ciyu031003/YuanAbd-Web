# Wi-Fi 列表里找不到自家网络怎么办

## 一句话结论

先分清是"只有这台电脑搜不到"还是"所有设备都搜不到"：只有一台 → 是电脑的网卡/驱动问题；全都搜不到 → 去路由器那边看，多半是 Wi-Fi 被关了、名字被隐藏或路由器没工作。

## 30 秒快速排查

1. **拿手机看 Wi-Fi 列表**里有没有自家网络名。期望：手机能搜到 → 问题在这台电脑；手机也搜不到 → 问题在路由器。
2. **看路由器指示灯**：电源灯亮、Wi-Fi（或 WLAN）灯是否亮或闪。期望：Wi-Fi 灯不亮 → 路由器上的 Wi-Fi 被关了。
3. **把电脑搬到路由器旁边**（1 米内）再看一次列表。期望：近距离能搜到 → 之前是信号太弱或被墙挡住。

## 适用 / 不适用

**适用：**

- Wi-Fi 列表里完全没有自家网络名，别人的网络能看到
- 换手机、换平板都搜不到同一个名字
- 明明就在路由器旁边，却搜不到 5G 的名字
- 路由器重启后，网络名消失了

**不适用（请转对应文章）：**

- 列表里能看到网络名，但连不上或连上没网 → [Wi-Fi 显示已连接但无法上网（打不开网页）](#)
- 电脑上连「WLAN」开关、飞行模式图标都找不到 → [电脑没有 WLAN 选项 / 网络适配器不见了](#)
- 家里所有设备都上不了网（不只是搜不到） → [家里所有设备都上不了网：先分清是谁的问题](#)
- 公司、宿舍、出租屋的 Wi-Fi，网络名可能被统一管理 → 直接联系单位 IT 或房东/网管

## 开始前确认

- [ ] 手边有一台能上网的手机（用来对照和查路由器资料）
- [ ] 知道自家 Wi-Fi 名称（SSID）和密码
- [ ] 知道路由器放在哪、能不能看到指示灯
- [ ] Windows 上查看驱动信息需要普通权限即可；macOS 部分命令需要输入管理员密码
- [ ] 如果是公司/学校配发的电脑，改驱动和网络设置前先问 IT

## 分步骤

### 步骤 1：确认是"一台设备"还是"所有设备"搜不到

**目的**：这一步决定后面往路由器查还是往电脑查，做错方向会白花时间。

**操作**：拿手机打开 Wi-Fi 设置，看列表里有没有自家网络名；再用另一台电脑或平板看一次。

**预期结果**：

- 手机也搜不到 → 问题在路由器侧，跳到步骤 2
- 手机能搜到、只有这台电脑搜不到 → 问题在电脑侧，跳到步骤 4

**失败怎么办**：手机连的是移动数据不是 Wi-Fi，请先关闭移动数据再测；手机上曾经连过该网络时，可能显示为"已连接"而不在列表里，可以先"忽略此网络"再刷新列表。

### 步骤 2：检查路由器的 Wi-Fi 是否被关闭或隐藏

**目的**：路由器端最常见的两个原因就是"Wi-Fi 被关了"和"网络名被隐藏了"。

**操作**：

1. 看路由器机身指示灯：电源灯常亮，Wi-Fi / WLAN 灯应常亮或闪烁。
2. 登录路由器管理页面（地址一般在机身底部标签上），找到「无线设置 / Wi-Fi 设置」：
   - 确认无线功能处于**开启**状态；
   - 确认**没有**勾选「隐藏 SSID / 不广播网络名称」；
   - 确认网络名称（SSID）没有被改成奇怪的名字。
3. 如果确实被隐藏了，可以取消隐藏；不想取消，就让每台设备手动加入隐藏网络（见步骤 6）。

**预期结果**：改完后，手机和电脑的 Wi-Fi 列表里很快出现自家网络名。

**失败怎么办**：进不去管理页面，看 [路由器后台 192.168.1.1 打不开怎么办](#)；忘记管理密码，只能按机身标签的默认密码试，或恢复出厂（会清空宽带账号，谨慎操作）。

### 步骤 3：看频段和信道——为什么偏偏搜不到 5G

**目的**：2.4GHz 和 5GHz 的覆盖范围不同，部分设备也不支持 5GHz 或 6GHz。

**操作**：在路由器管理页面查看 2.4GHz 和 5GHz 是否都开启，并记下各自的网络名（很多路由器会给 5G 名字加 `-5G` 后缀）。然后拿着设备在路由器 1 米内再搜一次。

常见的对应关系：

| 频段 | 穿墙能力 | 速度 | 谁能搜到 |
|---|---|---|---|
| 2.4GHz | 强，隔墙也能收到 | 较慢，容易拥堵 | 几乎所有设备 |
| 5GHz | 弱，隔一两堵墙就可能消失 | 快 | 近几年的手机、电脑 |
| 6GHz（Wi-Fi 6E/7） | 更弱 | 最快 | 只有新设备支持，老电脑完全看不到 |

**预期结果**：近距离能看到 5G 名字；隔墙时只剩 2.4GHz。

**失败怎么办**：在路由器里把 2.4GHz 信道手动固定为 1、6 或 11，5GHz 固定为 36/40/44/48 这类常用信道，避开"自动选到 DFS 信道"导致部分设备搜不到的情况；改完保存并等 1 分钟再搜。

### 步骤 4：Windows 上检查无线网卡与驱动

**目的**：确认网卡在正常工作、没有处于飞行模式或被禁用。

**操作**（命令提示符或 PowerShell，普通权限即可）：

```bat
netsh wlan show interfaces
netsh wlan show drivers
netsh wlan show networks mode=bssid
```

同时检查：

- 任务栏右下角有没有"飞行模式"图标，打开**设置 → 网络和 Internet → 飞行模式**确认它是关闭的；
- 有些笔记本有 Fn + F 键的无线开关，试一下；
- 打开**设备管理器 → 网络适配器**，看无线网卡有没有黄色感叹号或向下箭头。

**预期结果**：`netsh wlan show interfaces` 能显示出无线网卡名称和状态；`netsh wlan show networks mode=bssid` 能列出周围所有网络（含隐藏信息）。

**失败怎么办**：提示"无线自动配置服务(wlansvc)没有运行"，在服务里启动 `WLAN AutoConfig`；网卡有黄色感叹号 → 去 [电脑没有 WLAN 选项 / 网络适配器不见了](#)；附近网络一个都搜不到 → 很可能是网卡或驱动问题。

### 步骤 5：macOS 上检查 Wi-Fi 状态

**目的**：在 Mac 上用系统自带工具确认无线硬件与网络列表。

**操作**（终端）：

```bash
networksetup -listallhardwareports
system_profiler SPAirPortDataType | head -n 60
```

也可以按住 Option 键点击菜单栏的 Wi-Fi 图标，选择「打开无线诊断…」，用系统自带的无线诊断工具按提示扫描。

**预期结果**：`networksetup -listallhardwareports` 里能看到 Wi-Fi 对应的硬件端口（通常是 `en0` 或 `en1`）；`system_profiler` 输出里能看到"支持的 PHY 模式"和当前状态。

**失败怎么办**：硬件端口列表里完全没有 Wi-Fi → 属于网卡消失的问题，看 [电脑没有 WLAN 选项 / 网络适配器不见了](#)。旧系统上的 `airport -s` 扫描命令在新版 macOS 上已不可用，请改用「无线诊断」，不要照抄网上的老教程。

### 步骤 6：手动加入隐藏网络

**目的**：如果确实隐藏了 SSID，就只能手动输入网络名加入。

**操作**：

Windows：**设置 → 网络和 Internet → Wi-Fi → 管理已知网络 → 添加网络**，输入网络名（SSID）、安全类型和密码。

macOS：点菜单栏 Wi-Fi 图标 → **其他…**，在「网络名称」里填入 SSID，选择安全性（一般是 WPA2/WPA3 个人级）和密码。

**注意**：SSID 区分大小写，空格和特殊符号（中文、表情、连字符）必须完全一致；中文或表情名字在某些设备上会显示异常，建议在路由器里改成英文加数字。

**预期结果**：保存后能连上该网络。

**失败怎么办**：提示找不到网络 → 确认路由器上 SSID 拼写；连上但没网 → 转 [Wi-Fi 显示已连接但无法上网（打不开网页）](#)。

## 怎么确认修好了

Wi-Fi 列表里能看到自家网络名（隐藏网络则是手动加入后显示为已连接），点它能连上，并且能打开任意一个网页；把电脑拿到常用位置（例如卧室）后，网络名依然在列表里或能自动重连。

## 还是不行？

- **只有这台电脑搜不到，别的设备都正常** → 更新无线网卡驱动；仍不行看 [电脑没有 WLAN 选项 / 网络适配器不见了](#)
- **手机也搜不到，但路由器指示灯正常** → 在路由器里关闭「隐藏 SSID」并开启 2.4GHz，再重启路由器
- **路由器所有灯都正常但谁都不搜不到、也进不去管理页面** → 路由器可能故障，可先恢复出厂；不会操作就看 [路由器后台 192.168.1.1 打不开怎么办](#)
- **公司/宿舍/出租屋网络、或路由器由运营商提供** → 联系单位 IT、房东或运营商客服，不要自行改设备

## 预防

1. 在路由器里把 2.4GHz 和 5GHz 都打开，不要隐藏 SSID；隐藏并不等于安全，反而增加麻烦。
2. 网络名使用英文加数字，避免中文、空格和表情符号。
3. 把路由器的管理地址、登录密码、宽带账号写在纸上收好，不要只存在浏览器里。
4. 每 1-2 个月重启一次路由器，固件有更新时及时升级。
5. 电脑上不要随意卸载无线网卡驱动；更新驱动优先用笔记本厂商官网的版本。
