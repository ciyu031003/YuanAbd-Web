# 电脑开机黑屏只有鼠标指针，怎么救回来

> ⚠️ 需谨慎：本文会改动启动项、显卡驱动和注册表。操作前把桌面上的重要文件拷到 U 盘或网盘。
> ⛔ 有数据风险：步骤 6（系统还原）和步骤 7（注册表）会改动系统状态，动手前请先备份重要文件，并按文中提示导出注册表备份。

## 一句话结论

能看见鼠标说明系统其实已经启动，只是桌面程序 explorer.exe 没起来，或者显卡驱动、最近一次更新出了故障。先按 Ctrl+Alt+Del 打开任务管理器，运行 explorer.exe，多数情况当场恢复。

## 30 秒快速排查

1. **按 Ctrl+Alt+Del**，出现蓝底选项说明系统活着。选「任务管理器」→ 左上角「文件」→「运行新任务」→ 输入 `explorer.exe` → 确定。桌面和任务栏出现，就是它。
2. **按 Win+Ctrl+Shift+B**。这是 Windows 内置的「重启显卡驱动」快捷键，屏幕会闪黑一下、可能「叮」一声。按完桌面出现，问题在显卡驱动。
3. **长按电源键 10 秒强制关机**，拔掉所有 USB 设备（U 盘、移动硬盘、打印机、扩展坞）后重新开机。外接设备冲突导致黑屏很常见。

## 适用 / 不适用

**适用：**
- 开机后屏幕全黑，但鼠标指针能移动
- 输完密码进入系统后黑屏，只有指针
- 桌面图标和任务栏消失，只剩一片黑或只剩壁纸

**不适用（请转对应文章）：**
- 卡在品牌 Logo 或一直转圈 → [电脑开机一直转圈 / 卡在品牌 Logo 进不去系统](./win-stuck-on-boot-logo.html)
- 蓝底 + 哭脸 + 错误代码 → [电脑蓝屏了怎么办：先学会读蓝屏代码](./win-bluescreen-read-code.html)
- 完全没反应，连鼠标都没有、风扇也不转 → 属硬件/供电问题，见本文「还是不行？」
- 忘了登录密码进不去 → [电脑开机密码忘了 / PIN 突然用不了](./win-forgot-password.html)

## 开始前确认

- [ ] 按键盘 Caps Lock / Num Lock，指示灯能亮 → 系统没死，是显示或桌面问题
- [ ] 记得开机密码（进安全模式、系统还原都要用）
- [ ] 手边有手机或另一台电脑可以查资料
- [ ] 重要文件平时有备份；没有就趁桌面还能恢复时先拷走
- [ ] 回忆一下：黑屏是否发生在「刚装完更新 / 刚换显卡驱动 / 刚插了新设备」之后
- [ ] 台式机确认显示器线插在显卡上而不是主板上，线缆两端都插紧

## 分步骤

### 步骤 1：先分清是真黑屏还是桌面没起来

**目的**：避免把硬件没信号当成软件问题修，白折腾一晚上。

**操作**：
1. 移动鼠标，看指针是否跟手。
2. 按 Win+P，连按几次，看屏幕是否切到「仅电脑屏幕」「复制」等模式。
3. 笔记本插上电源，再按一次 Win+Ctrl+Shift+B。
4. 如果接了外接显示器，用 Win+P 切到「复制」，看外接屏有没有画面。

**预期结果**：指针能动、Caps Lock 灯能亮 → 系统正在运行，是桌面程序或显示输出的问题，继续往下做。

**失败怎么办**：键盘灯完全不亮、风扇不转、外接显示器也无信号 → 停止软件排查，直接看「还是不行？」最后一档，考虑送修。

### 步骤 2：用任务管理器重新拉起桌面（最可能一次解决）

**目的**：黑屏最常见的原因是资源管理器（explorer.exe）没有启动，重新运行它就能恢复桌面。

**操作**：
1. 按 Ctrl+Alt+Del。
2. 选择「任务管理器」。如果看不到窗口，按 Alt+Tab 切换，或用方向键 + 回车。
3. 点左上角「文件」→「运行新任务」。
4. 输入下面的命令后点「确定」：

```bat
explorer.exe
```

**预期结果**：任务栏和桌面图标出现，鼠标点击正常。任务管理器「详细信息」里能看到 `explorer.exe` 进程。

**失败怎么办**：没有任何变化 → 先做步骤 3 再回来重试；连任务管理器都打不开 → 跳到步骤 5 进安全模式。

### 步骤 3：重启显卡驱动

**目的**：显卡驱动卡死时，屏幕上可能只剩一个鼠标指针，重启驱动不用重启电脑。

**操作**：同时按下 `Win + Ctrl + Shift + B`。

**预期结果**：屏幕闪黑一下，可能听到提示音，随后显示恢复正常。

**失败怎么办**：没反应或依旧黑屏 → 继续步骤 4。如果是刚更新显卡驱动才黑屏，做完步骤 5 后优先回退驱动。

### 步骤 4：拔掉外接设备后强制重启

**目的**：排除外接设备、扩展坞、线缆接触不良和休眠残留造成的假黑屏。

**操作**：
1. 长按电源键 10 秒以上，直到断电。
2. 拔掉所有 USB 设备（U 盘、移动硬盘、打印机、摄像头、扩展坞、读卡器），只留键盘鼠标。
3. 台式机拔掉电源线等 30 秒再插回；笔记本可拆电池的拆下电池，不可拆的忽略。
4. 重新开机。

**预期结果**：正常进入桌面。

**失败怎么办**：仍然黑屏 → 继续下一步。如果拔掉某个设备后就好了，就是该设备或其驱动的问题，先别急着装回它的驱动。

### 步骤 5：进安全模式，回退或重装显卡驱动

**目的**：安全模式只加载基本驱动，能进去说明是第三方驱动或软件引起的黑屏。

**操作**：
1. 强制关机 2-3 次（开机看到 Logo 就长按电源键），系统会自动进入「自动修复」。
2. 选「高级选项」→「启动设置」→「重启」→ 按 `4` 进入安全模式（需要联网按 `5`）。
3. 进入后：右键开始菜单 →「设备管理器」→ 展开「显示适配器」→ 右键显卡 →「属性」→「驱动程序」标签 →「回退驱动程序」。
4. 如果「回退」是灰的，就选「卸载设备」并勾选「尝试删除此设备的驱动程序」，重启后到显卡厂商官网重新安装正式驱动。

**预期结果**：安全模式下能正常看到桌面；回退或重装驱动后，正常模式也能进桌面。

**失败怎么办**：安全模式同样黑屏 → 跳到步骤 6；设备管理器里显卡带黄色感叹号 → 直接用官网驱动重装，不要用第三方驱动工具。

### 步骤 6：卸载最近的更新，或用系统还原退回

**目的**：把系统退回到出问题之前的状态，对「更新后黑屏」最有效。

> ⛔ 有数据风险：系统还原一般不动个人文件，但会卸载还原点之后安装的软件和驱动。动手前把重要文件备份到 U 盘或网盘。

**操作**：
1. 再进一次「自动修复」→「高级选项」。
2. 要卸载更新：选「卸载更新」→ 先卸载「最新质量更新」，仍不行再卸载「最新功能更新」。
3. 要还原系统：选「系统还原」，挑一个黑屏之前的时间点，按提示完成。

**预期结果**：还原或卸载完成后重启，能正常进入桌面。

**失败怎么办**：没有可用还原点 → 继续步骤 7；还原报错 → 记下错误码，先按步骤 7 修系统文件，再回来重试。

### 步骤 7：修复系统文件，核对登录外壳设置

**目的**：系统文件损坏，或登录外壳被改成不存在的程序，都会造成「只有指针的黑屏」。

**操作**：
1. 以管理员身份打开命令提示符（开始菜单搜索 `cmd` → 右键 →「以管理员身份运行」），依次执行：

```powershell
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
```

> ⛔ 有数据风险：改注册表前先备份。打开 `regedit`，右键 `Winlogon` 这一项 →「导出」，保存为 .reg 文件，出问题可双击还原。

2. 打开注册表编辑器，定位到：

```text
HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon
```

3. 确认右侧 `Shell` 的值是 `explorer.exe`（微软官方黑屏排查文档就要求核对这一项）。不是就改回 `explorer.exe`，重启电脑。

**预期结果**：DISM 报告「操作成功完成」，sfc 报告「未找到完整性冲突」或「已成功修复」；`Shell` 值为 `explorer.exe`。

**失败怎么办**：DISM 报 `0x800f081f` 等错误 → 说明组件存储缺少修复源，按官方文档用 `/Source` 指定源；两条命令都失败 → 考虑「设置 → 系统 → 恢复 → 重置此电脑」并选「保留我的文件」。

## 怎么确认修好了

重启后能稳定看到桌面图标和任务栏，鼠标点击、双击都正常；把电脑正常关机再开机两次都能进桌面，且任务管理器里 `explorer.exe` 一直在运行，才算真的修好。

## 还是不行？

- 只在装了某个软件或驱动之后黑屏 → 用「干净启动」逐项排除，思路见 [开机太慢：关掉这些开机自启软件](./win-startup-apps-disable.html)。
- 安全模式正常、正常模式必黑屏，也不想再折腾 → 「设置 → 系统 → 恢复 → 重置此电脑」，选「保留我的文件」。
- 黑屏同时伴随蓝屏或自动重启 → [电脑蓝屏了怎么办：先学会读蓝屏代码](./win-bluescreen-read-code.html)。
- 开机风扇转但显示器始终无信号，换线换显示器都一样 → 属于内存、显卡、主板等硬件问题，不要自己拆机，联系售后维修点或报修。
- 公司或学校配发的电脑 → 直接联系公司 IT，不要自行重装系统或改注册表。

## 预防

1. 显卡驱动只从显卡厂商官网或 Windows 更新安装，不用来路不明的「驱动大师」。
2. 安装大版本更新或显卡驱动前，先创建一个系统还原点（开始菜单搜「创建还原点」）。
3. 不要用「系统优化」「注册表清理」类工具，它们是黑屏和启动失败的常见来源。
4. 扩展坞、采集卡、老打印机等外设，不用时拔掉，尤其别留在开机前。
5. 重要文件按「本机 + 移动硬盘 + 网盘」存三份。
