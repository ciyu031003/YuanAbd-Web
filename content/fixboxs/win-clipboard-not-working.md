# Windows 剪贴板不能用 / 复制粘贴失效怎么修

> 清空剪贴板历史会删除已经复制过的记录，但不会删除原文件。正在远程控制或虚拟机中操作时，先确认问题属于本机还是跨设备剪贴板。

## 一句话结论

复制粘贴失效先分范围：所有软件都不行，通常是桌面外壳或系统剪贴板卡住；只有浏览器、远程桌面或虚拟机不行，问题通常在对应软件的剪贴板权限。先用记事本交叉测试，再重启 `explorer.exe`，最后才修复系统组件。

## 30 秒快速排查

1. 在记事本里复制一句话，粘贴到同一记事本。**同一程序也失败**，说明系统剪贴板卡住。
2. 在浏览器复制文字，粘贴到记事本；再从记事本复制到浏览器。**只有一个方向失败**，重点查该软件的权限或剪贴板模式。
3. 按 `Win+V` 看剪贴板历史能否打开。打不开时，先用上方 BAT 重启桌面，再回来测试。

## 小白一键修复

- 下载：[重启 Windows 桌面（.bat）](../scripts/restart-explorer.bat)
- 适合：Windows 10/11，所有软件都无法复制粘贴，或 `Win+V` 没反应。
- 脚本会：重启 `explorer.exe`，重新加载与桌面外壳关联的剪贴板界面。
- 运行前：保存文档，打开的资源管理器窗口会关闭。
- 注意：脚本不会恢复已经被新内容覆盖的剪贴板，也不会修复浏览器或远程软件自己的权限。

## 适用 / 不适用

**适用：**
- `Ctrl+C` 和 `Ctrl+V` 在所有或大多数程序里失效
- 粘贴出来总是上一次的旧内容
- 按 `Win+V` 剪贴板历史打不开
- Windows 更新、休眠恢复后突然无法复制粘贴

**不适用：**
- 网页禁止复制 → 是网站限制，不应靠脚本绕过
- 远程桌面里不能双向复制 → 检查远程客户端剪贴板重定向
- 虚拟机里不能复制 → 检查虚拟机增强工具和共享剪贴板
- 键盘按键损坏 → 用屏幕键盘测试 `Ctrl+C/V`

## 开始前确认

- [ ] 知道问题是所有软件还是单个软件
- [ ] 最近是否使用远程桌面、云电脑或虚拟机
- [ ] 剪贴板里是否有必须保留的密码、地址等敏感内容
- [ ] 保存当前文档，准备重启桌面

## 分步骤

### 步骤 1：用记事本判断故障范围

**目的**：确定是本机系统剪贴板，还是跨应用、跨设备的功能。

**操作**：
1. 打开记事本，输入“修盒子剪贴板测试”并全选复制。
2. 在同一记事本末尾粘贴一次。
3. 再从浏览器复制一段普通文字，粘贴到记事本；反向再试一遍。
4. 如果物理键盘可疑，按 `Win+Ctrl+O` 打开屏幕键盘，用鼠标点击 `Ctrl+C/V`。

**预期结果**：明确“本机失效”“单向失效”还是“某软件失效”。

**失败怎么办**：屏幕键盘能复制、实体键盘不能 → 换键盘或检查按键；只有远程桌面失败 → 跳到步骤 3。

### 步骤 2：重启桌面外壳

**目的**：`explorer.exe` 负责不少系统界面与剪贴板交互，重启它可以清理临时卡死。

**操作**：
1. 保存工作后运行上方 BAT，选择 `Y`。
2. 桌面和任务栏恢复后，重新用记事本测试复制粘贴。
3. 手动处理时，在任务管理器“进程”中右键 `Windows 资源管理器` →“重新启动”。

**预期结果**：`Ctrl+C/V` 和 `Win+V` 恢复，粘贴内容与刚复制的文本一致。

**失败怎么办**：重启后几分钟再次失效 → 继续检查剪贴板历史、远程软件和系统文件。

### 步骤 3：检查远程桌面、云电脑和虚拟机

**目的**：跨设备剪贴板需要客户端和主机两端都允许，开关经常会因更新重置。

**操作**：
1. 退出远程桌面客户端，重新连接后在连接设置中打开“剪贴板”重定向。
2. 云电脑客户端检查“本地剪贴板同步”或类似开关。
3. 虚拟机检查“共享剪贴板”“拖放”设置，并确认增强工具已安装。
4. 断开远程连接后测试本机复制粘贴，区分本机故障与远程故障。

**预期结果**：本地、远程和虚拟机之间恢复按预期同步。

**失败怎么办**：本机也失败 → 按步骤 4 清空历史；公司远程环境权限被锁 → 联系 IT。

### 步骤 4：清空剪贴板历史和临时内容

**目的**：历史记录损坏时，旧内容可能卡住新的复制操作。

**操作**：
1. 按 `Win+V` 打开剪贴板历史。
2. 点右上角“全部清除”，再点“关闭”。
3. 设置 → 系统 → 剪贴板，关闭“剪贴板历史记录”，重启电脑后再打开。
4. 重新复制一段普通文字测试，不要先用密码或验证码。

**预期结果**：剪贴板历史重新建立，复制新内容后粘贴结果同步变化。

**失败怎么办**：`Win+V` 仍然完全打不开 → 继续步骤 5。

### 步骤 5：修复系统文件并排除第三方工具

**目的**：系统剪贴板组件或 shell 扩展损坏时，界面重置无法解决。

**操作**：
1. 以管理员身份打开终端，依次运行：

```powershell
DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
```

2. 完成后重启电脑。
3. 临时退出剪贴板增强、输入法云同步、截图翻译和任务栏美化工具，再测试复制粘贴。

**预期结果**：系统文件检查完成，退出第三方工具后剪贴板稳定。

**失败怎么办**：只有一个软件始终不能粘贴 → 更新或重装该软件；安全软件拦截剪贴板时，按组织规定处理。

## 怎么确认修好了

在记事本、浏览器和文件资源管理器之间连续做 5 次复制粘贴，内容都正确；`Win+V` 能显示本次历史；休眠恢复、锁屏解锁和重启各测试一次仍正常。

## 还是不行？

- 所有程序同时异常，任务栏也开始卡顿 → [Windows 任务栏卡死](./win-taskbar-unresponsive.html)
- 只有浏览器不能粘贴 → 检查网站权限、扩展和浏览器剪贴板提示
- 只有远程桌面不能粘贴 → 检查本地与远程客户端的剪贴板重定向
- 系统文件检查反复失败 → 备份数据后考虑系统还原
- 键盘快捷键偶发失效 → 换键盘或用屏幕键盘交叉验证

## 预防

1. 不在剪贴板中长期保留密码、验证码和身份证照片。
2. 更新远程桌面、虚拟机和输入法后主动测试剪贴板。
3. 少装来源不明的剪贴板增强和自动翻译工具。
4. 遇到异常时先记录“哪个应用复制、粘贴到哪里失败”，便于快速定位。
