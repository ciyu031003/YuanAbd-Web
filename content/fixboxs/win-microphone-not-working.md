# 电脑麦克风没声音 / 会议里对方听不到怎么修

> 本文只检查输入设备、权限和音频服务，不会录音保存隐私内容。测试麦克风时，请不要在会议或直播中播放测试声音。

## 一句话结论

“对方听不到”不一定是麦克风坏了。先看系统输入设备有没有选对、麦克风是否静音，再检查 Windows 与会议软件的权限。系统录音有电频、只有会议软件没声音，问题就在应用设置；系统里也没有输入，才去修服务和驱动。

## 30 秒快速排查

1. 右键任务栏音量图标 →“声音设置”，在“输入”里选正确麦克风，说话时看“输入音量”条是否动。
2. 会议软件里打开“音频设置”，确认麦克风选的是同一设备，且没有静音。
3. 检查笔记本键盘或耳机线上的物理静音键/隐私开关；蓝牙耳机要确认当前使用的是“头戴式耳机”而不是只输出声音的模式。

## 小白一键修复

- 下载：[重启 Windows 音频服务（.bat）](../scripts/restart-audio-services.bat)
- 适合：Windows 10/11，扬声器正常，但系统突然检测不到麦克风或音频设置打开很慢。
- 脚本会：重新扫描音频设备，重启音频端点与 Windows Audio 服务，并打开声音设置。
- 运行前：拔掉暂时不用的耳机和扩展坞，关闭会议、录音和直播软件。
- 注意：脚本不会更改隐私权限或安装驱动；打开声音设置后仍需手动选中正确输入设备。

## 适用 / 不适用

**适用：**
- 录音机里没有波形，会议软件提示“找不到麦克风”
- 之前能说话，Windows 更新或休眠后突然无声
- 接了耳机、扩展坞或蓝牙设备后输入设备选错
- 系统测试有声音，但浏览器或会议软件不工作

**不适用：**
- 播放音乐也没声音 → 看 [电脑没声音怎么修](./win-no-sound.html)
- 蓝牙耳机根本配对不上 → 看 [蓝牙耳机 / 键鼠连不上](./bluetooth-device-not-pairing.html)
- 摄像头同时不工作 → 看 [摄像头打不开怎么修](./webcam-not-working.html)
- 只有某个网页会议平台异常 → 先查该平台的浏览器麦克风权限

## 开始前确认

- [ ] 确认电脑可以正常播放声音
- [ ] 摘掉耳机测试内置麦克风，或换一个已知正常的耳机交叉验证
- [ ] 关闭所有会议、录音、直播和语音助手软件
- [ ] 查看笔记本或耳机是否有物理静音开关

## 分步骤

### 步骤 1：在系统里测试输入是否真的没有

**目的**：把问题分成“麦克风没采集”和“会议软件没使用”两段。

**操作**：
1. 打开设置 → 系统 → 声音 → 输入。
2. 选择正确设备，对着麦克风正常说话。
3. 观察“输入音量”是否跳动；再打开系统“录音机”录 5 秒并回放。
4. 打开声音控制面板 →“录制”，双击麦克风 →“级别”，确认没有静音且音量不是 0。

**预期结果**：系统里能看到输入电平，录音机能录到你的声音。

**失败怎么办**：系统里完全没有输入 → 继续步骤 2、5；系统正常但会议软件不行 → 跳到步骤 3。

### 步骤 2：检查 Windows 麦克风隐私权限

**目的**：系统总开关或单个应用权限关闭后，软件不会收到任何声音。

**操作**：
1. 设置 → 隐私和安全性 → 麦克风。
2. 打开“麦克风访问”和“允许应用访问你的麦克风”。
3. 在应用列表里找到会议、浏览器和录音软件，逐个允许。
4. 完全退出软件再重新打开，权限修改才会生效。

**预期结果**：系统总开关与应用开关都打开，会议软件能检测到输入电平。

**失败怎么办**：开关灰掉并显示“由组织管理” → 公司电脑联系 IT；个人电脑检查组策略或安全软件。

### 步骤 3：在会议软件里选对输入设备

**目的**：系统有多个麦克风时，软件可能一直使用已拔掉或不存在的设备。

**操作**：
1. 在会议软件设置中找到“音频”“麦克风”“输入设备”。
2. 选择与 Windows 声音设置相同的设备。
3. 关闭“自动调整麦克风音量”后测试；若声音太小，再手动把输入音量调到 70%-85%。
4. 检查软件里的静音按钮和快捷键，不要只看耳机上的灯。

**预期结果**：会议软件的输入电平随说话跳动，内置测试或预览能听到声音。

**失败怎么办**：软件里没有设备 → 重启软件；浏览器会议还要检查地址栏旁的站点麦克风权限。

### 步骤 4：重启音频设备与服务

**目的**：音频服务或端点设备卡住时，系统可能保留一个不可用的麦克风设备。

**操作**：
1. 运行上方 BAT，选择 `Y`。
2. 完成后在声音设置里重新选择输入设备。
3. 若有 USB 麦克风，换一个 USB 接口，避免经过无供电的扩展坞。
4. 蓝牙耳机在系统“蓝牙和设备”中断开再连接，并选择带“麦克风/免提”能力的模式。

**预期结果**：设备重新出现在列表里，输入电平恢复正常。

**失败怎么办**：设备仍然不出现 → 继续步骤 5。

### 步骤 5：检查驱动与硬件

**目的**：设备管理器看不到硬件时，继续改会议软件没有意义。

**操作**：
1. 右键开始菜单 → 设备管理器，展开“音频输入和输出”或“声音、视频和游戏控制器”。
2. 有黄色感叹号时，右键设备 → 属性，记录错误代码。
3. 笔记本优先到品牌官网按完整型号下载音频驱动；不要用聚合驱动工具批量替换。
4. USB 麦克风换电脑测试；内置麦克风在所有系统中都无声时，可能是排线或模组故障。
5. 装错驱动后参考 [驱动安装与回退](./driver-install-rollback.html)。

**预期结果**：设备管理器没有错误，系统能识别麦克风并采集声音。

**失败怎么办**：其他电脑也无声 → 外设本身故障；内置麦克风在恢复环境或外接系统中也无声 → 送修检查。

## 怎么确认修好了

用系统录音机录 10 秒并回放，波形和声音正常；在会议软件里测试 2 分钟，对方能连续听到且没有明显断续；重启电脑、休眠唤醒后各再测试一次，设备仍然存在。

## 预防

1. 会议前用系统录音机做 10 秒自检，确认输入设备名称。
2. Windows 更新和显卡、音频驱动更新后，再测试一次会议权限。
3. 蓝牙耳机注意区分“听音乐”和“通话”模式，避免误以为麦克风损坏。
4. 不安装宣称能“增强音质”但要求常驻录音权限的来源不明软件。
