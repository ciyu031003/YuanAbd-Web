# 电脑老是弹广告、浏览器主页被劫持改不回来

> ⚠️ 需谨慎：本文会卸载软件、清理启动项与计划任务，并会修改浏览器设置。清理前请确认重要 bookmark、密码已同步或导出。
> ⛔ 有数据风险：步骤 8 可能涉及重置此电脑或新建用户配置文件，动手前请备份重要数据。

## 一句话结论

先别急着改主页：主页改不回来，通常是某个常驻程序在每次开机时把设置写回去。先用任务管理器或 Process Explorer 定位弹窗是哪个进程弹的，卸载它，最后才处理浏览器主页和搜索设置。

## 30 秒快速排查

1. **弹窗出现的瞬间**：不要关，按 Ctrl+Shift+Esc 打开任务管理器 →「详细信息」标签，找可疑进程 → 右键 →「打开文件所在位置」，路径就是元凶的安装目录。
2. **看浏览器快捷方式**：右键桌面/任务栏的浏览器图标 →「属性」，如果「目标」末尾多了一串网址（如 `chrome.exe" http://xxx.com`），说明快捷方式被劫持。
3. **看扩展**：浏览器里打开 `chrome://extensions` 或 `edge://extensions`，删掉不认识的扩展。

## 小白一键修复

- 下载：[打开开机启动设置（.bat）](../scripts/open-startup-settings.bat)
- 适合：弹窗总在开机后不久出现，怀疑是某个常驻软件自启后在推广告。
- 脚本会：打开 Windows「启动应用」设置、任务管理器和两个启动文件夹，只开窗口不动任何开关。
- 运行前：无需管理员权限。
- 注意：脚本不会自动禁用或卸载任何软件，需要你对照正文把可疑自启项关掉；浏览器快捷方式被劫持请按正文检查「目标」栏。

## 适用 / 不适用

**适用：**
- 浏览器主页、搜索引擎被改成陌生网站，设置改回又被改走
- 桌面右下角定时弹广告窗口
- 打开浏览器就跳转到推广页面
- 桌面、收藏夹里莫名多出一堆图标和链接

**不适用（请转对应文章）：**
- 只是系统自带的「提示与建议」通知 → 属系统设置，见步骤 7
- 软件打不开、报缺 dll → [软件打不开、闪退，提示缺少 dll 或 0xc000007b](./win-app-crash-missing-dll.html)
- 电脑整体卡顿但没广告 → [电脑越来越卡怎么办：一张表定位是哪里卡](./win-slow-diagnose.html)
- 开机自启太多导致开机慢 → [开机太慢：关掉这些开机自启软件](./win-startup-apps-disable.html)
- 公司电脑出现弹窗或主页被策略修改 → 联系公司 IT

## 开始前确认

- [ ] 有管理员权限
- [ ] 已导出/同步浏览器书签和密码（清理扩展可能会重置部分设置）
- [ ] 记下弹窗出现的时间规律（开机后、固定整点、打开浏览器时）
- [ ] 回忆最近装过什么「下载器」「播放器」「PDF 工具」「系统优化」类软件
- [ ] 重要数据有备份

## 分步骤

### 步骤 1：定位弹窗到底是哪个进程弹的

**目的**：不找到源头，光改主页和删图标，第二天还会回来。

**操作**：
1. **快速法**：弹窗出现时按 `Ctrl+Shift+Esc` →「详细信息」标签，逐项右键 →「打开文件所在位置」，能打开目录的就是候选。
2. **精准法**：下载微软官方 Sysinternals 的 Process Explorer，右键 `procexp64.exe` 以管理员身份运行；把工具栏上的「准星」图标拖到弹窗上松开，列表中高亮的那一行就是弹窗进程。
3. 查看该进程的「公司名称」「数字签名」，没有签名或名字乱码的，基本就是流氓软件。
4. 也可以用 PowerShell 列出所有带可见窗口的进程：

```powershell
Get-Process | Where-Object { $_.MainWindowTitle } |
  Select-Object Id, ProcessName, MainWindowTitle, Path
```

**预期结果**：明确写出「哪个 exe、在哪个目录、属于哪个软件」。

**失败怎么办**：弹窗一闪就没了 → 用 Process Explorer 的 `View → Show Lower Pane` 配合持续观察，或改成查看步骤 2 的启动项清单。

### 步骤 2：顺藤摸瓜，查它靠什么自动运行

**目的**：找到自启方式，才能彻底断根。

**操作**：
1. 下载微软官方 Autoruns，以管理员身份运行 `Autoruns64.exe`。
2. 依次检查 `Logon`（登录启动）、`Scheduled Tasks`（计划任务）、`Services`（服务）三个标签。
3. 重点看「Image Path」指向步骤 1 找到的那个目录的条目。
4. 右键可疑项 → 先「取消勾选」临时禁用，观察几天没问题再删除。
5. 手工复查两处：
   - 任务计划程序：Win+R 输入 `taskschd.msc`，看「任务计划程序库」里触发器为「登录时」「启动时」的任务
   - 启动文件夹：Win+R 输入 `shell:startup`

**预期结果**：找到并禁用/删除所有指向该流氓程序的自启条目。

**失败怎么办**：不确定某项能否删 → 只取消勾选不要删除，观察稳定后再清理。

### 步骤 3：卸载来源程序并清理残留

**目的**：把软件主体卸掉，否则它会重新注册自启项。

**操作**：
1. 「设置 → 应用 → 已安装的应用」，按安装时间排序，找最近装的可疑程序，卸载。
2. 有些流氓软件不在列表里：用步骤 1 记录的目录，先结束进程（任务管理器 → 结束任务），再运行该目录里的 `uninstall.exe`。
3. 卸载后检查并删除残留目录（`C:\Program Files\可疑软件名`、`C:\Users\你的用户名\AppData\Local\可疑软件名`、`AppData\Roaming` 下的同名目录）。
4. 删除桌面和开始菜单里的可疑快捷方式。
5. 重启后再观察是否还有弹窗。

**预期结果**：弹窗消失，重启后不再出现。

**失败怎么办**：提示「文件正在使用」→ 先在任务管理器结束其进程再删，或重启后立刻删除；卸不掉 → 进安全模式再卸载。

### 步骤 4：用微软官方工具做一次全盘扫描

**目的**：流氓软件常捆绑木马，卸载后仍要确认系统干净。

**操作**：
1. Windows 安全中心 →「病毒和威胁防护」→ 扫描选项 →「完全扫描」，并打开「勒索软件防护」等基础防护。
2. 需要一次性深度扫描时，使用微软官方的 Microsoft Safety Scanner（免安装，下载后直接运行，扫描完成自动退出）。
3. 扫描结果里有威胁就按提示隔离或删除，然后重启。
4. 同时检查「设置 → 应用」里有没有没见过的浏览器、输入法、压缩软件、PDF 阅读器，一并卸载。

**预期结果**：扫描无威胁或威胁已被清除。

**失败怎么办**：反复扫描仍有威胁 → 用 Windows 安全中心的「脱机扫描」（Defender 脱机扫描），或在安全模式下扫描。

### 步骤 5：修复浏览器主页与搜索引擎

**目的**：弹窗源头处理干净后，再来修浏览器设置，否则会被反复覆盖。

**操作**：
1. **先查快捷方式**：右键浏览器图标 →「属性」→「目标」，正常应该只以 `chrome.exe` 结尾；如果后面跟着网址，把多出来的部分删掉（或删除该快捷方式，从开始菜单重新固定一个）。
2. **浏览器内设置**：
   - Chrome：`chrome://settings/onStartup` 设为「打开新标签页」；`chrome://settings/search` 改回常用搜索引擎；扩展页 `chrome://extensions` 删除不认识的扩展。
   - Edge：`edge://settings/startHomeNTP`、`edge://settings/search`、`edge://extensions` 同理。
   - Firefox：`about:preferences` 改主页与搜索引擎；扩展页 `about:addons` 清理；必要时用 `about:support` 里的「刷新 Firefox」。
3. **一键重置**：Chrome 用 `chrome://settings/reset`（将设置还原为原始默认值），Edge 用 `edge://settings/reset`。
4. 检查同步账户：如果书签和扩展会自动同步回来，先在浏览器里退出账号、清理完再登录。
5. 再检查任务栏固定项、开始菜单磁贴里有没有夹带网址的快捷方式。

**预期结果**：主页、搜索引擎、新标签页都恢复正常且重启浏览器不再反弹。

**失败怎么办**：设置改完立刻被改回 → 说明还有常驻程序没清干净，回到步骤 1、2 重新定位。

### 步骤 6：检查 hosts、DNS 与系统代理

**目的**：部分劫持不走程序，而是通过系统级配置把网页请求导向推广站。

**操作**：
1. **hosts 文件**：用记事本以管理员身份打开

```text
C:\Windows\System32\drivers\etc\hosts
```

   正常情况下这个文件只有以 `#` 开头的注释行；如果看到把常用网站域名指向某个 IP 的行，删掉该行并保存。注意：极少数正规软件也会写入条目，不确定就先备份该文件再改。

2. **DNS 设置**：「网络和 Internet → 高级网络设置 → 适配器」，右键正在使用的网卡 →「属性」→ 双击「Internet 协议版本 4 (TCP/IPv4)」，确认 DNS 是「自动获得」或你自己设置的常用 DNS，不是陌生地址。
3. **系统代理**：设置 →「网络和 Internet → 代理」，关掉不明来源的「使用代理服务器」；管理员命令提示符里查看：

```bat
netsh winhttp show proxy
```

4. 改完执行 `ipconfig /flushdns` 刷新 DNS 缓存，重启浏览器。

**预期结果**：hosts 干净、DNS 正常、代理关闭，浏览器不再跳转。

**失败怎么办**：公司电脑代理是 IT 配置的 → 不要改，联系 IT；改完断网 → 把 DNS 改回「自动获得」。

### 步骤 7：分清「系统通知广告」和真劫持

**目的**：有些推送不是病毒，而是系统自带的推荐内容，改设置即可。

**操作**：
1. 「设置 → 系统 → 通知」，关闭不需要的应用通知，尤其「获取有关 Windows 的提示和建议」。
2. 「设置 → 个性化 → 锁屏界面」，把背景从「Windows 聚焦」改为「图片」，可关闭锁屏上的推广内容。
3. 「设置 → 个性化 → 开始」，关闭「显示有关应用的建议」等推荐项。
4. 「设置 → 隐私和安全性 → 常规」，关闭「让应用使用广告 ID」等选项。
5. 这类通知的特点是：只出现在通知中心或锁屏，卸载软件无法解决，改了设置就好。

**预期结果**：不再出现系统级推广通知，也不再和弹窗广告混淆。

**失败怎么办**：区分不了 → 记住判据：能在任务管理器里找到进程的才是第三方弹窗；只在通知中心出现的属于系统设置项。

### 步骤 8：反复清不掉时的兜底方案

**目的**：有些流氓软件会重建自身，需要更强的手段。

> ⛔ 有数据风险：新建用户或重置系统会影响已安装的程序和部分个人设置，动手前请备份重要数据。

**操作**：
1. 先试安全模式：在安全模式下重复步骤 1-4，此时第三方程序无法自启，成功率更高。
2. 新建一个用户账户（「设置 → 账户 → 其他用户」，授予管理员），登录新账户观察是否还有弹窗：新账户干净说明问题在旧账户的配置里。
> ⛔ 有数据风险：重置此电脑会卸载所有已安装程序，选「删除所有内容」还会清空个人文件。执行前请再确认一次备份已完成。

3. 仍无解时：「设置 → 系统 → 恢复 → 重置此电脑」，选「保留我的文件」，重装后再把需要的软件从官网装一遍。
4. 公司设备、装有企业管控或加密软件 → 直接联系 IT，不要自行重置。

**预期结果**：系统恢复干净，主页不再被改。

**失败怎么办**：重装后立刻又出现 → 说明是你在重装后安装的某个软件带来的，逐个回忆并卸载。

## 怎么确认修好了

连续使用 3 天以上不再出现任何弹窗；关闭并重开浏览器、重启电脑后，主页和搜索引擎都保持在你设置的值；「任务管理器 → 启动」和 Autoruns 里不再有陌生条目；浏览器快捷方式「目标」中没有多余网址。

## 还是不行？

- 不确定弹窗是哪个程序，也找不到陌生进程 → 用 Process Explorer 抓一次截图，按步骤 1 重新定位
- 主页只在某个浏览器里被改，其他浏览器正常 → 该浏览器的扩展或配置文件问题，按步骤 5 重置
- 电脑同时明显变卡、CPU 常年高占用 → [电脑越来越卡怎么办：一张表定位是哪里卡](./win-slow-diagnose.html)
- 桌面出现陌生图标、开机总多出新启动项 → 回到步骤 2、3，重点检查计划任务
- 公司电脑装有统一管控软件、或反复重装也无法清除 → 联系公司 IT，或请专业人员现场处理

## 预防

1. 只从软件官网、微软商店等正规渠道下载软件，避开「高速下载器」和捆绑安装包。
2. 安装时选「自定义安装」，逐屏取消勾选附带的浏览器、输入法和「设为首页」。
3. 浏览器只装必要扩展，定期检查扩展列表。
4. 每周用 Windows 安全中心做一次快速扫描，保持系统自动更新开启。
5. 不要使用第三方「主页锁定」「IE 修复」「浏览器保护」类工具，它们本身就是劫持来源之一。
