DNS 被劫持怎么判断：打开网页要等很久 / 被插广告的根治方法

⚠ 需谨慎：本文会改路由器与系统的 DNS 设置——改之前截图记录原值，改错会导致整个家/这台电脑断网（恢复方法也给了）。判断劫持要拿证据，别凭「感觉慢」就乱改一通。

💡 一句话结论

DNS 劫持 = 你问路（域名解析），指路的人（DNS 服务器）被收买了——给你指到广告页、钓鱼站，或故意绕远路让你觉得慢。判断三板斧：ping 一个不存在的域名（居然能「解析成功」= 劫持实锤）、对比多个 DNS 的解析结果、查路由器 WAN/DHCP 下发的 DNS。根治 = 路由器与设备全改可信公共 DNS（223.5.5.5 / 119.29.29.29），中招的路由器顺手改密码升固件。

⚡ 30 秒快速排查（先试这个）

  1. 命令行跑 nslookup 不存在的域名随便起.test：
  2. 正常：报「找不到 xxx，不存在」（NXDOMAIN）。
  3. 劫持实锤：返回了一个 IP（劫持服务器，等着给你弹广告页）。
  4. nslookup www.qq.com 与 nslookup www.qq.com 223.5.5.5 对比：同一个域名，默认 DNS 与阿里公共 DNS 给出的 IP 不一致且默认那个指向奇怪地址 = 高度可疑。
  5. 登录路由器看「WAN 口状态 / DHCP 设置」里的 DNS 服务器：不是运营商常规地址（如 202.96.x.x 网通/电信段）也不是你设过的公共 DNS，而是陌生 IP → 路由器层被改。

适用 / 不适用

适用

  • 网页打开前「先转一下」再跳到带广告的页面、右下角弹窗。
  • 明显输入 A 网站却被带到 B 网站/导航站。
  • 所有网站都慢，且慢在「开始加载前」（DNS 解析阶段）。
  • 路由器 DNS 设置里出现陌生 IP。

不适用

  • 只是某个网站打不开：站点自身问题或被墙，不是劫持。
  • 微信能上网页打不开但无广告跳转：普通 DNS 故障，看「网页打不开但 QQ / 微信能用：DNS 问题怎么修」。
  • 浏览器主页被改：那是流氓软件层，看「电脑老是弹广告、浏览器主页被劫持改不回来」。
  • 公司网络的 DNS 由 IT 统一指定：别自行更改，先问 IT。

开始前确认

  • 已跑过 30 秒排查的 nslookup 三连，记录结果（判断在哪一层）。
  • 路由器管理后台能登录，管理密码记得。
  • 截图当前路由器 WAN/DHCP 里的 DNS 原值。
  • 知道可信公共 DNS：223.5.5.5（阿里）、119.29.29.29（腾讯）、114.114.114.114。

怎么确认修好了

  • nslookup 随便起.test 恢复「不存在」的标准回应。
  • 打开常用网站无广告跳转、无「先转一下再进」。
  • 路由器 DNS 设置保持手动公共 DNS，一周内没有自动变更。

还是不行？

  • 只有手机被插广告、电脑正常 → 检查手机装的山寨 Wi-Fi/清理类 App，卸载后观察。
  • 换 DNS 后部分网站反而打不开 → 某些公共 DNS 个别域名解析异常，换另一家（114 / 119.29.29.29）交叉验证。
  • 公司网络做不了任何改动 → 报 IT；家里做不到根治 → 保持设备级 DNS 手动设置 + 浏览器 DoH。

预防

  • 路由器到手第一件事：改管理密码 + 关远程管理 + 开自动固件升级。
  • DNS 永远手动设公共可信 DNS，不留给「自动获取」被下发的空间（家用场景）。
  • 浏览器开「安全 DNS（DoH）」，给解析再加一层加密保险。

更新日志

  • 2026-10-25 v1.0：首版发布。检测方法（NXDOMAIN 探测/多 DNS 对比）参照 Fortinet 与阿里云社区检测指引整理。

分步骤

  1. 定位劫持发生在哪一层

    按顺序排除：

    1. 本机 DNS 被改：ipconfig /all（macOS：网络详细信息）看「DNS 服务器」——出现陌生 IP（尤其非内网段）= 本机/木马层。
    2. 路由器层：路由器 WAN 口/DHCP 下发的 DNS 异常（见 30 秒排查第 3 条）。
    3. 运营商层：本机和路由器都干净、默认 DNS 仍劫持 → 运营商解析层问题。

    期望结果：锁定层。失败了怎么办：三层都看不出异常但症状在 → 可能是 HTTP 层插入而非 DNS 层，直接做步骤 2 换公共 DNS + 步骤 4 杀毒双管齐下。

  2. 设备与路由器全换可信公共 DNS

    1. 路由器（治全家）：后台 → WAN 口设置/DHCP 设置 → 手动 DNS 填 223.5.5.5 + 备用 119.29.29.29 → 保存重启路由器。
    2. Windows（单机兜底）：设置 → 网络 → 适配器属性 → IPv4 → 首选 DNS 223.5.5.5、备用 119.29.29.29。
    3. macOS：网络 → 详细信息 → DNS → 添加同样两条。
    4. 改完清缓存：Windows ipconfig /flushdns；macOS sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder。

    期望结果：劫持症状（广告跳转/慢解析）消失。失败了怎么办：换 DNS 后仍被插广告 → 不是 DNS 层，进步骤 3。

  3. 路由器侧的根治（被改过 DNS 的机器必做）

    被改过 DNS 的路由器 = 管理权曾经失守，光改回 DNS 不够：

    1. 改路由器管理密码（强密码；默认 admin/admin 是重灾区）。
    2. 关闭「远程管理/WAN 侧管理」功能。
    3. 升级固件到最新（老固件的漏洞就是被改 DNS 的入口），流程看「路由器固件升级与恢复出厂的正确姿势」。
    4. 重度中招（设置怎么改都会弹回）→ 直接恢复出厂重新配置。

    期望结果：路由器收复并加固。失败了怎么办：恢复出厂后 DNS 仍自动变回陌生 IP → 运营商层或光猫层问题，进步骤 4/5。

  4. 本机侧的根治（杀毒 + 代理残留检查）

    1. 全盘杀毒（Windows Defender 全盘扫描 + 顺手查「电脑中病毒了怎么办：先做这三件事再杀毒」的处置顺序）。
    2. 检查 hosts 文件有没有被加条目：C:\Windows\System32\drivers\etc\hosts（macOS：/etc/hosts），异常域名映射删掉。
    3. 检查系统代理残留（抓包工具/流氓软件留下的 127.0.0.1 代理），按「浏览器打不开网页但其他应用正常？浏览器代理与 PAC 设置修复」清理。

    期望结果：本机干净，解析路径无篡改。失败了怎么办：清不掉 → 按「系统改坏了进不去？安全模式、系统还原与重置的正确顺序」安全模式处理。

  5. 运营商层投诉 + 终极加密（DoH）

    1. 换公共 DNS 仍劫持（劫持发生在 53 端口透明拦截层）→ 打运营商客服投诉「DNS 劫持/网页插入广告」，报出现象与时间，工信部投诉渠道（小程序「工信部申诉」）是第二梯队，通常一投一个准。
    2. 终极方案：浏览器/系统开启 DNS over HTTPS（DoH）——加密的 DNS 查询让链路上的劫持者无从下手（浏览器设置 → 安全/隐私 → 使用安全 DNS）。

    期望结果：广告插入彻底消失。失败了怎么办：DoH 与公司网络/某些国内服务冲突 → 按场景开关，家庭网络保持开启。
