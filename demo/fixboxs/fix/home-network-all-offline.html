家里所有设备都上不了网：先分清是谁的问题

通用入门10-40 分钟✅ 安全

💡 一句话结论

全家断网时，问题几乎都在光猫、路由器或运营商的线路上，跟某台电脑无关。先看两台设备的指示灯，再看路由器里的 WAN/拨号状态，两边都正常才轮到查电脑。

⚡ 30 秒快速排查（先试这个）

  1. 用手机流量（关掉 Wi-Fi）打开一个网页。 期望：能打开，说明手机本身正常，问题在家里这条宽带；打不开就先解决手机流量问题。
  2. 看光猫的 LOS 灯。 期望：LOS 不亮或常灭 = 正常；红闪 = 光信号断了，直接报修。
  3. 断电重启：光猫先断 30 秒，通电等指示灯稳定，再给路由器通电。 期望：等 2-3 分钟，多数临时故障会自己恢复。

适用 / 不适用

适用：

  • 家里手机、电脑、电视盒子同时上不了网
  • Wi-Fi 名字能看到、也能连上，但所有设备都打不开网页
  • 光猫或路由器上有红灯、指示灯异常
  • 路由器刚重启完、或者刚停电/打雷之后就没网了

不适用（请转对应文章）：

  • 只有一台电脑上不了网，手机正常 → Wi-Fi 显示已连接但无法上网（打不开网页）
  • 手机搜不到自家 Wi-Fi 名字 → Wi-Fi 列表里找不到自家网络怎么办
  • 想进路由器后台看设置却打不开页面 → 路由器后台 192.168.1.1 打不开怎么办
  • 电脑单独提示拿不到 IP 地址 → 电脑获取不到 IP 地址 / IP 是 169.254 开头
  • 是公司、店铺、出租屋的整栋网络 → 直接联系 IT 或网管

开始前确认

  • 手机能切到移动数据（用来上网查资料和打客服电话）
  • 能找到光猫和路由器，并看清它们的指示灯
  • 知道宽带是哪家运营商（电信 / 移动 / 联通 / 广电等）
  • 尽量找到办宽带时的宽带账号、密码或业务受理单（改路由器拨号设置时要用）
  • 路由器管理地址和登录密码（一般贴在机身底部标签上）

怎么确认修好了

同时满足：

  1. 光猫 Power、PON 常亮，LOS 熄灭；路由器 WAN 灯亮；
  2. 路由器后台的 WAN 状态显示"已连接"并带有 IP 地址；
  3. 家里至少两台设备（例如手机 + 电脑）分别用不同浏览器打开 2 个网站都能正常显示。

还是不行？

  • 光猫 LOS 红闪、PON 不亮 → 外部线路或光猫故障，联系运营商报修
  • 光猫正常、路由器 WAN 灯不亮或拨号失败 → 先换网线、换光猫 LAN 口；仍不行联系运营商确认是否需要更换光猫
  • 路由器后台进不去 → 看 路由器后台 192.168.1.1 打不开怎么办
  • 只有一台电脑不行 → 看 Wi-Fi 显示已连接但无法上网（打不开网页）；公司/学校设备联系 IT
  • 反复出现、每次重启只能好一会儿 → 记录出现时间与指示灯状态，报修时提供给运营商，必要时要求上门检测线路

预防

  1. 给光猫和路由器留出通风空间，不要堆在杂物柜里，也不要频繁拔插电源。
  2. 宽带到期前留意运营商短信/App 提醒，避免因欠费突然停网。
  3. 把宽带账号密码、路由器管理地址和密码记在纸上或密码管理器里。
  4. 雷雨季节给光猫、路由器加装合格的防雷插排，打雷时尽量断电。
  5. 每 1-2 个月重启一次光猫和路由器，固件提示更新时及时升级。

分步骤

  1. 分清是"全家断网"还是"只有一台设备"

    目的：这是唯一能决定后面方向的一步，做错了后面全是无用功。

    操作：用 2 台设备测试——手机（连 Wi-Fi）和另一台电脑或平板（连同一个 Wi-Fi），各自打开一个网页。

    预期结果：
    • 两台都不行 → 全家断网，继续步骤 2
    • 只有一台不行 → 问题在那台设备上，转 Wi-Fi 显示已连接但无法上网（打不开网页）
    失败怎么办？
    有设备连的是手机热点或邻居的 Wi-Fi，先确认连的是自家网络；智能电视、扫地机器人等设备可能只支持 2.4GHz，不能作为"全家断网"的判据。

  2. 看光猫（ONU）的指示灯

    目的：光猫负责把运营商的光信号转成网络，它的灯能直接告诉你"外面那条线"是否正常。

    操作：观察光猫面板上的指示灯，对照下表判断。

    指示灯正常状态异常状态与含义该做什么
    Power / 电源常亮不亮 = 没通电或设备坏检查电源适配器和插座
    PON常亮闪烁/熄灭 = 未在运营商局端注册成功重启光猫；仍不行报修
    LOS熄灭红色闪烁 = 光信号丢失不要自己拆光纤，直接报修
    LAN / 网口亮或闪不亮 = 与路由器没连上检查网线两端是否插紧
    Internet / 网络常亮熄灭 = 未建立上网连接重启光猫和路由器
    ✅
    不同品牌光猫的灯名和位置不一样，以设备机身标识和运营商说明为准。
    预期结果：Power、PON 常亮，LOS 熄灭，LAN 灯闪烁。
    失败怎么办？
    LOS 红闪、PON 不亮 → 基本可以判定是外部线路或光猫故障，直接跳到步骤 6，不要自行拆机。

  3. 看路由器的指示灯

    目的：路由器负责拨号和分发网络，看它的 WAN 灯就知道"拨号是否成功"。

    操作：观察路由器面板，对照下表。

    指示灯正常状态异常状态与含义该做什么
    Power / 电源常亮不亮 = 没通电换插座、检查电源头
    WAN / Internet常亮或规律闪烁熄灭或慢闪 = 没有连上外网检查 WAN 口网线是否插到光猫的 LAN 口
    SYS / 系统有规律闪烁长亮不闪 = 系统卡死断电 30 秒重启
    Wi-Fi / WLAN常亮或闪熄灭 = 无线被关闭按机身上的 Wi-Fi 按钮或登录后台开启
    LAN 1-4插了设备才亮不亮 = 该口没连通换网线或换端口
    ✅
    部分路由器只用颜色表示状态（例如绿灯正常、红灯异常），具体含义以厂商说明为准。
    预期结果：Power 与 SYS 正常，WAN 灯亮。
    失败怎么办？
    WAN 灯始终不亮 → 优先怀疑网线或光猫端口，换一根网线、换光猫的另一个 LAN 口再试。

  4. 按正确顺序断电重启

    目的：光猫和路由器都需要重新向运营商拨号，顺序错了会一直失败。

    操作：

    1. 拔掉光猫和路由器的电源，等 30 秒。
    2. 先给光猫通电，等 2 分钟，确认 PON 常亮、LOS 熄灭。
    3. 再给路由器通电，等 1-2 分钟，看 WAN 灯是否亮起。
    预期结果：光猫灯正常后，路由器 WAN 灯在 1 分钟内亮起，设备恢复上网。
    失败怎么办？
    重启两次仍然不行，进入步骤 5 看拨号状态；如果是刚停电或雷雨后出现，且 LOS 红闪，直接跳到步骤 6 报修。

  5. 登录路由器看 WAN（上网）状态

    目的：路由器后台会直接告诉你"拨号失败"还是"已连接但没网"。

    操作：

    1. 用手机或电脑连上路由器，打开浏览器，输入机身标签上的管理地址（常见 192.168.1.1、192.168.0.1、192.168.31.1、tplogin.cn）。
    2. 找到「上网设置 / 外网设置 / WAN」页面，查看： - 连接类型是 PPPoE 拨号、动态 IP 还是静态 IP； - WAN 口是否获取到 IP 地址（0.0.0.0 表示没拿到）； - 是否有"拨号失败""未连接""正在连接"字样和错误提示。

    常见拨号错误提示与含义（不同品牌表述不同，以厂商和运营商说明为准）：

    错误提示常见含义先做什么
    691 / 用户名密码错误宽带账号或密码填错核对受理单；忘记密码找运营商重置
    678 / 651 / 远程计算机无响应拨号没有回应重启光猫；线路问题则报修
    769 / 无法访问指定目标本机网卡或网线问题换网线、换端口
    拨号一直显示"正在连接"光路或局端问题看 LOS 灯后报修
    获取不到 IP / DHCP 失败线路侧没有下发地址报修，同时记录具体提示
    预期结果：WAN 口状态显示"已连接"，并拿到一个公网或运营商内网 IP 地址。
    失败怎么办？
    进不去管理页面 → 看 路由器后台 192.168.1.1 打不开怎么办；账号密码不确定不要反复试，避免被锁定，直接联系运营商核对。

  6. 查欠费、停网和运营商故障

    目的：很多"全家断网"其实是宽带到期、欠费或片区故障。

    操作：

    1. 打开办理宽带那家运营商的官方 App 或官网，查看宽带是否欠费、是否到期、是否有片区故障公告。
    2. 打运营商客服电话咨询（中国电信 10000、中国移动 10086、中国联通 10010，以运营商官方公布为准），说明"光猫 LOS 红闪/路由器拨号失败"。
    3. 报修时准备好：宽带账号或办理手机号、地址、光猫上的指示灯状态。
    预期结果：确认是欠费/停网/线路故障，缴费或等运营商处理。
    失败怎么办？
    客服说是线路正常，就请对方远程检测端口状态，并记下工单号；不要相信任何主动上门收费"提速"的陌生电话。

  7. 若以上都正常，回到单台设备排查

    目的：光猫、路由器、运营商都正常时，问题就只剩电脑或手机自身。

    操作：在路由器后台确认 WAN 正常后，用一台电脑连 Wi-Fi，先做两条最基础的连通性测试。

    Windows（命令提示符，网关地址换成 ipconfig 里看到的默认网关）：

    ping 192.168.1.1
ping 223.5.5.5
nslookup www.baidu.com

    macOS（终端）：

    ping -c 4 192.168.1.1
ping -c 4 223.5.5.5
nslookup www.baidu.com

    然后按 Wi-Fi 显示已连接但无法上网（打不开网页） 里的四层定位法（物理层 → IP 层 → DNS 层 → 代理层）逐层判断。

    预期结果：定位到具体是某一台设备的 DNS、代理或网卡问题。
    失败怎么办？
    所有设备都正常、只有某一台不行且重装系统级网络设置也没用，考虑该设备网卡硬件问题，送修或联系 IT。
