隔空投送用不了：搜不到设备 / 一直等待 / 传到一半失败

💡 一句话结论

隔空投送 = 蓝牙发现 + Wi-Fi 直连传输，两副链条缺一不可：搜不到是「发现」层的问题（蓝牙/接收范围设置/专注模式），搜到了却卡在「正在等待」是「传输」层的问题（Wi-Fi 干扰、个人热点抢占、防火墙）。按「先发现、后传输」的顺序查，九成在五分钟内解决。

⚡ 30 秒快速排查（先试这个）

  1. 双方各开 Wi-Fi 和蓝牙（不用连同一个 Wi-Fi，但要都开着），并关闭个人热点——热点会让 Wi-Fi 模块退出直连模式。期望结果：重新打开访达 → 隔空投送，能看到对方。
  2. 接收设置改成「所有人 · 10 分钟」：Mac 在控制中心 → 隔空投送；iPhone 在设置 → 通用 → 隔空投送。传完再改回「仅限联系人」。期望结果：立即可见。
  3. 关掉专注模式：Mac 与 iPhone 的勿扰/专注会静默拒绝隔空投送请求。

适用 / 不适用

适用

  • 访达「隔空投送」里始终看不到附近设备。
  • 能看到对方头像，点发送后对方一直显示「正在等待」。
  • 传输到一半失败或速度极慢。
  • iPhone → Mac 或 Mac → iPhone 单方向不通。

不适用

  • Mac 蓝牙完全打不开/搜不到任何蓝牙设备 → 先看「Mac 蓝牙不可用」，那是底层问题。
  • Wi-Fi 本身断连 → 先修网络：「Mac 的 Wi-Fi 反复断连」。
  • 只是嫌隔空投送慢、要传几十 GB → 用线：U 盘/移动硬盘方案见「U 盘无法识别」。
  • 公司网络屏蔽了设备发现（AP 隔离）→ 换个人热点试，或联系网管。

开始前确认

  • 两台设备距离 9 米以内、中间没有厚墙。
  • 两台都是 2012 年之后的 Mac / 较新的 iPhone（更早的机型不支持发现模式）。
  • 双方系统都是较新版本（隔空投送行为随版本变过好几轮）。

怎么确认修好了

  • 访达隔空投送面板稳定出现对方设备。
  • 连续互传 3 个文件（含 1 个几百 MB 的）全部成功。
  • 传完后把接收设置改回「仅限联系人」，隔天再传一次仍然正常。

还是不行？

  • 单向不通（iPhone 能发 Mac 收不到）→ 在 Mac 上新建一个测试用户账户试一次，排除个人配置问题。
  • 换了网络环境、重置过无线仍不行 → Apple 官方诊断：Apple Silicon 重启时长按电源键进选项按 Command-D（Intel 按 D）跑硬件诊断，看无线模块是否报错。
  • 是公司/学校 Mac → IT 可能用配置描述文件锁死了隔空投送，找 IT。

预防

  • 平时接收设置保持「仅限联系人」，别长期开「所有人」——机场地铁里会被陌生人投垃圾图。
  • 定期重启 Mac，长期不重启是无线模块抽风的最大来源。
  • 需要传大文件时，提前关掉热点和 VPN。

分步骤

  1. 修「发现」层——让双方互相看见

    1. Mac 打开访达 → 边栏「隔空投送」；iPhone 打开「隔空投送」接收面板，两个窗口同时开着。
    2. Mac 侧确认控制中心：Wi-Fi ✓、蓝牙 ✓、隔空投送 = 仅限联系人或所有人；iPhone 侧同样确认。
    3. 关闭双方专注模式/勿扰。
    4. 接收方临时改成「所有人 · 10 分钟」再测。

    期望结果：发送方列表出现对方头像。失败了怎么办：进步骤 2。

  2. 重置无线模块

    1. 两台设备都关闭再打开 Wi-Fi 和蓝牙（控制中心里直接点）。
    2. 没效果就把两台设备都重启——社区案例里这解决最多。
    3. Mac 再试一次隔空投送。

    期望结果：搜到并可发送。失败了怎么办：仍卡「正在等待」→ 步骤 3（传输层）。

  3. 修「传输」层——卡在「正在等待」

    1. 确认 Mac 没开个人热点，也没连着 VPN（VPN 会改路由，直连打不通）。
    2. 检查 Mac 防火墙：系统设置 → 网络 → 防火墙 → 若开着，进「选项」确认没有阻止性的严格策略（临时关掉防火墙测一次最能说明问题）。
    3. 换个环境试：离开当前 Wi-Fi 环境（隔空投送不需要网络，但拥挤的公共 Wi-Fi 信道会干扰直连）。
    4. 大文件（几 GB）中途失败 → 先传一个小文件确认链路，再把大文件分批传。

    期望结果：小文件秒传成功，大文件分批传完。失败了怎么办：小文件也一直等待 → 步骤 4。

  4. 检查账号与系统状态

    1. 「仅限联系人」模式要求双方登录 Apple 账户且互为联系人：确认接收方的 Apple 账户邮箱/手机号就在发送方通讯录里。
    2. 两台设备都更新到最新系统（隔空投送协议随系统演进，版本差太多会握手失败）。
    3. Apple Silicon 与 Intel 混用时发现慢是正常的——先传一次，第二次就快了。

    期望结果：链路稳定，不再反复掉。失败了怎么办：彻底无解 → 用「接力」或微信文件传输助手替代，或用线传（U 盘/移动硬盘）。
