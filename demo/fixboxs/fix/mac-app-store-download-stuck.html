Mac App Store 下载卡住 / 应用装不上怎么修

✅
本文不会删除已安装应用或账户购买记录。退出 Apple 账户再登录前，请确认自己记得密码并能接收双重认证验证码。

💡 一句话结论

App Store 卡在“等待中”，通常是下载队列、网络、日期时间或账户登录状态不同步，不等于应用损坏。先暂停再继续下载，再检查网络和储存空间；仍然不行才退出 Apple 账户重新登录。

⚡ 30 秒快速排查（先试这个）

  1. App Store 底部点“下载”或“账户”，在更新列表里找到卡住的项目，先暂停再继续。
  2. 用 Safari 打开一个普通网页，再打开 Apple 系统状态页面，确认不是整个网络断了。
  3. 打开系统设置 → 通用 → 储存空间，确认至少有 10% 空闲空间。

适用 / 不适用

适用：

  • 下载进度长时间停在“等待中”或 0%
  • 更新按钮点击后没有反应
  • 已购应用显示云朵图标但无法下载
  • App Store 能打开，搜索也正常，只有安装失败

不适用：

  • 整台 Mac 所有网站都打不开 → 先检查 Wi-Fi 和 DNS
  • Safari 单独打不开网页 → 看 Mac Safari 打不开网页
  • macOS 系统更新卡住 → 系统更新与 App Store 不是同一通道
  • 公司或学校 Mac 禁止安装软件 → 联系设备管理员

开始前确认

  • Mac 电量充足或已接电源
  • 知道 Apple 账户密码与双重认证设备
  • 没在使用会拦截 Apple 服务的公司代理或家长控制
  • 已确认应用支持当前 macOS 版本

怎么确认修好了

先下载一个体积较小的免费应用测试，进度能开始并完成安装；再更新一个已有应用；重启 Mac 后打开 App Store，下载列表没有重新卡住。

还是不行？

  • 整台 Mac 网络都不稳定 → 检查 Wi-Fi、DNS、代理和路由器
  • 只有 Safari 网页异常 → Mac Safari 打不开网页
  • 储存空间持续不足 → Mac 储存空间不足怎么清理
  • 聚焦、App Store 和 Finder 同时异常 → 检查系统更新、磁盘健康和第三方清理工具
  • 提示账户问题 → 从 Apple 官方账户恢复流程处理，不向来路不明网站提供验证码

预防

  1. 保持日期、时区和 Apple 账户双重认证正常。
  2. 不在下载时同时切换 VPN、代理和网络。
  3. 为系统盘保留足够空间，避免更新和应用缓存反复失败。
  4. 软件优先从 App Store 或开发商官网下载，不使用聚合站安装包。

分步骤

  1. 处理卡住的下载队列

    目的：App Store 可能同时排队多个下载，前面的任务卡住会挡住后续应用。

    操作：

    1. 打开 App Store，点左下角账户或“下载”。
    2. 找到正在下载或显示“等待中”的项目，点圆形暂停按钮。
    3. 等 10 秒后继续，观察进度是否变化。
    4. 如果多个任务同时进行，先暂停其他任务，只保留一个下载。
    5. 按 Command+R 重新载入 App Store 页面。
    预期结果：进度开始变化，按钮从“等待中”变成百分比或“停止”。
    失败怎么办？
    仍然不动 → 重启 App Store 和 Mac，再继续步骤 2。

  2. 检查网络、日期与 Apple 服务状态

    目的：证书和账户验证依赖正确时间，网络代理也会让商店连接失败。

    操作：

    1. 断开 VPN、公司代理和第三方网络加速器，改用普通 Wi-Fi 或手机热点测试。
    2. 系统设置 → 通用 → 日期与时间，打开自动设置日期和时间、自动设置时区。
    3. 访问 Apple“系统状态”页面，确认 App Store 没有大范围故障。
    4. 如果使用内容过滤或防火墙，临时允许 App Store 后测试，完成后恢复安全设置。
    预期结果：网络可访问 Apple 服务，日期时间正确，App Store 能刷新账户页面。
    失败怎么办？
    仅某个网络失败 → 检查路由器、DNS 或代理；所有网络都失败 → 继续账户排查。

  3. 检查储存空间和应用兼容性

    目的：空间不足或系统版本不满足要求时，App Store 可能只显示“等待中”而不给明确提示。

    操作：

    1. 打开系统设置 → 通用 → 储存空间，确认可用空间大于应用标注大小的两倍。
    2. 在 App Store 应用页面向下查看“兼容性”，确认支持当前 macOS。
    3. 删除不再使用的安装包和下载缓存，但不要直接删除不认识的系统文件。
    4. 重启 Mac 后再次下载。
    预期结果：空间充足，应用兼容当前系统，重新下载有明确进度或错误码。
    失败怎么办？
    空间仍不足 → 参考 Mac 储存空间文章；应用不兼容 → 找开发商提供的兼容版本或官网下载渠道。

  4. 刷新 Apple 账户登录状态

    目的：账户令牌过期时，商店能显示购买记录，却无法开始或验证下载。

    操作：

    1. 记下当前 Apple 账户邮箱，确认双重认证可用。
    2. App Store 左下角账户 → 退出登录。
    3. 重启 Mac。
    4. 重新登录同一个 Apple 账户，同意必要条款后重试。
    5. 若使用家人共享，确认当前账户仍有下载权限。
    预期结果：账户页面正常刷新，已购应用出现云朵下载按钮，下载可以开始。
    失败怎么办？
    提示“账户被停用”“需要验证” → 按 Apple 官方提示处理账户问题，不要反复猜测密码。

  5. 安全模式与系统更新

    目的：第三方安全、同步或网络软件可能拦截 App Store；系统组件也可能需要更新。

    操作：

    1. 正常重启一次 Mac。
    2. 仍然失败时进入安全模式，再打开 App Store 测试。
    3. 如果安全模式正常，退出登录项中的 VPN、网络过滤、清理和同步软件后再测。
    4. 打开系统设置 → 通用 → 软件更新，安装可用的 macOS 更新并重启。
    预期结果：安全模式能下载说明第三方软件干扰；更新后错误码消失，下载恢复。
    失败怎么办？
    不同应用都失败且账户正常 → 联系 Apple 支持，提供错误码、macOS 版本和发生时间。
