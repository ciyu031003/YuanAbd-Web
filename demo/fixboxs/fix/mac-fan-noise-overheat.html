Mac 风扇狂转、机身发烫怎么办

macOS 12+入门15-40 分钟✅ 安全

💡 一句话结论

风扇狂转多半不是硬件坏了：先打开「活动监视器」按 CPU 排序，找出长时间占满处理器的程序，再检查散热环境和后台备份有没有卡住。

⚡ 30 秒快速排查（先试这个）

  1. 打开「活动监视器」（访达 → 应用程序 → 实用工具），点「CPU」标签，再点「% CPU」列排序，看排在前三名的程序。期望：能说出占 CPU 最高的那个名字。
  2. 正常退出那个程序（不要强制退出名字里带 com.apple 的系统进程），等 2 分钟再听风扇。期望：噪音明显变小、机身温度下降。
  3. 把 Mac 挪到硬质平面上（桌面、支架），别放在被子、沙发、抱枕或腿上，拔掉不用的外接硬盘和扩展坞，改用原装或合规充电器。期望：机身底部进风口和转轴处出风口不被遮挡。

适用 / 不适用

适用：

  • 风扇长时间高速转，机身明显发烫，但电脑还能正常用
  • 待机（没开大程序）时风扇也一直响
  • 每次打开某个软件就开始响
  • 系统更新、照片分析、时间机器备份之后一直响

不适用（请转对应文章）：

  • 磁盘快满、系统整体卡顿，怀疑是空间不足引起的负载 → Mac 储存空间不足 /「系统数据」占了上百 G
  • 风扇有咔哒声、摩擦声、机身变形或有液体泼溅/跌落 → 属于硬件问题，直接看 Mac 硬件异常与送修判断
  • 电脑根本进不去系统、反复重启 → Mac 无法开机 / 反复重启怎么办
  • 电池鼓包、机身被顶起 → 立即停止使用并联系 Apple 支持或 Apple 授权服务商

开始前确认

  • Mac 已接电源，或电量高于 30%
  • 知道开机密码（进入安全模式、重置 SMC 时需要）
  • 已保存并退出正在编辑的文档
  • 大致记下：什么时候开始响、响之前装过什么软件、是不是插了扩展坞或外接显示器
  • 公司/学校统一管理的 Mac，安装更新或改系统设置前先问 IT

怎么确认修好了

在插电、屏幕亮着、不运行大型程序的状态下观察 10 分钟，同时满足三条才算修好：

  1. 活动监视器里 CPU 总占用低于约 10%，且前几名是你熟悉的程序；
  2. 终端执行 pmset -g therm，CPU_Speed_Limit 回到 100；
  3. 风扇噪音明显回落（贴近出风口能感觉到风但不刺耳），机身不再烫手。

还是不行？

  • 主要问题是磁盘快满、系统卡顿 → 去 Mac 储存空间不足 /「系统数据」占了上百 G
  • 只在某个软件运行/开机自启时出现 → 卸载该软件，或在「登录项」里关掉它
  • 安全模式下正常、正常启动就狂转 → 逐项排查第三方登录项与后台程序
  • Apple 诊断报出参考代码、风扇机械异响、液体泼溅或跌落 → 送修：预约 Apple Store 或 Apple 授权服务商；公司/学校设备先联系 IT

预防

  1. 不要把笔记本放在被子、沙发、抱枕或腿上使用，尽量用硬质支架垫高机身。
  2. 每周花 1 分钟看一眼活动监视器，退出不用的虚拟机和浏览器标签页。
  3. 保持启动磁盘至少 15% 的可用空间，磁盘太满会让系统整体负载升高。
  4. 每 3 到 6 个月清理一次进风口/出风口的灰尘（关机断电后，用气吹或软毛刷）。
  5. 夏天避免在高温环境长时间满负载运行渲染、游戏或视频导出。

分步骤

  1. 判断是真过热还是只是风扇吵

    目的：确认系统是不是真的在因为温度限制性能，避免白折腾散热。

    操作：打开「终端」（访达 → 应用程序 → 实用工具 → 终端），执行：

    pmset -g therm

    想看得更细，可以临时执行（需要管理员密码，输出较专业）：

    sudo powermetrics -n 1 -i 1000 | head -40
    预期结果：pmset -g therm 显示 CPU_Speed_Limit 一行的数值，正常是 100；如果明显低于 100，说明系统正在给 CPU 限频降温。同时在活动监视器的「CPU」标签里，总占用长期高于 50%。
    失败怎么办？
    提示 command not found 说明输错了命令；powermetrics 要求管理员密码，输入时不显示字符是正常的。如果两条命令都不认，直接看活动监视器的 CPU 和「能耗」两个标签即可。

  2. 找出占 CPU 的程序

    目的：风扇狂转的本质是"有东西在长期占用处理器"，先抓到它。

    操作：活动监视器 → 「CPU」标签 → 点「% CPU」列排序，观察 1 分钟。也可以在终端执行：

    ps -Ao pcpu,comm -r | head -n 11
    预期结果：能列出占用最高的 10 个进程。常见"元凶"和处理方式见下表。
    进程名它是什么怎么处理
    mds / mdworker / mds_storesSpotlight 正在重建索引通常几小时内自己结束；刚升级系统或刚恢复备份时正常，先等
    backupd时间机器正在备份等它备份完；tmutil status 可看进度
    photolibraryd / photoanalysisd照片图库在分析人脸和场景让它跑完，别中途关；别在此时做大量照片导入
    kernel_taskmacOS 的散热管理进程它高占用往往是"系统在限频降温"，处理办法是关掉其它高负载程序并改善散热，不要强行结束它
    浏览器视频、网页游戏、太多标签页关掉不看的标签页，退出后台播放的视频
    Docker / 虚拟机容器和虚拟系统不用时退出，而不是最小化
    Xcode / 模拟器编译和模拟器退出模拟器，清 DerivedData
    不认识的程序可能是挖矿类恶意软件查来源，用系统自带方式卸载；不要轻信"一键清理"工具
    失败怎么办？
    活动监视器里进程一闪就没了，说明是短时任务，不是元凶；抓不到就改用「能耗」标签看"12 小时电量"一列，找出长期大户。

  3. 按嫌疑逐个收尾

    目的：把"临时关掉"变成"以后不再反复"。

    操作：

    1. 打开系统设置 → 通用 → 登录项，关掉不需要开机自启的程序。
    2. 检查磁盘空间：系统设置 → 通用 → 储存空间，可用空间低于 15% 会明显加重系统负担，此时先处理空间问题。
    3. 打开软件更新，把 macOS 更新到当前版本。
    4. 重启一次 Mac（很多临时负载重启就消失）。
    预期结果：重启后待机 10 分钟，活动监视器 CPU 总占用降到 10% 以下，风扇转速回落。
    失败怎么办？
    重启后依旧高，进下一步；如果只在装了某个软件后出现，先卸载该软件再看。

  4. 改善散热环境与供电

    目的：同样负载下，散热条件差会让风扇一直高速转。

    操作：

    • 把 Mac 放在硬质、平整、通风的平面上，别挡进风口和出风口。
    • 取下会盖住键盘/底部的保护壳、键盘膜。
    • 环境温度保持在 10°C 到 35°C 之间（Apple 对 Mac 笔记本的使用温度建议）。
    • 用原装充电器或通过 Apple 认证的充电器；边充边跑大型程序会更热。
    • 查看电池状态：
    system_profiler SPPowerDataType | grep -A 6 "电池信息"
pmset -g batt
    预期结果：电池状态显示「正常」，循环计数在合理范围；移走遮挡物、换到硬质平面后风扇转速下降。
    失败怎么办？
    电池状态显示「建议维修」或「更换电池」，或机身有鼓包，停止私自处理，预约 Apple 支持或授权服务商。

  5. 系统层面排查（安全模式 / SMC）

    目的：排除第三方软件和电源管理状态异常。

    操作：

    1. 安全模式排查：Apple 芯片 Mac 关机后按住电源键不放，出现启动选项后，按住 Shift 选择启动磁盘，再点「以安全模式继续」；Intel Mac 开机立即按住 Shift 键直到看到登录窗口。在安全模式下观察风扇是否还狂转，然后正常重启。
    2. 重置 SMC（仅 Intel Mac 需要，Apple 芯片机型不需要）：具体按键顺序按 Apple 官方文档操作，见文末来源。
    3. 重置 NVRAM（仅 Intel Mac）：同样以 Apple 官方文档为准。
    预期结果：安全模式下风扇正常 → 说明是某个第三方登录项或后台程序导致，回到步骤 3 排查登录项；安全模式下也狂转 → 更可能是硬件或系统本身的问题。
    失败怎么办？
    不记得自己是不是 Intel Mac，可在「关于本机」里看芯片一栏（Apple M 开头就是 Apple 芯片）；拿不准就别做重置，直接进入步骤 6。

  6. 怀疑硬件时用 Apple 诊断

    目的：用官方自检区分"软件负载"和"硬件故障"。

    操作：

    1. 关机。
    2. Apple 芯片 Mac：按住电源键开机，出现启动选项后按住 Command (⌘) + D；Intel Mac：开机时按住 D 键（联网诊断按住 Option + D）。
    3. 等待诊断完成，记下参考代码。
    预期结果：显示「未检测到问题」，或者给出一个参考代码（例如以 PPN、NDD、VFD 开头的代码）。
    失败怎么办？
    出现任何参考代码、或风扇在没有高 CPU 占用的情况下持续满速、或有异响，都不要再自行拆机，带上参考代码联系 Apple 支持或 Apple 授权服务商；公司设备先联系 IT。
