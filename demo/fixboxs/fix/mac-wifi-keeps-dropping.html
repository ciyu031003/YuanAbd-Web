Mac 的 Wi-Fi 反复断连 / 自己关掉怎么修

⚠ 需谨慎：本文会「删除 Wi-Fi 网络配置并重连」，这会清掉该网络在这台 Mac 上的记忆（重新输密码即可），不影响其他设备。改动系统网络配置前，先记住当前的 DNS 与代理设置（有的话），方便复原。

💡 一句话结论

Mac Wi-Fi 断连先分清「只有 Mac 断还是「全家都断」：手机同网正常 → 问题在 Mac 这边，走「忘记网络重连 → 新建网络位置 → 关 VPN/代理干扰 → 无线诊断」；全家都断 → 是路由器侧，看路由器专题。Apple 官方排查顺序里最容易被忽略的是检查 VPN 与安全软件和日期时间——时差过大会让 Wi-Fi 的认证直接失败。

⚡ 30 秒快速排查（先试这个）

  1. 掏出手机连同一个 Wi-Fi 刷视频。期望结果：手机正常 → 走本文（Mac 侧）；手机也断 → 看「家里所有设备都上不了网怎么办」和「某些房间 WiFi 信号差怎么优化」。
  2. 系统设置 → Wi-Fi，把开关关 10 秒再开。期望结果：相当一部分「假死」就此恢复。
  3. 看日期时间：系统设置 → 通用 → 日期与时间 → 打开「自动设置」。期望结果：时区正确——Apple 官方排查表里明确列了这一项，时差大会导致认证类 Wi-Fi（公司/校园网）反复掉线。

适用 / 不适用

适用

  • MacBook/iMac 的 Wi-Fi 每隔几分钟断一次、图标闪断。
  • 合盖再打开后 Wi-Fi 必断、要手动重连。
  • Wi-Fi 显示已连接但「自分配 IP」上不了网。
  • 只在某一个网络（家里/公司）断，别处正常。

不适用

  • 全部设备都断网：路由器/宽带问题，看家庭网络专题。
  • Wi-Fi 图标直接消失/开关变灰：网卡层面问题，重启不行就送修。
  • 有线网络的问题：与本文无关。
  • 能连上但网速慢：先按「网速慢怎么定位：是宽带、路由器还是电脑的问题」分层。

开始前确认

  • 手机在同一 Wi-Fi 下测试过（确定范围）。
  • 记下当前 Wi-Fi 名称与密码（要「忘记」后重连）。
  • 知道自己装没装 VPN / 代理 / 「安全软件」（CleanMyMac 类）。
  • 系统设置为自动时区。

怎么确认修好了

  • 连续使用 2 小时（含合盖开盖几次）Wi-Fi 无自动断开。
  • Wi-Fi 详细信息里 IPv4 是路由器网段的正常地址，非 169.254。
  • 视频会议 30 分钟不掉线。

还是不行？

  • 只在特定网络断 → 该路由器与 Mac 网卡的兼容问题：路由器固件升级、2.4G/5G 分开命名分别试。
  • 全新 Mac 持续断连 → 走保修检测天线，新机硬件问题不罕见。
  • 公司网络断连 → 可能是准入/认证客户端，看「公司电脑上不了网？企业代理环境排查」。

预防

  • 系统更新出了就装，Wi-Fi 相关修复经常包含在内。
  • VPN 用完就退出，别常驻；「安全软件」能不装就不装。
  • 路由器给 Mac 绑定固定 IP，避开「自分配 IP」类问题。

更新日志

  • 2026-10-25 v1.0：首版发布。排查顺序综合 Apple 官方「Mac 无法通过 Wi-Fi 接入互联网」指南与 Wi-Fi 设置文档整理。

分步骤

  1. 忘记网络并重新连接（清掉坏配置）

    1. 系统设置 → Wi-Fi → 网络名右侧「详细信息」→ 「忘记此网络」→ 忘掉。
    2. 等待列表刷新，重新选中该网络输入密码连接。

    期望结果：连接稳定，不再分钟级断连。失败了怎么办：依旧断 → 步骤 2。

  2. 新建网络位置（刷新整套网络配置，Apple 支持社区的常用解法）

    1. 系统设置 → 网络 → 左下角「···」→「位置」→「编辑位置」→ 加号新建一个（如「位置 2」）→ 完成。
    2. 新位置里重新连 Wi-Fi。旧位置不会被删，随时可切回。

    期望结果：断连明显减少。失败了怎么办：仍断 → 步骤 3。

  3. 排除 VPN / 代理 / 安全软件干扰（官方排查表明确项）

    1. 退出所有 VPN 客户端、代理工具（菜单栏图标右键退出）；系统设置 → 网络 → 详细信息 → 代理：确认没有残留的代理勾选。
    2. 卸载或暂时停用第三方「清理/安全」软件后观察半天。
    3. 装过抓包工具（Charles 之类）的，按「浏览器打不开网页但其他应用正常？浏览器代理与 PAC 设置修复」检查系统代理是否被改。

    期望结果：断连消失。失败了怎么办：仍断 → 步骤 4。

  4. 跑内建「无线诊断」

    1. 按住 Option 点菜单栏 Wi-Fi 图标，看「信道」「信号（RSSI）」「传输速率」：RSSI 高于 -60 属良好，-75 以下说明信号太差（先解决覆盖，看「某些房间 WiFi 信号差」）。
    2. 顶部菜单栏「打开无线诊断」（或在「其他」文件夹找）→ 按向导「监视」模式跑几分钟，它会记录断连事件并给出结论。
    3. 打开自动「记录」前先别点——监视模式的报告已够定位多数问题。

    期望结果：诊断给出明确原因（信道拥挤/信号弱/漫游冲突）。失败了怎么办：诊断指向路由器侧 → 改路由器信道/位置；指向 Mac 侧 → 步骤 5。

  5. DNS 与「自分配 IP」专项

    1. Wi-Fi 详细信息 → TCP/IP：IPv4 显示「自分配 IP（169.254.x.x）」→ 点「续订 DHCP 租约」；反复出现就给 Mac 手动指定一个不冲突的内网 IP（如 192.168.1.200）。
    2. DNS 改为 223.5.5.5 / 119.29.29.29（默认 DNS 有时是断连的表象来源——其实只是解析卡）。
    3. 路由器端把这台 Mac 的 MAC 做 DHCP 绑定（固定分配同一 IP）。

    期望结果：IP 稳定、解析顺畅。失败了怎么办：进阶手段 → 步骤 6。

  6. 重启进安全模式验证 + 系统更新

    1. Apple Silicon：关机后长按电源键；Intel：开机按住 Shift——进安全模式待 1 分钟重启回正常模式（会顺带清理部分缓存）。
    2. 系统设置 → 通用 → 软件更新：装齐所有更新（Apple 官方排查表第 4 项，Wi-Fi 驱动随系统更新修）。
    3. Intel 机型可再试重置 SMC（关机 → Shift+Ctrl+Option+电源 10 秒）。

    期望结果：断连根治。失败了怎么办：安全模式下也断 → 硬件天线/网卡嫌疑，预约 Apple Store 或授权服务商检测。
