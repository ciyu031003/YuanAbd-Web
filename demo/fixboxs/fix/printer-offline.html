打印机显示脱机 / 打印没反应怎么修

Windows 10Windows 11入门20-60 分钟✅ 安全

💡 一句话结论

"脱机"九成不是打印机坏了，而是电脑上的打印队列卡死了或者取消了"脱机使用打印机"的勾选；先清空队列，再取消脱机状态，最后才考虑重装驱动。

⚡ 30 秒快速排查（先试这个）

  1. 打开"设置 → 蓝牙和其他设备 → 打印机和扫描仪"，点开你的打印机 → 打开打印队列，把里面堆积的任务全部取消（队列 → 取消所有文档）。期望结果：队列清空，打印机可能立刻吐出之前积压的纸。
  2. 在同一页面点"打印机属性"，在"常规"或"端口"页里确认该打印机没有勾选"脱机使用打印机（Use Printer Offline）"。期望结果：取消勾选后状态从"脱机"变为"就绪"。
  3. 关掉打印机电源，等 30 秒再开；同时重启一次电脑。期望结果：设备和电脑重新握手，状态恢复正常。

✅
ℹ️ 本文只涉及打印队列、连接方式与驱动，不会删除你的任何文件。唯一需要注意的是清除打印任务会作废排队的文档（未保存的内容请先在软件里另存一份）。

适用 / 不适用

适用

  • 打印机面板显示正常，但电脑上显示"脱机""离线""暂停"。
  • 点了打印之后任务一直排队、进度不动。
  • 之前能打、突然打不了，没有换过任何设置。

不适用

  • 打印机面板本身报错（卡纸、缺墨、进纸异常）：先处理打印机面板上的提示，或查阅打印机厂商官网说明。
  • 局域网里共享别人的打印机连不上、报 0x0000011b：看「共享打印机连不上 / 报错 0x0000011b」。
  • 插在电脑上的打印机整个"不见了"、设备管理器没反应：看「U 盘 / 移动硬盘不识别、提示格式化怎么办」里的接口与设备识别思路，或查阅打印机厂商官网的驱动安装说明。
  • 公司里由 IT 统一部署的网络打印机：请联系 IT，不要自行删除设备。

开始前确认

  • 打印机电源已开、屏幕无报错、纸盒有纸、墨粉/墨水没有见底。
  • 网络打印机已连上同一个 Wi-Fi/网线（和电脑在同一个网络），可以先用手机打印页测试一下。
  • USB 打印机确认线插紧、插在电脑本体的 USB 口上（不是坏的扩展坞口）。
  • 知道这台电脑的管理员密码（后面要重启服务、可能要重装驱动）。
  • 如果是办公打印机，先问一下同事能不能打，判断是"只有你这台电脑不行"还是"大家都打不了"。
  • 确认队列里有没有重要且未保存的文档，先在本机软件里另存一份。

怎么确认修好了

在没有手动干预的情况下，从任意一个软件（记事本即可）点"打印"，任务在 1 分钟内进入打印并正常出纸；随后在"打印机和扫描仪"页面里，该打印机状态保持"就绪"，不自动回到"脱机"。

还是不行？

  • 只有你这台电脑打不了，同事的电脑能打 → 是这台电脑的驱动/队列问题，重做步骤 2-6。
  • 局域网里共享别人的打印机连不上、报错 0x0000011b → 看「共享打印机连不上 / 报错 0x0000011b」。
  • 打印机面板自己报错、卡纸、缺墨 → 按面板提示处理，错误码对照打印机厂商官网说明。
  • 打印机用了 5 年以上、频繁卡纸/报通信错误、面板报硬件故障码 → 考虑送修或更换；办公/公司打印机请联系 IT 报修，不要自行拆机。

预防

  1. 网络打印机在路由器里做 DHCP 静态绑定，避免 IP 变化后电脑找不到它。
  2. 打印前先看一眼队列里有没有卡住的旧任务，别让坏任务滚雪球。
  3. 只从打印机厂商官网下载驱动，不用第三方"万能驱动"。
  4. 长期不用时按厂商说明让打印头/硒鼓进入保护状态，喷墨机定期打一张防堵头。
  5. 办公打印机遇到问题先问同事是否同样打不了，能快速区分电脑问题还是打印机问题。

分步骤

  1. 先判断问题在哪一侧

    目的：避免在电脑上折腾半天，结果是打印机本身或网络的问题。

    操作：

    1. 在打印机面板上打印一张自检页（菜单里通常叫"打印配置页 / 网络配置页 / 自检页"，具体路径以打印机厂商手册为准）。 - 打得出来 → 打印机本体没问题，问题在电脑侧或传输链路。 - 打不出来 → 卡纸/耗材/硬件问题，先处理打印机。
    2. 网络打印机：在电脑上 ping 它的地址。先从打印机面板或路由器后台查到它的 IP，然后：
    ping 打印机IP

    （例如 ping 192.168.1.120）

    • 能 ping 通 → 网络链路正常。
    • ping 不通 → 网络/连接问题，看步骤 5。
    预期结果：能明确说出"打印机本身好的，是电脑连不上"或"打印机自己有问题"。
    失败怎么办？
    打不出自检页就检查纸张、墨盒/碳粉、是否卡纸；面板报错误码时以打印机厂商官网的错误码说明为准。

  2. 清空卡住的打印队列

    目的：一个坏任务会把整条队列堵死，后面所有任务都变成"没反应"。

    操作：

    1. 打开打印队列窗口（设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 你的打印机 → 打开打印队列）。
    2. 点菜单"打印机 → 取消所有文档"。
    3. 如果任务删不掉（点了没反应），用管理员身份重启后台服务：
    net stop spooler
net start spooler
    预期结果：队列列表清空；重启服务后状态恢复为"就绪"。
    失败怎么办？
    服务停不下来或报错，打开 services.msc 找到"Print Spooler"，右键 → 重新启动；仍不行就重启电脑后再试。如果任务顽固残留，可清理缓存目录（见步骤 3）。

  3. 清理打印缓存文件（任务删不掉时）

    目的：队列里显示的"幽灵任务"其实是缓存目录里的文件，删掉才能真正清空。

    ✅
    ℹ️ 这一步只删除排队的打印任务（作废还没打印的文档），不会删除其他文件。操作前先把正在编辑的文档保存好。

    操作：先停止服务，再清理目录，最后启动服务。以管理员身份打开命令提示符：

    net stop spooler
del /Q /F %systemroot%\System32\spool\PRINTERS\*
net start spooler
    预期结果：PRINTERS 目录里的 .SPL/.SHD 文件被清空，服务重新启动，队列为空。
    失败怎么办？
    提示"文件正在被使用"，说明服务没停干净——在任务管理器里结束 spoolsv.exe 进程后再删；删除命令报"拒绝访问"就用管理员身份重开命令行。

  4. 取消"脱机使用打印机"并设为默认

    目的：这一项一旦被勾上，任务只会一直排队，永远不发出。

    操作：

    1. 打印机和扫描仪页面 → 你的打印机 → 打印机属性（不是"打印首选项"）。
    2. 切到"常规"页 → 点"首选项 → 高级"或直接找"脱机使用打印机"勾选项，取消勾选；如果看到"暂停打印"也一并取消。
    3. 在"常规"页点"打印测试页"。
    4. 确认这台打印机被设为默认（设置 → 打印机和扫描仪里关闭"让 Windows 管理默认打印机"，再手动设为默认）。
    预期结果：打印机状态显示"就绪"，测试页正常打印出来。
    失败怎么办？
    取消勾选后过一会儿又自动变回脱机，通常是连接方式不稳（网络打印机 IP 变了、USB 口供电不足），跳到步骤 5；状态一直显示"暂停"，检查队列窗口"打印机"菜单里是否还有暂停项没取消。

  5. 检查连接方式（USB / 网络）

    目的：脱机最常见的物理原因是连接断了或地址变了。

    操作：

    • USB 直连：换一个 USB 口（台式机优先机箱后置口）、换一根打印线；如果是透过扩展坞/集线器，改成直插电脑。
    • 网络/无线打印机： 1. 在打印机面板上打印网络配置页，确认它的 IP。 2. 电脑上 ping 打印机IP，通的话继续；不通就检查打印机是否掉出了 Wi-Fi（重连一次）。 3. 打开"打印机属性 → 端口"，确认选中的端口与打印机当前 IP 一致。若不一致，添加标准 TCP/IP 端口并指向新 IP；条件允许的话，在路由器后台给打印机做 DHCP 静态绑定，以后 IP 不再变（参考「怎么查谁在蹭网 / 给设备限速与拉黑」里查看客户端列表的方法）。
    预期结果：ping 通，端口指向打印机当前 IP，测试页能打。
    失败怎么办？
    打印机连不上 Wi-Fi 时，按打印机厂商官网的配网说明重配（多数支持面板输入密码或 WPS 配网）；公司网络里的打印机需要固定 IP 或特殊网段，请联系 IT。

  6. 删除设备后重新添加（并更新驱动）

    目的：前五步都正常还不打印，说明驱动或设备记录损坏了。

    操作：

    1. 设置 → 蓝牙和其他设备 → 打印机和扫描仪 → 选中该打印机 → 删除设备。
    2. 到打印机厂商官网下载对应型号的完整驱动包（不要用来源不明的"万能驱动"），按官方说明安装，让它自动创建端口和队列。
    3. 如果厂商只提供 Windows 内置驱动，就回到"添加设备/手动添加"里添加，安装完再打测试页。
    4. 需要批量清理旧打印机记录时，可用系统自带工具 Print Management（printmanagement.msc） 删除多余队列。
    ⛔
    ⛔ 有影响：printui 的 /s /f /dd 之类参数属于专业运维用途，会删除打印机与驱动配置，普通用户不要执行；企业环境由 IT 操作。
    预期结果：新添加的打印机显示"就绪"，测试页成功。
    失败怎么办？
    装驱动时提示"需要管理员权限"，用管理员账户登录或右键安装程序以管理员身份运行；驱动装完报错，先卸载厂商驱动再重装，并以打印机厂商官网的安装说明为准。

  7. macOS 上的对应处理

    目的：Mac 用户的操作路径与 Windows 完全不同。

    操作：

    1. 系统设置 → 打印机与扫描仪，先看设备状态是否显示"暂停"或"脱机"，点开后选择"恢复"。
    2. 打开打印队列：双击设备或点"打印机队列"，把卡住的任务删掉（选中按 Delete 键，或点"×"）。
    3. 仍不行就移除这台打印机：选中 → "移除打印机"，再点"添加打印机"，按提示重新添加（同一网络下通常能自动发现）。
    4. 添加不上时检查 Mac 与打印机是否在同一网络、是否是"访客网络"（访客网络常隔离内网设备）。
    预期结果：队列清空，打印机状态正常，能打印测试页。
    失败怎么办？
    添加时提示过滤器/驱动不可用，到打印机厂商官网下载 macOS 版驱动，或改用 AirPrint/IPP Everywhere；网络发现不到就换成用 IP 添加（ipp://打印机IP/ipp/print 一类地址以厂商文档为准）。

  8. 用系统自带疑难解答收尾

    目的：让 Windows 自动检查一遍服务、端口和防火墙配置。

    操作：设置 → 系统 → 疑难解答 → 其他疑难解答 → 找到"打印机" → 运行。按提示应用修复。

    预期结果：疑难解答报告已修复或未发现问题。
    失败怎么办？
    疑难解答修不了就不必反复跑；回到步骤 1 重新判断是"打印机侧"还是"电脑侧"，走"还是不行"里的分流。
