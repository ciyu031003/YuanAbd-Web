共享打印机连不上 / 报错 0x0000011b 怎么修

⚠ 需谨慎：本文含一处注册表修改（微软官方提供的临时缓解）。改注册表前先看清路径与值名，改错位置会影响系统。改完必须重启打印服务才生效；这个开关会降低一点 RPC 连接的安全性，属于「先让办公室能打印」的权衡，长期方案是把系统更新装齐。

💡 一句话结论

0x0000011b 常见于 2021 年打印组件安全更新之后，与打印队列的 RPC 凭据/隐私验证兼容性有关，不一定是打印机坏了。修复顺序应是：主机和客户机安装仍在支持期内的系统更新 → 客户机凭据管理器保存主机账号 → 仅在不适用时临时调整 RpcAuthnLevelPrivacyEnabled。不同补丁版本和环境结果不同，不存在“接近 100%”的保证。

⚡ 30 秒快速排查（先试这个）

  1. 确认错误码：连接共享打印机时弹「操作失败，错误为 0x0000011b」。期望结果：实锤是本文问题；若是 0x00000709（默认打印机错误）或 0x0000015，按「打印机显示脱机 / 打印没反应怎么修」走。
  2. 主机上直接打印一张测试页。期望结果：主机能打 → 打印机本身与驱动正常，问题纯粹在「共享」这一层；主机也打不了 → 先修主机（看脱机篇）。
  3. 两台机器的 Windows 更新都检查一遍：设置 → Windows 更新 → 检查更新。期望结果：装齐累积更新——微软在后续补丁里已给出官方修复。

适用 / 不适用

适用

  • 连接局域网共享打印机时报 0x0000011b。
  • Windows 更新（特别是每月补丁日）之后，办公室共享打印机集体失联。
  • 重装/新增客户机后连共享打印机被拒绝。

不适用

  • 打印机直连 USB 的单机脱机问题：看「打印机显示脱机 / 打印没反应怎么修」。
  • 网络打印机（网线/Wi-Fi 直连路由器，不走某台电脑共享）的离线：看「网络打印机 IP 变了就离线？固定 IP 与端口配置」。
  • 公司域环境统一部署的打印服务器：找 IT，别自行改注册表。

开始前确认

  • 分清架构：打印机插在主机上共享（本文） vs 打印机自己有网口/Wi-Fi（另一篇）。
  • 主机上的共享名知道（\\主机名\打印机名）。
  • 主机的登录用户名和密码（凭据方案要用）。
  • 两台机器都备份好重要数据（涉及更新与注册表操作）。

怎么确认修好了

  • 客户机打印测试页一次成功，连续打印无报错。
  • 重启两台机器后依然正常。
  • 下个补丁日（每月第二个星期）后复测——装齐更新的机器不会再复发。

还是不行？

  • 三招全试过仍 11b → 卸载最近一次质量更新（设置 → 更新历史 → 卸载更新）验证是否更新引起，确认后暂停该更新并等下月修复版（这是官方问答里认可的诊断手段）。
  • 只有某一台客户机报错 → 该机系统太旧（Win7/8.1），升级到受支持的 Windows 版本。
  • 需要长期稳定且人多（>10 人）→ 淘汰「共享」架构，上打印服务器或支持网络直连的打印机。

预防

  • 办公室所有机器开自动更新，补丁日之后主动打一张测试页。
  • 新客户机接入时，先在凭据管理器存主机账号再连打印机（省一次报错）。
  • 打印机支持网口/Wi-Fi 的，优先用 TCP/IP 直连架构，「共享」是无奈之选。

更新日志

  • 2026-10-25 v1.0：首版发布。成因（KB5005565 RPC 强化）与修复顺序（更新根治 / 凭据 / 注册表缓解）依据 Microsoft Learn 官方问答与支持文档整理。

分步骤

  1. 装齐两边的 Windows 更新（官方根治方案）

    1. 主机与客户机：设置 → Windows 更新 → 检查更新。先确认系统仍在微软支持期内；Windows 7 已于 2020 年结束扩展支持，不应继续作为共享主机暴露在局域网。
    2. 安装适用于本机版本和架构的累积更新，重启两台机器，再试连接共享打印机。

    期望结果：补丁兼容后连接恢复。失败了怎么办：装齐仍报 11b → 步骤 2；不要从第三方网站单独下载来历不明的 KB 补丁。

  2. 客户机凭据管理器存主机账号（不动系统的解法）

    1. 客户机：控制面板 → 用户账户 → 凭据管理器 →「Windows 凭据」→ 添加 Windows 凭据。
    2. 地址填主机名（如 OFFICE-PC，也可填 OFFICE-PC 的 IP）；用户名密码填主机上的登录账号（主机若用微软账户登录，用户名填邮箱全称）。
    3. 保存后重新连接共享打印机。

    期望结果：连接成功——11b 的本质是「匿名/旧凭据被拒」，存了合法凭据就不再触发。失败了怎么办：仍被拒 → 步骤 3。

  3. 主机注册表 RpcAuthnLevelPrivacyEnabled（微软官方临时缓解）

    1. 主机上 Win + R → regedit。
    2. 定位到 HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Print。
    3. 右侧新建 DWORD (32 位) 值：RpcAuthnLevelPrivacyEnabled，数值数据填 0。
    4. 重启打印服务：services.msc → 找到 Print Spooler → 右键重新启动（或直接重启主机）。
    5. 客户机重试。

    期望结果：共享恢复。失败了怎么办：仍报 11b → 步骤 4 查共享与网络层。若临时方案有效，记录该改动并在打印机厂商或后续 Windows 兼容更新发布后把值改回 1 或删除该值，避免长期降低 RPC 隐私保护。

  4. 共享与网络层复核（11b 之外常叠加的问题）

    1. 主机：设置 → 网络和 Internet → 高级网络设置 → 高级共享设置：当前配置文件（专用）打开「网络发现」和「文件和打印机共享」。
    2. 主机 Win + R 输入 \\localhost 能看到共享的打印机；客户机资源管理器输入 \\主机名 能打开并看到它——看不到就是共享/发现层问题，先修这里（防火墙放行「文件和打印机共享」）。
    3. 主机与客户机互相 ping 通（同一网段、无 AP 隔离）。

    期望结果：\\主机名 里双击打印机直接安装成功。失败了怎么办：能看见但连接仍报 11b → 回步骤 3 确认注册表与 Spooler 重启生效；完全看不见 → 检查路由器「AP 隔离/访客网络」设置。

  5. 兜底——绕开「共享」架构

    1. 给打印机配固定 IP，客户机直接按「TCP/IP 端口」添加网络打印机（不再依赖主机转发）：具体做法看「网络打印机 IP 变了就离线？固定 IP 与端口配置」。
    2. 或主机装「打印机共享为服务」的厂商方案（HP Smart / Epson iPrint 的局域网共享）。
    3. Windows 7 机器作主机 + Windows 11 客户机的老办公室：兼容性和安全问题都高发，强烈建议迁到 TCP/IP 直连或更换受支持的共享主机。

    期望结果：打印恢复且以后不再被补丁日打断。失败了怎么办：TCP/IP 方案也失败 → 打印机或网络硬件问题，回到单机脱机排查。
