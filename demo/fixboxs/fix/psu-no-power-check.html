电脑按开机键没反应？电源故障自查清单（含短接启动法）

⚠ 需谨慎：本教程严禁拆开电源外壳——内部大电容在断电后仍可能带数百伏高压，非专业人员拆解有生命危险。所有操作都在关机断电后进行；有烧焦味、异响或电源曾冒烟的，直接换新，不要再通电测试。

💡 一句话结论

「按了没反应」要按 插座 → 电源线 → 开关 → 电源本身 → 主板开机电路 的顺序查，其中「回形针短接 24pin」是判断电源死活的金标准：短接后电源风扇转、各路电压正常，电源就是好的，锅在主板或机箱开关；不转，电源报废，换新即可。

⚡ 30 秒快速排查（先试这个）

  1. 换一个确定正常的墙插，跳过插线板直接插墙。期望结果：不少「电源坏了」其实是插线板开关被碰掉了。
  2. 确认电源背后的机械开关在「—」位（I 是开），且电源线两端插紧。期望结果：排除最蠢也最常见的原因。
  3. 观察主机：按开机键时任何反应都没有（灯不闪、风扇不动）→ 按本教程走短接测试；风扇转一下就停 → 更多是短路保护或内存/主板问题，看「电脑反复重启？先重插内存条」。

适用 / 不适用

适用

  • 按开机键整机无任何反应，电源灯不亮。
  • 使用中突然断电关机、再开没反应，过一会儿又能开（电源过热保护或老化）。
  • 新装机或换件后点不亮，怀疑电源或安装问题。

不适用

  • 能点亮、能进系统，只是用着重启：先查系统和温度，看「电脑很卡 / 频繁死机怎么排查」。
  • 雷雨天之后坏的：电源可能和主板一起伤，逐件送检，别只换电源。
  • 品牌机（联想/戴尔/惠普）在保修内：不要短接测试，直接报修，拆封条会失保。

开始前确认

  • 房间插座确认有电（插个手机充电器试试）。
  • 电源线没有发黑、变硬、有糊味（有线损的直接换线）。
  • 手边有回形针，能掰直。
  • 记住机箱内部大致走线，方便复原。
  • 嗅觉确认无烧焦味（有 → 跳过一切测试，直接换电源）。

怎么确认修好了

  • 冷启动 3 次都正常，满负载（跑游戏/压视频）半小时不自动断电。
  • 无焦味、无异响（电源里「哒哒」继电器声高频出现也是老化征兆）。
  • 万用表三路电压全部在 ±5% 内。

还是不行？

  • 短接 PWR_SW 能开、机箱按钮不能开 → 换机箱开关线，或把 PWR_SW 接到 RESET 针上临时顶替。
  • 短接测试正常但装回主板无反应 → 主板开机电路问题，送修主板；顺带检查主板上的电源开关跳线是否插错到 LED 针上。
  • 用着突然断电且电源烫手 → 清灰换风扇或直接换电源，过热保护不是玩笑。

预防

  • 电源别买「够用就好」的杂牌：它带不动时最先死的是硬盘数据。
  • 每年清一次电源进风口的灰，散热差直接缩短寿命。
  • 大雷雨天气拔掉电源线，浪涌是电源和主板的双料杀手。

分步骤

  1. 排除外部供电

    1. 直插墙插；换电源线（显示器、其他电器同规格的「品字口」线通用）。
    2. 检查电压选择开关（部分老电源背面 115/230V）在 230V。

    期望结果：开机有反应。失败了怎么办：依旧没反应，进步骤 2。

  2. 排除机箱开机键

    1. 打开侧板，找到主板上标着 PWR_SW 的两根针，机箱开关线就插在上面。
    2. 用螺丝刀金属头轻碰短接这两根针一瞬（等同于按开机键）。

    期望结果：机器启动 → 锅在机箱开机键或那条线，几块钱换个开关线即可。失败了怎么办：短接 PWR_SW 仍无反应 → 进步骤 3 判电源。

  3. 回形针短接测试（电源死活金标准）

    1. 关机拔电，把 24pin 主供电插头从主板上拔下。
    2. 把回形针掰成 U 形，插进插头一侧绿色线（PS_ON）和任意一根黑色线（COM/GND）对应的孔位（绿线通常只有一根，很好找）。
    3. 插回市电，观察电源风扇。

    期望结果：风扇转起来（多数电源空载风扇不转或慢转属正常，看电源指示/风扇即可）→ 电源基本活着，恢复接线后故障在主板开机电路，送修主板。失败了怎么办：完全不转 → 换电源；短接后转但一装回主板就断电 → 主板或某部件短路，逐件排查（先拔显卡只留 CPU+内存再试）。

  4. 用万用表复核电压（可选，进阶）

    1. 短接启动状态下，黑表笔接黑线，红表笔分别测：黄色（+12V，应在 ±5% 即 11.4-12.6V）、红色（+5V，4.75-5.25V）、橙色（+3.3V）。
    2. 电压飘出范围 → 电源老化，即使「能转」也应换，它正在慢性伤害硬盘。

    期望结果：三路电压都在范围内。失败了怎么办：+12V 偏低明显 → 换电源，优先 80PLUS 铜牌以上、功率留 30% 余量。

  5. 换新电源后的接线检查

    1. 24pin、CPU 8pin（4+4）、显卡供电全部插到底——「转一下就停」很多是 CPU 8pin 忘插。
    2. 品牌机换非原装电源前，先核对接口形态（看「硬件拆解图」里的主机型号页，联想/戴尔/惠普的电源接口互不通用）。

    期望结果：一次点亮稳定运行。失败了怎么办：换电源仍点不亮 → 电源以外有损伤，交叉验证主板。
