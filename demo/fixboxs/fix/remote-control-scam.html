有人让我下载软件并远程控制电脑，是诈骗吗

通用入门10-30 分钟⚠ 需谨慎

💡 一句话结论

只要有陌生人主动联系你、说你电脑有问题、要你装软件让他"远程看一下"，一律按诈骗处理——正规厂商客服永远不会主动打电话让你安装远程控制软件或共享屏幕。

⚡ 30 秒快速排查（先试这个）

  1. 立刻挂断，不要再操作。对方让你装什么、点什么，都先停下来。期望结果：中断对方的指令链条。
  2. 问自己三个问题：是他主动联系我的吗？他在催我马上处理吗？他要我装软件、看屏幕、报验证码、转钱吗？三个都"是"就是诈骗。
  3. 如果已经装了远程软件或共享过屏幕：先断网（拔网线/关 Wi-Fi），再往下看"已经做了怎么办"。期望结果：切断对方继续操控的通道。

⚠
⚠️ 本文只做识别与止损，不涉及任何网络攻击技术。涉及资金的判断请以银行与公安机关的正式渠道为准；本文给出的号码与举报入口以官方最新公告为准（参考来源见文末）。

适用 / 不适用

适用

  • 接到自称"银行/支付平台/电商/运营商/平台客服/公检法"的来电或消息，说你的账号或电脑有问题。
  • 对方要你安装 TeamViewer、AnyDesk、向日葵、ToDesk 一类远程控制或屏幕共享软件。
  • 对方要你"打开网银页面慢慢操作、我在这边教你怎么填"。
  • 有人加你微信/QQ 说要帮你"清理病毒""修复系统""退款理赔"。

不适用

  • 你自己主动联系厂商客服，并按厂商官方渠道（官网、官方 App、官方热线）接受的正规远程协助：这种情况请以厂商官方流程与家人知情为前提，仍不要把验证码和密码给对方。
  • 电脑确实中了病毒或被入侵：看「电脑中病毒了怎么办：先做这三件事再杀毒」。
  • 怀疑账号已经被盗但没有资金损失：看「电脑中病毒了怎么办：先做这三件事再杀毒」里的改密与账号检查部分。

开始前确认

  • 已停止与对方的任何操作配合（不再装软件、不再共享屏幕、不再念验证码）。
  • 手边有另一台干净设备（手机）用来改密码、查账。
  • 保留了证据：对方的号码、账号、聊天记录、转账记录（先截图，不要删除）。
  • 银行卡/支付 App 在手边，或知道银行客服电话。
  • 如果涉及家人（尤其是老人），先确认他们有没有也在跟对方通话。

怎么确认处理好了

三件事同时满足：这台电脑/手机已不再被远程控制（远控软件已卸载、远程桌面已关闭、无陌生自启项）；所有重要账号已在干净设备上改密并开启两步验证、没有未授权转账；报警/银行/平台已受理并留有记录。

还是不行？

  • 对方还有你的资料、继续威胁你 → 保存证据并报警（110），不要私下转账"私了"。
  • 怀疑电脑已被植入木马或远控 → 看「电脑中病毒了怎么办：先做这三件事再杀毒」，必要时重装系统。
  • 文件被加密、出现勒索说明 → 看「文件被加密了 / 弹出勒索要比特币怎么办」，不要支付赎金。
  • 正在发生、涉及资金 → 立即 110 报警 + 联系银行止付；涉及家人被劝导 → 拨打 96110。
  • 公司/单位电脑曾被远程控制 → 立即联系 IT 与安全负责人，由单位按安全事件流程处置，不要自行清理。

预防

  1. 记住一条底线：任何人主动联系你、要你装远控软件或共享屏幕，都是诈骗，直接挂断。
  2. 任何情况下都不把短信验证码、银行卡密码、取款密码告诉别人；正规客服永远不会问这些。
  3. 需要联系客服时，从官网、官方 App 或银行卡背面找号码，不用对方提供的联系方式。
  4. 手机安装"国家反诈中心 App"并开启来电预警；收到 12381 预警短信要重视。
  5. 家人之间约定"转账前先电话确认"的规则，给长辈的手机设置好这个习惯。
  6. 电脑上的远程桌面、远程协助功能不用时保持关闭，远控类软件只在明确需要时临时安装，用完卸载。

分步骤

  1. 先搞清楚"远程控制"到底能做什么

    目的：知道风险有多大，才不会觉得"只是让他看一下没关系"。

    操作：对照下面这张表理解对方能看到和做到什么：

    对方能做的事说明
    看到你屏幕上的一切包括网银余额、短信验证码、聊天内容、照片
    操作你的鼠标键盘你看着它自己动，钱可能就在你眼前被转走
    翻你的文件通讯录、身份证照片、工作资料都可能被拷走
    读取你保存的密码浏览器里"记住的密码"、部分软件的自动登录
    装更多东西木马、远控、勒索软件都可能在此时被装进来
    记住你的操作节奏以后可以伪装成"你本人"操作
    预期结果：明白"远程控制 = 把电脑的钥匙交出去"，不存在"只是看看"。
    失败怎么办？
    如果你已经想不起对方屏幕里出现过什么，按步骤 4、5 全面检查账号并报警。

  2. 用这张表判断对面是不是骗子

    目的：骗子的话术高度相似，用特征比对最快。

    特征正规客服骗子
    谁先联系谁你去官方渠道找他他主动打给你/加你
    会不会要验证码永远不会问你要短信验证码、密码、取款密码反复要验证码、要你念出来
    会不会要远程官方远程协助有明确流程与工单号上来就让你装远控/共享屏幕
    紧不紧张让你按流程慢慢来制造紧张："再不处理就冻结/立案/扣费"
    让不让你挂断你可以先挂断、自己打官方热线核实不许挂断、不许告诉家人、不许报警
    钱往哪走只走官方渠道让你转"安全账户""保证金""解冻费"
    预期结果：能明确判定"这是诈骗"。
    失败怎么办？
    拿不准时，挂断后用官方渠道回拨（银行卡背面电话、平台 App 内的客服入口、官网公布的号码），不要用对方给你的号码；也可以拨打 96110 咨询（反诈专线提供防骗咨询服务，见文末来源）。

  3. 已经装了远控软件 / 共享过屏幕，怎么办

    目的：第一时间切断对方的控制通道。

    操作（按顺序做，越快越好）：

    1. 断网：拔网线、关 Wi-Fi、关掉手机热点共享。手机上的远控/共享 App 也要关闭并卸载。
    2. 结束远控连接并卸载软件：Windows 在任务管理器结束对应进程，再到"设置 → 应用"卸载；手机直接卸载 App。
    3. 不要在这台电脑上登录任何账号，包括网银、邮箱、微信。
    4. 用另一台干净设备改密码（见步骤 4）。
    5. 如果不确定对方装了什么，最稳妥的方案是备份数据后重装系统（参考「电脑中病毒了怎么办：先做这三件事再杀毒」的步骤 7）。
    预期结果：对方失去控制通道，机器进入"隔离观察"状态。
    失败怎么办？
    软件卸载不掉、鼠标仍自己动，直接强制关机，拔掉网线后再开机处理；仍然异常就走重装系统。

  4. 账户止损：改密码、查登录、查转账

    目的：把可能已经泄露的账号全部收回来。

    操作（务必在干净设备上做）：

    1. 银行卡与支付：登录银行 App 或致电银行客服，核对最近交易；开启或调整支付限额、开启交易提醒。
    2. 邮箱：改密码 + 开启两步验证，检查"转发规则/自动转发"和"最近登录设备"有没有陌生条目。
    3. 微信/QQ/社交与电商账号：改密码、查看"登录设备管理"并踢掉陌生设备、关闭"允许通过手机号搜索"之类的弱入口。
    4. 电脑/手机上的账号：Windows 用微软账号的"设备"页面查看已登录设备；手机检查 Apple/安卓账号的登录设备。
    5. 所有账号不要再复用同一个密码；改完后把新密码记在安全的地方（不要存在刚中毒的电脑里）。
    预期结果：关键账号密码已更换、陌生设备已移除、没有未授权转账。
    失败怎么办？
    账号已经登不上，走官方找回流程；发现任何异常转账，立即联系银行冻结/挂失，并按步骤 5 报警。

  5. 报警与举报渠道

    目的：抢在资金被转走前申请止付，同时留下正式记录。

    操作：

    • 已经转账/被骗：立即拨打 110 报警（越快越好，有利于冻结止付），同时联系银行客服申请紧急止付。
    • 疑似诈骗、想咨询：拨打 96110（反诈预警劝阻与防骗咨询专线，由公安机关开通；以官方最新公告为准）。
    • 收到涉诈预警短信：来自 12381 的短信是涉诈预警劝阻短信系统发出的，收到即说明你可能正处于诈骗风险中，请提高警惕（来源见文末）。
    • 举报涉诈电话、短信、钓鱼网站、不良 App：可通过 12321（网络不良与垃圾信息举报受理中心，工信部委托中国互联网协会设立）投诉举报，电话 010-12321，网站 www.12321.cn。
    • 安装官方反诈工具：可在手机官方应用商店安装"国家反诈中心 App"（公安部推出），用于预警、举报与风险验证。
    • 保留证据：通话号码、聊天记录、转账凭证、对方发来的链接与文件，不要删除。
    预期结果：报警/举报完成，拿到受理信息；资金类问题已第一时间联系银行。
    失败怎么办？
    拨不通就换时间段再拨；涉及的平台（如银行、支付平台、电商）也要同时在平台内提交投诉与申诉。以公安机关与各平台的官方指引为准。

  6. 检查电脑上的残留，并处理好家人的情况

    目的：对方远程时可能顺手装了东西；而被骗的常常是长辈，止损之外还要有统一规则。

    操作：

    1. 对照下表逐项检查这台电脑：
    检查项位置看什么
    远程控制软件设置 → 应用TeamViewer/AnyDesk/向日葵/ToDesk 等是否还装着、有没有"开机自启"
    启动项任务管理器 → 启动应用陌生的自启程序
    计划任务taskschd.msc登录时/开机时触发的陌生任务
    远程协助设置设置 → 系统 → 远程桌面是否被开启
    浏览器保存的密码浏览器 → 设置 → 密码建议全部更换，不要只删记录
    浏览器扩展chrome://extensions陌生扩展
    1. 如果被骗的是家人（尤其是老人）：先帮他断网、关机、拔卡；陪他一起改密码、查账、必要时陪同报警，不要责怪（这只会让人隐瞒损失、延误止付）；在家人手机上安装官方反诈 App 并开启来电预警。
    2. 约定家庭规则：任何涉及转账、验证码、"客服"来电，先挂断并给家人打电话确认。
    预期结果：没有残留的远控与自启项，远程桌面处于关闭状态；家人配合处理，后续有统一的应对规则。
    失败怎么办？
    不确定是否干净，就按「电脑中病毒了怎么办：先做这三件事再杀毒」的流程用 Microsoft Defender 脱机扫描，或直接重装系统；家人不肯相信是诈骗，就直接拨打 110 或 96110 请民警协助劝阻。
