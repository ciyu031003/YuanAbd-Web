怎么查谁在蹭网 / 给设备限速与拉黑

通用进阶20-60 分钟⚠ 需谨慎

⚠
⚠️ 本文会修改路由器的无线与设备管理设置。动手前请先记下当前 Wi-Fi 名称、密码和管理员密码；改错了可以在这里改回来，但改 Wi-Fi 密码会让所有设备重新连接一次。

💡 一句话结论

网速被占多半是"自家设备认不出来"，先在路由器后台的客户端列表逐台核对；确认有陌生设备，再改 Wi-Fi 密码 + 开访客网络，最后才考虑 MAC 过滤和限速。

⚡ 30 秒快速排查（先试这个）

  1. 拿手机连家里 Wi-Fi，打开浏览器输入路由器后台地址（常见 192.168.1.1、192.168.0.1、192.168.31.1、tplogin.cn），登录后找到"已连接设备 / 客户端列表 / 终端管理"。期望结果：看到一份设备清单，每行有设备名、IP、MAC 地址。
  2. 把清单上的设备数量和家里实际在用的设备数量对一遍（手机、电脑、电视、音箱、摄像头、扫地机都算）。期望结果：数量对得上就是没有外人；多出 1 台以上，记下它的 MAC 再处理。
  3. 如果你只想先快速止血：把 Wi-Fi 密码改掉并重启路由器。期望结果：所有设备需要重新输密码，陌生设备立即下线。

适用 / 不适用

适用

  • 自家路由器，你知道后台地址和管理员密码，路由器的 Wi-Fi 是自己能控制的。
  • 感觉晚上变慢、测速不达标，怀疑被别的设备占带宽。
  • 想给孩子的平板、家里的电视单独限速。

不适用

  • 不知道路由器后台地址、密码也忘了：先看「路由器后台 192.168.1.1 打不开怎么办」。
  • 全家所有设备都上不了网（不是慢，是断）：看「家里所有设备都上不了网：先分清是谁的问题」。
  • 用的是房东、邻居、单位提供的网络：不要登录和修改别人家的路由器，这是别人的设备；有问题请联系网络提供方。
  • 想用 MAC 过滤把别人"锁死"在门外：先看完本文下面的说明，MAC 过滤很容易把自己也关在门外。

开始前确认

  • 你连的是自己家的 Wi-Fi，不是热点、不是邻居的网络。
  • 已经拿到路由器后台地址和管理员密码（不是 Wi-Fi 密码，两个不一样）。
  • 如果这是单位/公司统一配发的路由器或网络设备，请联系 IT，不要自行修改。
  • 记录当前 Wi-Fi 名称与密码（改密码后要重新配一遍所有设备）。
  • 准备一支笔或手机备忘录，用来记陌生设备的 MAC 地址。
  • 如果有智能家居设备，先确认它们在线（否则你会把它们当成"陌生人"）。

怎么确认修好了

在路由器后台的客户端列表里，所有设备你都能说出它是什么；同时在晚上用网高峰做一次测速（有线连接下测），速度接近套餐标称值的 80% 以上，就算修好了。

还是不行？

  • 陌生设备删了又来 → 说明密码泄露渠道没堵上（WPS、远程管理、或路由器后台密码太弱），重点看本文步骤 4，并考虑升级固件：「路由器怎么恢复出厂 / 固件要不要升级」。
  • 没人蹭网但网速还是慢 → 不是蹭网问题，去看「网速变慢了：测速、延迟、丢包怎么一步步查」。
  • 路由器后台密码忘了、进不去 → 看「路由器后台 192.168.1.1 打不开怎么办」。
  • 路由器用 5 年以上、反复被陌生设备接入、固件早已停止更新 → 建议直接换新路由器；如果是单位/公司提供的网络设备，请联系 IT，不要自行修改。

预防

  1. Wi-Fi 密码每 6-12 个月换一次，或用路由器 App 的"一键改密"，顺手把全家设备重新连一遍。
  2. 关闭 WPS 与路由器远程管理，管理员密码不要和 Wi-Fi 密码相同。
  3. 客人一律走访客网络，主网络密码不写在纸上贴墙、不发在群里。
  4. 每季度打开一次客户端列表看一眼，陌生设备趁早处理。
  5. 路由器固件保持厂商最新版本，旧型号长期无更新就该换。

分步骤

  1. 找到路由器后台地址并登录

    目的：客户端列表只在路由器管理后台里，先要能进去。

    操作：电脑上按 Win + R，输入 cmd 回车，执行：

    ipconfig

    在输出里找默认网关（例如 192.168.1.1），这就是路由器后台地址。macOS 用：

    netstat -nr | grep default

    然后在浏览器地址栏输入 http://默认网关地址，用管理员密码登录。

    预期结果：看到路由器的管理页面。不同品牌的入口名字不一样，通常在"设备管理 / 终端管理 / 客户端列表 / DHCP 客户端列表 / 已连接设备"里。
    失败怎么办？
    打不开就换 http://、换浏览器、关掉浏览器代理插件；仍不行看「路由器后台 192.168.1.1 打不开怎么办」。注意别登错到光猫（光猫和路由器可能都是 192.168.1.1，以实际默认网关为准）。

  2. 核对客户端列表，找出陌生设备

    目的：先确认到底有没有外人，避免误伤自家设备。

    操作：打开客户端列表，逐行看三列信息：设备名 / IP 地址 / MAC 地址。对照下面这张表判断：

    看到的设备名大概率是什么处理
    手机型号、电脑名、DESKTOP-xxxx自家设备保留
    ESP_xxxx、Tuya、Mi-xxxx智能插座、灯泡、传感器保留
    电视、音箱、摄像头品牌名自家家电保留
    Android-xxxx 这类通用名手机（关掉了设备名广播）用 MAC 前 3 位到网上查厂商缩写
    完全对不上的名字 + 对不上的时间可疑设备记下 MAC，进入步骤 3

    Windows 上想从电脑侧看局域网里的邻居，可以辅助执行：

    arp -a
    预期结果：能明确说出"这台是电视、这台是扫地机、这台不认识"。arp -a 只会显示最近通信过的设备，看不到全部，只作辅助。
    失败怎么办？
    路由器列表只有 MAC 没有名字，就用 MAC 地址前 3 段（OUI）在浏览器里搜厂商名；仍然判断不了，就把不认识的设备先记下来，按步骤 3 处理——改了 Wi-Fi 密码后如果家里少了哪台设备，再把它加回来。

  3. 改 Wi-Fi 密码（最有效、最干净的一招）

    目的：让所有陌生设备一次性掉线，而且它们无法自动重连。

    操作：在路由器后台的"无线设置 / Wi-Fi 设置"里，把 Wi-Fi 密码改成新的强密码，加密方式选 WPA2-PSK（AES） 或 WPA3，不要选 WEP、不要选"混合 WPA/WPA2 但只有 TKIP"。保存后路由器通常会自动重启无线。

    新密码建议：长度 ≥ 12 位，大小写字母 + 数字 + 符号，不含自家门牌号、手机号、生日
    预期结果：所有设备断线，需要重新输入新密码才能连上。
    失败怎么办？
    家里设备多、怕麻烦，可以先只改 5GHz 的密码测试；如果连自己的设备都连不上，检查是不是密码里带了中文或特殊符号导致老设备不支持，改用纯英文数字符号组合。

  4. 关闭 WPS 和远程管理

    目的：堵住两个常见的"不必知道密码也能进来"的口子。

    操作：在路由器后台里找这两项并关闭：

    • WPS / QSS / 一键连接：关闭。WPS 的 PIN 方式历史上存在被暴力猜解的风险，家庭场景一般用不上。
    • 远程管理 / 远程 Web 管理 / 从外网访问路由器：关闭。除非你明确需要在外网管理路由器，并且已经按「端口映射 / 外网访问 NAS、摄像头怎么设置」做过安全加固。
    预期结果：后台里这两项显示为"关闭"。
    失败怎么办？
    找不到对应菜单，就在后台里用搜索框搜 WPS 或查阅路由器厂商官网的说明书（不同品牌位置差异很大），以官方文档为准。

  5. 开访客网络，把"来客"隔离出去

    目的：朋友、租客、临时设备走独立网络，接触不到你的电脑和 NAS。

    操作：在路由器后台找"访客网络 / 访客 Wi-Fi"，开启并设置一个单独的密码，勾选"隔离访客网络 / 禁止访客访问内网"这类选项。访客网络一般是 2.4GHz 或 5GHz 单独一个 SSID，名称建议不要和主网络一样。

    预期结果：多出一个新的 Wi-Fi 名称，连上去后只能上网，看不到你的共享文件和打印机。
    失败怎么办？
    路由器太旧没有访客网络功能，就用"改主密码 + 定期查看客户端列表"代替；长期需要隔离，考虑换一台支持访客网络的路由器。

  6. 步骤 6（可选）：MAC 地址过滤——先想清楚再开

    目的：只允许白名单里的设备接入，其余一律拒绝。

    操作：在路由器后台的"MAC 地址过滤 / 访问控制"里：

    1. 选择"仅允许列表中的设备接入"（白名单）或"禁止列表中的设备接入"（黑名单）。
    2. 把自家所有设备的 MAC 逐个填进去（从步骤 2 的客户端列表里复制，格式通常是 AA:BB:CC:11:22:33）。
    3. 保存并重启路由器无线。
    预期结果：黑名单模式下陌生设备被拒绝；白名单模式下只有列表内设备能连。
    失败怎么办？
    • 把自己也关在门外了：用网线直连路由器（网线通常不受无线过滤限制），或者长按 Reset 恢复出厂后重配——恢复出厂会清空宽带拨号账号等所有配置，动手前先记录。
    • 白名单模式漏填了设备，家里人回来说连不上 Wi-Fi：去后台补上那台设备的 MAC。
    • 说明：MAC 地址可以被改（伪造），所以过滤只挡得住"顺手蹭网"的人，挡不住有心人。改强密码 + 关 WPS 比 MAC 过滤更根本。

  7. 步骤 7（可选）：用 QoS 给设备限速

    目的：不踢人，但要保证自家设备（尤其是开会、网课）的带宽。

    操作：在路由器后台找"QoS / 带宽控制 / 智能限速 / 设备限速"：

    1. 先填写宽带的上行/下行带宽（不知道就填运营商套餐标称值，比如 500Mbps 下行 / 50Mbps 上行）。
    2. 在设备列表里选中要限速的设备，设置它的最大上行、下行速率。
    3. 如果路由器支持"优先级"模式，把电脑/手机设为高优先级，把下载机、电视盒子设为低优先级，比你手动填数字更简单。
    4. 保存生效。
    预期结果：该设备测速被压到你设置的数值以下，其他设备不再被它拖慢。
    失败怎么办？
    不同品牌 QoS 的叫法和参数完全不同（有的按百分比、有的按 Mbps），以路由器厂商官网的说明为准；开启 QoS 后整体网速反而下降，说明这台路由器的 QoS 是软件转发实现，直接关掉，改用"限速那台设备自身的下载速度"这种土办法。

  8. 检查并保留一份记录

    目的：确认陌生设备已下线，并且下次能快速对比。

    操作：改完设置后，隔 10 分钟再看一次客户端列表，确认陌生设备不在列表里。把当前正常的清单（设备名 + MAC）抄下来或截图保存。

    预期结果：列表里只剩自家设备；网速恢复。
    失败怎么办？
    陌生设备仍在列表里，说明它掌握了新密码——检查是否有人能看到你输入密码的过程，或是否开了 WPS/远程管理，回到步骤 4。
