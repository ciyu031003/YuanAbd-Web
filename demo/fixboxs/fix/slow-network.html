网速慢怎么定位：是宽带、路由器还是电脑的问题

ℹ️ 本教程全部是只读测试与常规设置调整，不会动数据。「重启路由器」这类操作也不会丢配置（恢复出厂才会，本文不会让你做）。

💡 一句话结论

网速慢要按「设备 → Wi-Fi 链路 → 路由器 → 运营商」分段测，每一段都有明确判据：有线直连测速够签约值 = 宽带没问题；同一房间里手机也慢 = Wi-Fi 链路问题；只有一台设备慢 = 那台设备的问题。分段测完，问题自动浮出水面，不用猜。

⚡ 30 秒快速排查（先试这个）

  1. 看测速前的姿势：用网线直连光猫/路由器测一次速（speedtest.cn），和签约带宽对比。期望结果：有线跑出签约值的 80% 以上 = 宽带正常，问题在 Wi-Fi 或设备。
  2. 换 5GHz Wi-Fi（SSID 带 _5G 或在路由器后台分开的两个频段里选 5G 那个）再测。期望结果：2.4G 慢 5G 快 = 典型的 2.4G 拥堵/干扰，不是宽带问题。
  3. 问一句「是不是全家都慢 / 全公司都慢」。期望结果：大家都慢 → 跳到运营商/路由器段；只有你慢 → 跳到设备段。

适用 / 不适用

适用

  • 看视频转圈、下载只有几百 KB/s、网页半天刷不出来。
  • 晚上 8-11 点明显更慢（高峰期拥塞的典型特征）。
  • 换了新宽带/新路由器后感觉不对劲。

不适用

  • 完全断网/上不了网：看「Wi-Fi 有信号但上不了网」和「家里所有设备都上不了网怎么办」。
  • 打开网页特别慢但下载满速：那是 DNS 解析慢，看「网页打不开但 QQ / 微信能用：DNS 问题怎么修」。
  • 电脑整体卡（开个窗口都卡）：是性能问题，看「电脑越来越卡怎么办：一张表定位是哪里卡」。

开始前确认

  • 知道签约带宽（账单/运营商 App 可查）。
  • 手头有网线（没有的话，把电脑搬到路由器旁边 1 米内测 Wi-Fi）。
  • 记得路由器后台地址和密码（贴在路由器底部）。
  • 测速时暂停下载、网盘同步、系统更新——它们会吃光带宽污染结果。

怎么确认修好了

  • 有线测速 ≥ 签约值的 80%，Wi-Fi 在常用位置 ≥ 签约值的 50%。
  • 视频平台播放 4K/高码率不再转圈。
  • ping 外网延迟稳定，无周期性飙高。

还是不行？

  • 运营商测过上门也没问题、路由器也换了 → 布线老化（老房子百兆网线）：换超五类/六类线或改用 Mesh/电力猫。
  • 大户型边缘房间慢 → 单路由覆盖不足，上 Mesh 组网比调天线管用。
  • 公司网络慢 → 可能是带宽策略限速，找 IT；个人别在公司网络做测速压测。

预防

  • 路由器每季度断电重启一次；固件保持更新。
  • 新设备优先连 5GHz；智能家居留在 2.4G，互不抢占。
  • 每半年对着账单测一次速，带宽缩水能第一时间发现。

分步骤

  1. 分段测速，锁定问题层

    1. 有线直连光猫（或路由器 LAN 口）→ speedtest.cn 测速，记下「下载/上传/延迟」。
    2. 同一位置 Wi-Fi 测速，记下数据。
    3. 手机流量测速，作为外部参照。

    判读：有线达标 + Wi-Fi 慢 → Wi-Fi 链路问题（步骤 2）；有线也不达标 → 路由器/运营商（步骤 3）；只有这台设备慢 → 设备问题（步骤 4）。 期望结果：三组数据在手，问题锁定在哪一层。失败了怎么办：没有网线 → 手机贴着路由器测 Wi-Fi，勉强可当「有线」参照。

  2. Wi-Fi 链路优化（最常见的慢）

    1. 切到 5GHz 频段；老设备不支持 5G 的，2.4G 换 1/6/11 信道（路由器后台 → 无线设置）。
    2. 路由器摆到房子中心、离地 1 米以上，离开微波炉、蓝牙音箱、金属柜。
    3. 怀疑蹭网挤带宽 → 看「怎么查谁在蹭网 / 给设备限速与拉黑」。

    期望结果：同位置 Wi-Fi 测速明显提升。失败了怎么办：5G 也慢且贴脸测也慢 → 回步骤 1 复测有线，进入路由器/运营商段。

  3. 路由器与运营商段

    1. 重启路由器和光猫（断电 30 秒再上电），等 2 分钟稳定后有线复测。
    2. 有线仍不达签约值 60% → 光猫拨号模式、线路质量、运营商侧问题，直接打运营商客服报「测速不达标」，报出测速截图和时段。
    3. 高峰期（20-23 点）慢、白天正常 → 多半是小区共享带宽拥塞，同样向运营商投诉才有效。

    期望结果：宽带侧问题被坐实并推给运营商，或重启后恢复。失败了怎么办：运营商上门前，把路由器换成别人家的正常路由器交叉验证，排除自家路由器老化。

  4. 设备段（只有这一台慢）

    1. Windows：任务管理器 → 性能 → Wi-Fi/以太网，看「发送/接收」和链路速度（Wi-Fi 链路低于 100Mbps 多是信号差或老网卡）。
    2. 网卡驱动重装：设备管理器 → 网络适配器 → 卸载设备 → 重启自动装回；无线网卡驱动去笔记本官网下最新版。
    3. 检查是否开了「省电模式」导致网卡降速：电源选项 → 高级设置 → 无线适配器 → 最高性能。
    4. macOS：按住 Option 点菜单栏 Wi-Fi 图标，看 Tx Rate（传输速率）与 RSSI（信号强度，-50 优秀 / -70 及格 / -80 以下很差）。

    期望结果：该设备测速恢复到与其他设备接近。失败了怎么办：驱动重装仍慢 → USB 网卡/换 Wi-Fi 6 网卡是最省事的硬件解法。

  5. DNS 与「感觉慢」的修正

    1. 网页打开慢但下载快 → 换 DNS（路由器或本机填 223.5.5.5 / 119.29.29.29），细节看 DNS 专题文章。
    2. 感觉「卡」但测速正常 → 是延迟/抖动问题，ping 网关看延迟是否 <3ms、ping 外网 <50ms；游戏卡顿优先查这个和 NAT 类型。
    3. 一切正常但仍不满意 → 对照签约带宽管理预期：300M 宽带下载峰值约 37MB/s，达不到 40MB/s 不是故障。

    期望结果：对「慢」的定义与实际瓶颈一致。失败了怎么办：延迟高丢包严重且有线也一样 → 回到运营商段报修。
