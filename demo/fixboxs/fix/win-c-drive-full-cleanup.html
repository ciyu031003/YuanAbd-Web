C 盘爆红快满了，怎么安全清理出空间

⚠️ 需谨慎：本文会删除缓存、临时文件、旧系统备份和还原点。动手前请确认重要文件已有备份，并把不清楚用途的文件先挪到别处而不是直接删。
⛔ 有数据风险：删除「以前的 Windows 安装」（Windows.old）后无法回退旧版本；删除卷影副本/还原点后无法再用系统还原；这两项操作前请务必确认数据已备份。

💡 一句话结论

C 盘满不要瞎删：先用「设置 → 系统 → 存储」看清是哪一类文件占的空间，再用系统自带的存储感知、磁盘清理（清理系统文件）逐级处理，最后才考虑压缩休眠文件、清理组件存储这类进阶操作。

⚡ 30 秒快速排查（先试这个）

  1. 看谁占了空间：「设置 → 系统 → 存储」，等它扫描完，看是「应用和功能」「临时文件」「文档」「其他」哪一类最大。
  2. 一键清临时文件：同一页面点「清理建议」或打开「存储感知」，先清临时文件和回收站，动辄能空出几个 GB。
  3. 带系统文件深清：按 Win+R 输入 cleanmgr → 选 C 盘 → 点「清理系统文件」→ 勾选「Windows 更新清理」「传递优化文件」等。这一步通常最有效。

小白一键修复

不想研究原因，就下载脚本，右键选择“以管理员身份运行”。脚本执行前仍会再次确认。

下载 安全清理临时文件（.bat）
  • 适合Windows 10/11，C 盘临时文件很多，想先安全腾出一部分空间。
  • 脚本会清理当前用户和 Windows 临时目录中未被占用的文件，并显示 C 盘剩余空间。
  • 运行前保存正在编辑的文档；正在使用的临时文件会自动跳过。
  • 注意脚本不会清空下载、桌面、文档、回收站、系统还原点或 Windows.old，也不会删除休眠文件。
运行方式：下载后先解压（如有），右键 BAT 文件 → 以管理员身份运行 → 阅读提示后选择 Y。浏览器若提示“不常见文件”，请先核对文件名与下方源码。若浏览器无法下载，点“复制全部脚本”，粘贴到记事本，保存类型选择“所有文件”，文件名以 .bat 结尾。

查看完整 BAT 源码
@echo off
chcp 65001 >nul
setlocal EnableExtensions
title 修盒子 - 安全清理临时文件

fltmc >nul 2>&1
if errorlevel 1 (
  echo 正在请求管理员权限...
  powershell -NoProfile -Command "Start-Process -FilePath '%~f0' -Verb RunAs"
  exit /b
)

echo ============================================================
echo 修盒子 - 安全清理临时文件
echo ============================================================
echo 将清理当前用户临时目录和 Windows 临时目录。
echo 不会清理下载、桌面、文档、图片、回收站或系统还原点。
echo 正在使用的文件会自动跳过。
echo.
choice /C YN /N /M "确认继续？[Y/N] "
if errorlevel 2 goto :cancelled

echo.
echo [1/3] 清理用户临时目录...
for /d %%D in ("%TEMP%\*") do rd /s /q "%%D" >nul 2>&1
del /F /Q /S "%TEMP%\*.*" >nul 2>&1

echo [2/3] 清理 Windows 临时目录...
for /d %%D in ("%SystemRoot%\Temp\*") do rd /s /q "%%D" >nul 2>&1
del /F /Q /S "%SystemRoot%\Temp\*.*" >nul 2>&1

echo [3/3] 输出 C 盘可用空间...
powershell -NoProfile -Command "$d=Get-PSDrive C; '{0:N2} GB 可用' -f ($d.Free/1GB)"

echo.
echo 完成。此脚本只清理临时文件，不会处理 Windows.old、休眠文件或系统还原点。
echo 若 C 盘仍满，请回到文章按“存储感知 / 磁盘清理”继续处理。
goto :end

:cancelled
echo.
echo 已取消，没有删除任何文件。

:end
echo.
pause
endlocal

适用 / 不适用

适用：

  • C 盘图标变红，提示空间不足
  • Windows 更新因空间不足失败
  • 想安全清理但怕删错系统文件
  • 想知道到底是什么吃掉了 C 盘

不适用（请转对应文章）：

  • 更新反复失败但不缺空间 → Windows 更新卡在 0% / 一直失败，怎么强制修好
  • 电脑整体变慢，不只是空间问题 → 电脑越来越卡怎么办：一张表定位是哪里卡
  • 想减少开机自启占用 → 开机太慢：关掉这些开机自启软件
  • C 盘是 128 GB 且常年告急 → 本文能缓解但不能根治，考虑换更大的 SSD

开始前确认

  • 重要文件已经备份到移动硬盘或网盘
  • 知道自己装的哪些软件比较重要，别误卸载
  • 确认近期没有刚升级过系统（升级后 10 天内删 Windows.old 就无法回退）
  • 有管理员权限（清理系统文件、关闭休眠都需要）
  • 企业设备 → 清理前先问 IT，部分管控软件依赖这些缓存

怎么确认修好了

「此电脑」里 C 盘可用空间回到总容量的 15% 以上（或至少 20 GB），红色容量条消失；系统能正常开关机，常用软件可以正常打开，Windows 更新能够顺利下载安装。

还是不行？

  • 清完几天又满 → 回步骤 1 复查，重点看日志、聊天软件缓存、OneDrive 同步目录和系统还原
  • 空间够但更新仍失败 → Windows 更新卡在 0% / 一直失败，怎么强制修好
  • C 盘本身容量太小（128 GB 及以下）→ 换更大的 SSD，或用做好的系统镜像迁移系统
  • 不敢再动手，怕删错 → 只做步骤 2、3 两种系统自带清理，其余交给专业人员
  • 公司电脑、C 盘由 IT 统一管理 → 联系公司 IT，不要自行清理系统文件

预防

  1. 新软件一律装到 D 盘，安装时手动改路径。
  2. 微信、QQ、钉钉等把「文件保存位置」改到 D 盘，并定期清理聊天缓存。
  3. 打开存储感知，让它每周自动清临时文件和回收站。
  4. 桌面和下载文件夹不要当仓库，重要大文件放到其他盘或网盘。
  5. 每月打开一次「设置 → 系统 → 存储」看一眼趋势，别等到爆红才处理。

分步骤

  1. 先看是什么占了空间

    目的：不看清占用就去删，既清不出多少，还容易误删重要文件。

    操作：

    1. 「设置 → 系统 → 存储」，等待扫描完成，逐项展开： - 「应用和功能」看哪些软件体积大 - 「临时文件」看缓存和更新残留 - 「文档/图片/视频/其他」看个人文件 - 「清理建议」会列出临时文件、大文件、云端已同步文件、不常用应用
    2. 想看得更细，用「目录树」类工具，二选一： - WinDirStat：开源软件（GPL），免费、无捆绑，扫描较慢但结果直观，推荐优先选它。 - WizTree：读取 NTFS 主文件表，扫描速度快得多，但它是闭源免费软件，且需要管理员权限读取磁盘，是否使用请自行取舍。 - 取舍原则：只用系统自带工具或知名开源/知名厂商工具；不要用「XX 管家 C 盘瘦身」「一键清理大师」这类来路不明的清理工具，它们可能误删文件、捆绑安装甚至改系统设置。
    3. 用资源管理器排查个人大文件：进入 C:\Users\你的用户名，右键各文件夹 →「属性」看大小，重点看「下载」「桌面」「文档」「视频」。
    预期结果：明确最大的空间占用属于哪一类：系统缓存、软件安装、个人文件，还是系统还原/休眠文件。
    失败怎么办？
    分类里显示「其他」很大 → 多半是恢复分区、休眠文件、页面文件或组件存储，继续做步骤 5、6、7。

  2. 用存储感知和清理建议清临时文件

    目的：这是微软官方推荐的首选方式，安全且不用懂技术。

    操作：

    1. 「设置 → 系统 → 存储 → 清理建议」，逐类查看并勾选要删的内容，点「清理」。
    2. 「设置 → 系统 → 存储 → 存储感知」，打开开关，并设置自动清理频率（如每周）和回收站、下载文件夹的保留天数。
    3. 手动补充：按 Win+R 输入 %temp% 回车，全选删除（提示占用中的文件跳过即可）。
    4. 清空回收站，确认里面没有被误删的文件。
    预期结果：通常能释放 2-20 GB，取决于之前的积累。
    失败怎么办？
    清理建议里显示的内容你不敢删 → 只勾「临时文件」「缩略图」这类明确安全的项；删除时提示「文件正在使用」→ 正常，跳过即可。

  3. 磁盘清理 + 清理系统文件（关键一步）

    目的：Windows 更新残留、「以前的 Windows 安装」、传递优化文件动辄十几 GB，只有「清理系统文件」模式才能看到。

    操作：

    1. 按 Win+R 输入 cleanmgr，选择 C 盘。
    2. 在「磁盘清理」窗口点左下角的「清理系统文件」，程序会重新扫描（这一步是关键，很多人漏掉）。
    3. 勾选下列项目： - Windows 更新清理 - 传递优化文件 - 以前的 Windows 安装（相当于 Windows.old） - 临时文件、缩略图、回收站、错误报告
    4. 点「确定」→「删除文件」，等待完成。
    ⛔
    ⛔ 有数据风险：勾选「以前的 Windows 安装」后，系统将无法回退到升级前的旧版本；如果升级还不满 10 天且你可能会后悔，请先不要勾这一项。
    预期结果：通常释放 5-30 GB；「以前的 Windows 安装」单独就可能占 10 GB 以上。
    失败怎么办？
    列表里没有「Windows 更新清理」→ 说明当前没有可清理的更新残留，属正常；清理过程中卡住 → 耐心等待，别强制关机。

  4. 卸载不用的软件，把大文件挪出 C 盘

    目的：软件安装位置和个人文件才是长期占用的大头，清缓存只能缓解一时。

    操作：

    1. 「设置 → 应用 → 已安装的应用」，按大小排序，卸载不再使用的软件（尤其是游戏、旧版办公软件、多个播放器）。
    2. 把「下载」「桌面」「视频」「图片」里的大文件剪切到 D 盘或移动硬盘。
    3. 云盘用户开启按需同步：OneDrive → 设置 →「文件按需」，把不常用文件夹设为「释放空间」（文件仍在云端，占位符留在本地）。
    4. 聊天软件缓存搬家：微信、QQ、钉钉的设置里都能改「文件保存位置」，改到 D 盘。
    5. 新软件安装时把路径改成 D:\Program Files，别再往 C 盘装。
    预期结果：C 盘释放数 GB 到数十 GB，且日后增长变慢。
    失败怎么办？
    没有 D 盘或 D 盘也快满 → 先加一块硬盘或用移动硬盘；不敢确认哪些文件能挪 → 只挪自己创建的文档、图片、视频。

  5. 关闭休眠，删掉 hiberfil.sys

    目的：休眠文件大小约等于内存容量，16 GB 内存的机器可能占十几 GB。

    操作：管理员命令提示符执行：

    powercfg /h off

    想恢复休眠和快速启动时执行：

    powercfg /h on
    预期结果：执行后 hiberfil.sys 消失，C 盘立刻多出接近内存容量大小的空间。
    失败怎么办？
    提示「拒绝访问」→ 确认是管理员命令提示符；关掉后你习惯用「休眠」而不是「睡眠」→ 执行 powercfg /h on 恢复。

  6. 调整页面文件与系统还原占用

    目的：页面文件和系统还原（卷影副本）会占用不小的空间，可以按需限流。

    操作：

    1. 页面文件默认由系统管理，一般不需要动；确实紧张时可在「系统属性 → 高级 → 性能 → 设置 → 高级 → 虚拟内存」里改到 D 盘（注意：物理内存较小或系统盘是唯一磁盘时不要关闭）。
    2. 查看还原点占用（管理员命令提示符）：
    vssadmin list shadowstorage
    1. 限制最大占用（示例：C 盘上限 10 GB）：
    vssadmin resize shadowstorage /for=C: /on=C: /maxsize=10GB
    ⛔
    ⛔ 有数据风险：下面的命令会删除所有还原点和卷影副本，删除后无法再用「系统还原」或「以前的版本」找回文件。执行前请确认已备份重要数据，且你确实不需要这些还原点。
    企业设备不要执行，相关信息可能由 IT 统一管理。
    vssadmin delete shadows /for=C: /all /quiet
    预期结果：还原点占用被限制或释放，C 盘多出数 GB。
    失败怎么办？
    提示「没有找到卷影副本」→ 说明系统保护未开启，可忽略；执行后想重新启用 → 「系统属性 → 系统保护 → 配置 → 启用系统保护」。

  7. 清理组件存储（WinSxS）

    目的：Windows 组件存储里堆积的旧版本组件可能占几 GB，只能由 DISM 清理，不能手动删。

    操作：管理员命令提示符执行，先分析再清理：

    DISM /Online /Cleanup-Image /AnalyzeComponentStore
DISM /Online /Cleanup-Image /StartComponentCleanup

    需要连旧更新备份一起清（影响回退能力，可选）：

    DISM /Online /Cleanup-Image /StartComponentCleanup /ResetBase
    预期结果：分析结果里「组件存储清理建议」为「是」时执行清理，通常释放 1-10 GB。
    失败怎么办？
    /ResetBase 之后无法再卸载已安装的更新，若你需要保留卸载更新的能力就不要加这个参数；DISM 报错 → 先按 Windows 更新卡在 0% / 一直失败，怎么强制修好 修组件存储。

  8. 这些地方千万别手动删

    目的：划出安全红线，避免清完空间把系统搞坏。

    操作：以下目录不要手动删除或移动：

    位置为什么不能删
    C:\Windows\WinSxS组件存储，只能通过 DISM 维护
    C:\Windows\System32系统核心文件，删了可能无法开机
    C:\Windows\Installer已安装软件的安装缓存，删了会导致无法修复/卸载
    C:\Windows\Fonts系统字体
    C:\ProgramData 下的未知文件夹可能是软件配置或授权信息
    C:\Recovery恢复分区相关文件
    C:\$Recycle.Bin、System Volume Information系统管理目录，由系统维护
    预期结果：清理过程不触碰这些目录。
    失败怎么办？
    已经误删导致软件报错 → 用「控制面板 → 程序和功能」修复该软件，或重装；系统无法启动 → 用恢复环境的「启动修复」。
