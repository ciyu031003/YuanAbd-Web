电脑开机密码忘了 / PIN 突然用不了

⛔
⚠️ 需谨慎：本文涉及账户与登录方式修改，改完请把新密码记到可靠的地方。
⛔ 有数据风险：如果这台电脑开启了 BitLocker 设备加密，任何离线重置密码、重装系统的操作都可能触发恢复密钥要求，密钥丢失将导致数据无法读取。动手前请先按步骤 5 确认加密状态并找回恢复密钥。

💡 一句话结论

先分清账户类型：微软账户直接去 account.live.com 在线重置密码，本地账户用安全问题或另一个管理员账户改密码。PIN 用不了通常不用慌，点「登录选项」换密码登录后就能重设 PIN。

⚡ 30 秒快速排查（先试这个）

  1. PIN 输不进去？改用密码登录。 登录界面点「登录选项」→ 选钥匙图标「密码」→ 输入账户密码。PIN 和密码是两套东西，PIN 坏了密码常常还能用。
  2. 账户名是邮箱或手机号 → 微软账户。 用手机打开 account.live.com/password/reset 在线重置，然后回电脑用新密码登录（需要联网）。
  3. 只有一个名字、没有邮箱 → 本地账户。 在登录界面故意输错一次，点「重置密码」看有没有安全问题；有第二个管理员账户的话，用它登录后执行 net user 用户名 新密码。

适用 / 不适用

适用：

  • 开机密码忘了、输错多次提示等待
  • PIN 突然提示「你的 PIN 不可用」「PIN 已失效」
  • 换主板/换硬盘/重装后登录方式失效
  • 想区分自己的账户是微软账户还是本地账户

不适用（请转对应文章）：

  • 密码正确但登录后黑屏只剩鼠标 → 电脑开机黑屏只有鼠标指针，怎么救回来
  • 开机画面要求输入 48 位 BitLocker 恢复密钥 → 直接看本文步骤 5
  • 卡在开机 Logo 根本到不了登录界面 → 电脑开机一直转圈 / 卡在品牌 Logo 进不去系统
  • 公司或学校发的电脑 → 联系公司 IT，本文大部分方法不适用；Mac 是另一套流程：「Mac 忘记开机密码怎么办」

开始前确认

  • 有一台能上网的手机或另一台电脑（重置微软账户密码必须用）
  • 回忆账户名是邮箱、手机号，还是单独的英文名
  • 确认这台电脑是否开启 BitLocker / 设备加密（见步骤 5）
  • 如果电脑里还有重要数据且没有备份，先别执行重装类操作
  • 企业或学校设备：先联系 IT，别自行重置

怎么确认修好了

能使用新密码或新 PIN 正常进入桌面，关机再开机两次都成功登录；「设置 → 账户 → 登录选项」里 PIN 状态正常，登录时不再弹出 BitLocker 恢复密钥提示。

还是不行？

  • 微软账户收不到验证码、恢复表单也没通过 → 等 24 小时后重试，或联系微软支持；重装前先按「换硬盘 / 重装系统前，怎么把数据备份全」备份
  • 公司/学校账户、域账户、Entra ID 账户 → 联系公司 IT，他们能直接重置
  • 提示需要 BitLocker 恢复密钥但找不到 → 联系 IT 或数据恢复机构，绝对不要格式化
  • 只想拿回硬盘里的文件、不打算修系统 → 把硬盘接到别的电脑上拷贝（未加密的情况下）
  • 确认是本机自用、没有重要数据 → 用安装 U 盘全新安装系统

预防

  1. 微软账户绑定手机号和备用邮箱，并开启双重验证。
  2. 本地账户设置 3 个安全问题，或提前制作一张密码重置盘。
  3. 开启 BitLocker 时按微软建议把恢复密钥打印出来或保存在只有你能访问的地方，不要只存在这台电脑上。
  4. 设置 PIN 的同时确保账户密码记在密码管理器或纸质记录里（PIN 忘了必须靠密码重设）。
  5. 重要文件同时存网盘或移动硬盘，别只放在系统盘。

分步骤

  1. 先确认是微软账户还是本地账户

    目的：两条路径完全不同，先分清能少走一半弯路。

    操作：

    1. 看登录界面：账户名位置显示邮箱或手机号（如 abc@outlook.com）→ 微软账户；只显示一个名字（如 Lenovo、Administrator）→ 可能是本地账户。
    2. 用手机或另一台电脑登录 account.microsoft.com，在「设备」里能否看到这台电脑。
    3. 如果还能进系统（比如用另一个账户或 PIN）：打开「设置 → 账户 → 你的信息」，如果是微软账户，会看到「改用本地账户登录」的选项；只有「改用 Microsoft 账户登录」则说明当前是本地账户。
    4. 也可以用开始菜单搜索 netplwiz 查看账户列表。
    预期结果：明确知道该走步骤 3（微软账户）还是步骤 4（本地账户）。
    失败怎么办？
    完全分不清 → 先按微软账户路径试一次（对本地账户无副作用），再去步骤 3、4。

  2. PIN 用不了但密码还记得

    目的：PIN 属于本地快捷登录方式，用账户密码验证后即可重设，不必改密码。

    操作：

    1. 在登录界面点「登录选项」，选择钥匙图标的「密码」，用账户密码登录。
    2. 进入系统后打开「设置 → 账户 → 登录选项」。
    3. 找到「PIN (Windows Hello)」，点「我忘记了 PIN」。
    4. 按提示验证账户密码，重新设置一个新 PIN。
    5. 如果提示需要联网验证，先接好网线或用手机热点共享网络。
    6. 如果「我忘记了 PIN」点了没反应，先删除 PIN 再重新添加。
    预期结果：能重新设置 PIN 并用它正常登录。
    失败怎么办？
    账户密码也不记得 → 走步骤 3 或 4；提示「你的组织要求使用 Windows Hello」→ 这是公司管控，联系 IT。

  3. 微软账户：在线重置密码

    目的：微软账户的密码存在微软服务器上，在电脑上怎么试都没用，必须在线改。

    操作：

    1. 用手机或另一台设备打开 https://account.live.com/password/reset。
    2. 输入账户的邮箱或手机号，完成验证码验证（发到备用邮箱或手机）。
    3. 设置新密码。
    4. 回到这台电脑，确保联网，用「新的账户密码」登录。
    5. 开了双重验证的，按提示用验证器 App 或备用邮箱继续验证。
    预期结果：用新密码成功进入桌面。
    失败怎么办？
    收不到验证码 → 在验证页选「使用其他验证方式」；完全不记得账户名 → 使用微软的账户恢复表单（account.live.com/acsr），如实填写信息，通常 24 小时内出结果；刚重置完登录时提示要输入 BitLocker 恢复密钥 → 立刻转到步骤 5。

  4. 本地账户：用安全问题或另一个管理员账户改密码

    目的：本地账户密码存在这台电脑上，只能用电脑上的可用凭据来重置。

    操作：

    1. 在登录界面故意输错一次，点「重置密码」，回答当初设置的安全问题；答对后就能设新密码。
    2. 如果电脑上还有另一个管理员账户：用它登录，以管理员身份打开命令提示符，先看有哪些账户：
    net user
    1. 再改目标账户的密码（把 用户名 和 新密码 换成实际内容）：
    net user 用户名 新密码
    1. 也可以走图形界面：控制面板 →「用户账户」→「管理其他账户」→ 选择该账户 →「更改密码」。
    预期结果：能用新密码登录目标账户。
    失败怎么办？
    提示「拒绝访问」→ 当前账户不是管理员，换一个管理员账户；没有第二个账户、也没有安全问题 → 只能走步骤 5、6、7，本地账户没有官方后门。
    ✅
    不要使用的方法：网上流传的替换 sethc.exe / utilman.exe、第三方「密码破解 U 盘」、PE 下的账户清除工具，都属于绕过登录保护，本文不提供。在单位设备上使用属于违规；在开了 BitLocker 的设备上极易触发恢复密钥要求，可能直接导致数据读不出来。

  5. 确认 BitLocker / 设备加密，并找回恢复密钥

    目的：这是整篇文章最关键的风险点。开了加密的电脑，如果没拿到密钥就重装或离线改密码，数据可能永远读不出来。

    ⛔
    ⛔ 有数据风险：找不到恢复密钥时，绝对不要格式化、不要重装系统、不要用第三方工具清账户。先把数据保住。

    操作：

    1. 判断是否开启加密： - 开机时曾提示「输入恢复密钥以解锁驱动器」→ 已开启 - 「设置 → 隐私和安全性 → 设备加密」（Windows 11）或「设置 → 更新和安全 → 设备加密」（Windows 10）显示为「已开启」 - 能进系统时，用管理员命令提示符执行 manage-bde -status C: 查看
    2. 按顺序查找恢复密钥： - 个人微软账户：https://account.microsoft.com/devices/recoverykey - 公司/学校账户（Entra ID / 域）：联系 IT，密钥通常由组织托管 - 当初打印出来的纸张、U 盘里的 .txt / .bek 文件、初始设置时的截图 - 能进系统时（管理员命令提示符）导出：
    manage-bde -protectors -get C:
    1. 屏幕提示要密钥时，把 48 位数字输入即可解锁。
    预期结果：找到密钥并成功解锁；或者确认这台电脑没有开启设备加密，可以安全进行后续操作。
    失败怎么办？
    确认开启加密但找不到任何密钥 → 停止一切操作，联系公司 IT（企业设备）或专业数据恢复机构。重装或格式化后，数据基本无法取回。

  6. 用密码重置盘（仅本地账户，且需事先做过）

    目的：密码重置盘是微软为本地账户提供的官方恢复手段，如果你以前做过就能一步解决。

    操作：

    1. 插入当初制作的那张密码重置盘（U 盘）。
    2. 在登录界面输错一次密码，点「重置密码」。
    3. 按向导选择该盘并设置新密码。
    预期结果：重设成功并正常登录。
    失败怎么办？
    没有重置盘，或提示「该磁盘不是密码重置盘」→ 密码重置盘只对当初创建它的那个账户有效，而且必须在忘记密码之前制作；没有就只能走步骤 7。

  7. 最后手段：备份数据后重装，或找 IT

    目的：所有正规途径都失效时，让电脑恢复可用，同时把数据损失降到最低。

    ⛔
    ⛔ 有数据风险：本步骤会导致无法登录原有账户，甚至清空系统盘，请先备份数据。

    操作：

    1. 优先保数据：关机断电，把硬盘拆下来接到另一台电脑上拷出文件。
    2. 注意：如果硬盘开了 BitLocker 且你没有恢复密钥，接到别的电脑上同样读不出来。
    3. 数据安全后，用微软官网的媒体创建工具做安装 U 盘，全新安装系统。
    4. 公司或学校设备、带企业加密的设备 → 直接联系 IT，他们有正规的账户恢复流程。
    预期结果：得到一台能正常登录使用的电脑。
    失败怎么办？
    数据读不出来又有重要资料 → 找专业数据恢复机构，在此之前不要再往这块硬盘写入任何数据。
