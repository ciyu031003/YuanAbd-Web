电脑越来越卡怎么办：一张表定位是哪里卡

💡 一句话结论

「卡」不是一种病，得先分清卡在哪：先看任务管理器里 CPU、内存、磁盘、网络哪一项长期接近 100%，再按症状对照表定位到具体环节，然后只修那一处，别一上来就重装。

⚡ 30 秒快速排查（先试这个）

  1. Ctrl+Shift+Esc 打开任务管理器，点「性能」看四条曲线：哪一项长期贴顶（多数是磁盘 100% 或内存 90%+），问题就在那一栏对应的步骤。
  2. 「启动」标签看影响：标着「高」的项目全列出来，能关的先关，做法见 开机太慢：关掉这些开机自启软件。
  3. 看 C 盘剩余空间：低于 10% 会明显拖慢系统，先去清理：C 盘爆红快满了，怎么安全清理出空间。

适用 / 不适用

适用：

  • 开机要好几分钟才进桌面
  • 打开任何程序都要转半天圈
  • 用一会儿就卡，重启后短暂恢复
  • 鼠标一顿一顿、声音断续、视频卡帧
  • 想知道到底该换硬盘还是加内存

不适用（请转对应文章）：

  • 开机开机慢但主要是自启动软件太多 → 开机太慢：关掉这些开机自启软件
  • C 盘快满导致整体变慢 → C 盘爆红快满了，怎么安全清理出空间
  • 卡着卡着蓝屏或自动重启 → 电脑蓝屏了怎么办：先学会读蓝屏代码
  • 上网慢但电脑本身流畅 → 属网络问题，不是本文范围
  • 只有一个软件卡、其他都正常 → 直接看本文步骤 2 的对应行

开始前确认

  • 接上电源再测（电池模式下 CPU 会被降频，结果不准）
  • 关掉不用的后台大程序，最好重启一次再开始
  • 记录现象：什么时候卡、卡多久、做什么操作时卡
  • 知道自己电脑的硬盘类型（机械硬盘还是固态硬盘）和内存容量，设置 → 系统 → 关于里能看内存
  • 有管理员权限最好（部分命令需要）

怎么确认修好了

重启后连续使用 1-2 小时，任务管理器中 CPU、内存、磁盘不再长期贴近 100%；开机进入桌面时间明显缩短；打开常用软件不再长时间转圈，并且「可靠性监视器」里最近三天没有新的应用崩溃记录。

还是不行？

  • 主要是开机慢，进桌面后还算正常 → 开机太慢：关掉这些开机自启软件
  • 主要是 C 盘满导致变慢 → C 盘爆红快满了，怎么安全清理出空间
  • 卡着卡着蓝屏、死机、自动重启 → 电脑蓝屏了怎么办：先学会读蓝屏代码
  • 只有某个软件卡、其他都正常 → 卸载重装该软件，或联系软件官方支持
  • 已经按本文排查完、硬件也换过还是卡 → 主板或 CPU 可能存在故障，送修检测

预防

  1. 系统盘尽量用 SSD，并保持 15%-20% 的剩余空间。
  2. 只装必要的常驻软件，开机自启越少越好。
  3. 浏览器标签页别开几十个，定期重启浏览器。
  4. 每 6-12 个月清一次灰，笔记本注意散热垫和出风口。
  5. 不要安装「系统加速」「深度优化」类工具，它们往往是卡顿的来源。

分步骤

  1. 用任务管理器做 20 秒定位

    目的：先确定瓶颈在哪一类资源，后面的排查才有的放矢。

    操作：

    1. 按 Ctrl+Shift+Esc 打开任务管理器。
    2. 点「性能」标签，盯住 30 秒，看 CPU、内存、磁盘、以太网/Wi-Fi 四条曲线。
    3. 回到「进程」标签，点列头按 CPU、内存、磁盘排序，看排在前三位的是谁。
    预期结果：明确一项长期接近 100% 的资源，例如「磁盘 100%」「内存 95%」。
    失败怎么办？
    四项都不高但依然卡 → 转到步骤 5，用资源监视器和可靠性监视器找间歇性问题。

  2. 按症状对照表定位

    目的：不同「卡」对应完全不同的原因，一张表就能少走弯路。

    操作：对照下表找到最接近你的一行。

    症状先看哪里常见原因
    开机到桌面要 2-5 分钟任务管理器「启动」标签、事件查看器 Diagnostics-Performance 日志启动项太多、机械硬盘、快速启动异常
    打开任何程序都慢磁盘占用、硬盘类型机械硬盘老化、磁盘 100%、C 盘接近写满
    用 10-30 分钟后开始卡内存占用内存不足、浏览器标签太多、内存泄漏
    鼠标卡顿、声音断续磁盘和 CPU 曲线磁盘坏道、驱动异常、电源模式被设为节能
    特定软件卡该进程的 CPU/内存软件本身、插件、显卡驱动不匹配
    上网、开网页慢网络占用、浏览器扩展下载任务占满带宽、扩展过多、DNS 慢
    一插电就快、用电池就卡电源模式电池模式降频，属正常现象
    预期结果：锁定 1-2 个最可疑的方向，进入对应步骤。
    失败怎么办？
    对不上号 → 直接做步骤 3、4、5，覆盖最常见的三类瓶颈。

  3. 处理磁盘瓶颈（最常见的元凶）

    目的：磁盘 100% 是 Windows 卡顿的头号原因，先排除硬件老化再谈软件。

    操作：

    1. 先看硬盘类型和健康状态（管理员 PowerShell）：
    Get-PhysicalDisk | Select-Object FriendlyName, MediaType, HealthStatus, OperationalStatus
Get-Disk | Select-Object Number, FriendlyName, HealthStatus
    1. MediaType 显示 HDD → 是机械硬盘，这是系统盘的话，卡是必然的，参考步骤 7。
    2. HealthStatus 不是 Healthy、或 OperationalStatus 不是 OK → 硬盘在衰退，先备份数据。
    3. 软件层面：暂停正在进行的 Windows 更新（设置 → Windows 更新 → 暂停更新 1 周）、暂停 OneDrive 同步、临时关闭杀软的实时扫描试一次。
    4. 「设置 → 系统 → 存储 → 存储感知」打开自动清理。
    5. 在任务管理器里看看是不是 System、MsMpEng.exe（Defender 扫描）、SearchIndexer.exe 占着磁盘：Defender 扫描时卡属于正常，等它跑完。
    预期结果：磁盘占用回落到正常水平；或者确认瓶颈就是机械硬盘老化。
    失败怎么办？
    HealthStatus 异常或伴随异响 → 立即备份数据并准备更换硬盘；磁盘占用忽高忽低查不出原因 → 做步骤 5。

  4. 处理内存与页面文件瓶颈

    目的：内存不足时系统会频繁读写硬盘上的页面文件，表现为「一直卡、硬盘灯常亮」。

    操作：

    1. 任务管理器「性能 → 内存」，看「已提交」是否接近上限，以及「使用中（压缩）」的比例。
    2. 找出吃内存最多的进程（管理员 PowerShell）：
    Get-Process | Sort-Object WS -Descending | Select-Object -First 10 Name, WS, CPU
    1. 常见大户：浏览器（几十个标签页）、微信/QQ、虚拟机、设计软件。
    2. 内存 4 GB 且经常超过 90% → 加内存是最有效的手段；8 GB 只够轻办公，16 GB 适合大多数场景。
    3. 不要迷信「内存整理」「释放内存」类工具，它们只会让系统更忙。
    预期结果：内存占用降到 80% 以下，卡顿明显缓解。
    失败怎么办？
    内存占比不高但依然卡 → 回步骤 3 看磁盘；怀疑内存条故障 → 按 Win+R 输入 mdsched.exe 做内存诊断。

  5. 用系统自带工具收集证据

    目的：间歇性卡顿需要记录一段时间的表现才能定位。

    操作：

    1. 资源监视器：按 Win+R 输入 resmon，看「概览」里的 CPU、磁盘、网络、内存四张图，以及「磁盘」标签里各文件的读写量。
    2. 可靠性监视器：按 Win+R 输入 perfmon /rel，查看最近几天的「警告」「错误」以及每次系统崩溃、应用失败的时间点。
    3. 开机耗时：事件查看器 →「应用程序和服务日志 → Microsoft → Windows → Diagnostics-Performance → Operational」，看事件 ID 100（启动性能）的耗时明细。
    4. 系统文件体检（管理员命令提示符）：
    DISM /Online /Cleanup-Image /ScanHealth
sfc /verifyonly
    预期结果：拿到具体的时间点、进程名或文件路径，能把「卡」对应到一个明确对象。
    失败怎么办？
    看不懂日志 → 记下时间点和进程名即可，再回到步骤 2 对照；sfc /verifyonly 报告有损坏 → 用 Windows 更新卡在 0% / 一直失败，怎么强制修好 里的 DISM /RestoreHealth + sfc /scannow 修复。

  6. 做一轮系统维护

    目的：把可控的软件因素一次性处理干净，观察是否改善。

    操作：

    1. 关闭多余启动项：见 开机太慢：关掉这些开机自启软件。
    2. 清理磁盘空间：见 C 盘爆红快满了，怎么安全清理出空间。
    3. 更新系统与驱动：设置 → Windows 更新；显卡驱动到厂商官网或 Windows 更新安装。
    4. 全盘杀毒：Windows 安全中心 →「病毒和威胁防护」→ 扫描选项 → 完全扫描。
    5. 调整电源模式：「设置 → 系统 → 电源和电池 → 电源模式」选「最佳性能」（笔记本注意发热和续航）。
    6. 检查散热：出风口烫手、风扇长时间狂转说明积灰或硅脂老化，会导致 CPU 降频变卡。
    预期结果：重启后开机和日常操作明显变快。
    失败怎么办？
    维护后毫无变化 → 大概率是硬件瓶颈，做步骤 7。

  7. 判断该换硬件还是送修

    目的：软件层面已经查完，剩下的问题要靠硬件解决，避免白花钱。

    操作：对照下表决定下一步。

    情况建议说明
    系统盘还是机械硬盘（HDD）换 SSD提升最明显，换完开机通常从几分钟降到十几秒
    内存 4 GB / 8 GB 常年吃满加内存优先加到 16 GB，注意型号与插槽
    硬盘 HealthStatus 异常或有异响立即备份并更换随时可能彻底损坏
    清灰后仍高温降频清灰、换硅脂或送修笔记本建议找专业人员
    换 SSD、加内存后依旧卡送修检测主板/CPU别再继续买配件试
    预期结果：明确是「花小钱升级」还是「该送修」。
    失败怎么办？
    不确定能不能自己加内存/换硬盘 → 查整机型号的官方维护手册，或直接找售后。
