开机太慢：关掉这些开机自启软件

Windows 10Windows 11入门10-30 分钟✅ 安全

💡 一句话结论

开机慢八成是自启动程序太多：聊天工具、网盘、游戏平台、厂商更新器都会抢开机时间。打开任务管理器的「启动」标签，把标「高」影响的非必要项全部禁用，通常能快一半。

⚡ 30 秒快速排查（先试这个）

  1. Ctrl+Shift+Esc → 「启动」标签，看「启动影响」一列，把标「高」且你不需要开机就运行的项，右键 →「禁用」。
  2. 设置 → 应用 → 启动，这是同一个列表的另一种入口，把不需要的开关全部关掉。
  3. 看右下角托盘：开机后一堆常驻图标（网盘、下载器、厂商助手），它们基本都是从启动项来的，关掉即可。

✅
本文只调整启动项，不删除软件、不动系统文件，操作都可随时恢复，风险很低。

适用 / 不适用

适用：

  • 开机要 2 分钟以上才进桌面，进桌面后还要卡一阵
  • 任务管理器「启动」标签里一堆「高」影响项
  • 右下角托盘区常年挤满图标
  • 想弄清某个程序为什么会自己启动

不适用（请转对应文章）：

  • 关完启动项还是卡，想全面定位瓶颈 → 电脑越来越卡怎么办：一张表定位是哪里卡
  • 开机卡在品牌 Logo 根本进不去桌面 → 电脑开机一直转圈 / 卡在品牌 Logo 进不去系统
  • C 盘快满导致整体变慢 → C 盘爆红快满了，怎么安全清理出空间
  • 开机后浏览器主页被改、频繁弹广告 → 电脑老是弹广告、浏览器主页被劫持改不回来

开始前确认

  • 记住你平时开机后一定会打开的软件（微信、钉钉、输入法……）
  • 有管理员账户（改全局启动项需要）
  • 插上电源，避免操作中断电
  • 不要一次性全关，按「先关第三方、后看效果」的顺序来

怎么确认修好了

重启后任务管理器「上次 BIOS 时间」和进桌面总耗时明显缩短（通常能减少 30 秒到 2 分钟）；托盘区只剩你认识的图标；连续开关机 2 次都稳定，且被保留的软件功能（声音、触摸板、网络）全部正常。

还是不行？

  • 启动项已经很少，开机还是慢 → 瓶颈可能在硬盘或内存，看 电脑越来越卡怎么办：一张表定位是哪里卡
  • 关完启动项后某个软件一直弹报错 → 重新启用该项，或卸载重装该软件
  • 每次开机都多出新的自启项 → 可能有广告软件，看 电脑老是弹广告、浏览器主页被劫持改不回来
  • C 盘空间不足拖慢开机 → C 盘爆红快满了，怎么安全清理出空间
  • 公司统一配置的电脑，自启项被策略锁定改不了 → 联系公司 IT

预防

  1. 装软件时注意取消勾选「开机自动启动」「随系统启动」这类默认选项。
  2. 每 3 个月检查一次「设置 → 应用 → 启动」，及时清理新装的常驻程序。
  3. 同类工具只留一个（云盘、下载器、播放器各一个就够）。
  4. 不安装来源不明的「加速」「优化」「清理」类软件。
  5. 系统盘用 SSD，这是开机速度提升最明显的一步。

分步骤

  1. 先量出开机到底慢在哪

    目的：有了数字，关完启动项才知道有没有变快。

    操作：

    1. 任务管理器（Ctrl+Shift+Esc）→「启动」标签，右上角会显示「上次 BIOS 时间」，这是固件加系统的开机用时。
    2. 看「启动影响」列：高、中、低、无、未测量。判定标准（微软官方说明）：CPU 超过 1 秒或磁盘读写超过 3 MB 记为高影响。
    3. 更细的记录：事件查看器 →「应用程序和服务日志 → Microsoft → Windows → Diagnostics-Performance → Operational」，找事件 ID 100（整机启动耗时），101-103 会指出具体拖慢启动的应用、驱动或服务。
    预期结果：知道开机总耗时，以及哪几个程序影响最大。
    失败怎么办？
    看不到「上次 BIOS 时间」→ 系统版本较老，可以忽略，直接看影响等级；事件日志为空 → 直接用任务管理器列表判断。

  2. 在任务管理器或设置里禁用启动项

    目的：这是最安全也最有效的第一步，禁用只是不自动启动，软件本身还在。

    操作：

    1. 任务管理器 →「启动」标签，右键要处理的项 →「禁用」。
    2. 或「设置 → 应用 → 启动」，把对应开关关掉。
    3. 建议顺序：先关游戏平台、下载工具、播放器、云盘、厂商更新助手，再关聊天软件。
    4. 处理完重启一次，用步骤 1 的方法对比开机时间。
    预期结果：重启后开机明显变快，托盘图标减少。
    失败怎么办？
    列表里找不到某个顽固程序 → 做步骤 3、4；关掉后某个软件不好用了 → 重新「启用」即可，无副作用。

  3. 处理列表里没有的启动项

    目的：不少程序不走标准注册，而是靠启动文件夹、注册表 Run 键或计划任务自启。

    操作：

    1. 启动文件夹：按 Win+R，输入 shell:startup，删掉或移走不需要的快捷方式。
    2. 全体用户的启动文件夹：Win+R 输入 shell:common startup（需要管理员权限）。
    3. 注册表 Run 键（regedit，改前先导出备份）：检查以下三处，右侧每一项都是一个自启程序： - HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run - HKEY_LOCAL_MACHINE\Software\Microsoft\Windows\CurrentVersion\Run - HKEY_LOCAL_MACHINE\Software\WOW6432Node\Microsoft\Windows\CurrentVersion\Run
    4. 计划任务：Win+R 输入 taskschd.msc，在「任务计划程序库」里找触发器为「登录时」「启动时」的任务。
    5. 也可以一次列出所有自启项（管理员 PowerShell）：
    Get-CimInstance Win32_StartupCommand | Select-Object Name, Command, Location, User
    预期结果：找到并清掉任务管理器列表里看不到的自启项。
    失败怎么办？
    不确定某一项能不能删 → 先用下面的 Autoruns 查来源，或先禁用观察一周；注册表不认识就别乱删，导出备份后再动。

  4. 用微软官方 Autoruns 做全面体检

    目的：Autoruns 是微软 Sysinternals 官方工具，能把所有自启位置一网打尽。

    操作：

    1. 从微软官方页面下载 Autoruns 并解压（无需安装）。
    2. 右键 Autoruns64.exe →「以管理员身份运行」。
    3. 先看 Logon 和 Scheduled Tasks 两个标签。
    4. 勾选 Options → Hide Microsoft entries，可以把微软自带项隐藏，只留第三方。
    5. 右键可疑项 →「Delete」删除，或取消勾选临时禁用（更稳妥）。
    预期结果：看到完整的自启清单，包括任务管理器里完全不显示的项。
    失败怎么办？
    不确定某项是否关键 → 先取消勾选（禁用）而不是删除，观察几天没问题再删；公司电脑装有管控软件 → 不要动，先问 IT。

  5. 哪些绝对不能关

    目的：避免为了开机快几秒把功能关掉，导致设备异常。

    操作：对照下表决定。

    启动项类型建议说明
    输入法、触摸板、指纹、声卡、网卡驱动配套保留关掉可能导致手势、声音、网络异常
    Windows 安全中心 / Microsoft Defender保留关掉会失去实时防护
    企业管控、加密、VPN 客户端保留公司设备动了可能违规
    显卡控制面板（如 NVIDIA App）可关不影响驱动，需要时手动打开
    云盘同步（OneDrive、百度网盘等）按需关了不自动同步，需要时手动开
    聊天软件（微信、QQ、钉钉）可关关掉就要手动启动，消息不会自动同步
    游戏平台（Steam、Epic 等）可关需要时再开
    厂商更新助手（如各类电脑管家）可关定期手动检查驱动即可
    下载器、播放器、虚拟光驱可关典型的纯占资源项
    来路不明、名字乱码的项先禁用再查可能是广告软件，见弹窗劫持那篇
    预期结果：既提速又不影响硬件功能。
    失败怎么办？
    关错导致设备异常 → 回到同一位置重新「启用」，或重启进安全模式恢复。

  6. 顺手检查快速启动与系统配置

    目的：快速启动有时反而导致开机慢或卡住，另外可以确认启动环境干净。

    操作：

    1. 打开 msconfig →「常规」选「有选择的启动」，确认「加载启动项」没有被误勾选异常。
    2. 快速启动取舍：控制面板 →「电源选项」→「选择电源按钮的功能」→「更改当前不可用的设置」，这里有「启用快速启动」。 - 老机器或遇到开机变慢、关机后风扇不停，可以取消勾选试试。 - 想恢复休眠功能就别关它（关闭快速启动不影响正常开关机）。
    3. 「引导」标签里不要随意改，除非你明确知道自己在做什么。
    预期结果：确认启动方式正常，问题不再复发。
    失败怎么办？
    改完出现异常 → 改回来即可；误改「引导」导致进不去系统 → 用恢复环境里的「启动修复」。

  7. 不要用第三方「一键加速」

    目的：避免为了提速引入更麻烦的问题。

    操作：

    1. 卸载「开机加速」「内存优化」「系统瘦身」类工具，它们常自带常驻进程和广告。
    2. 卸载后把它们的启动项一并清掉（用步骤 4 的 Autoruns 复查）。
    3. 只用系统自带的设置、任务管理器、Autoruns 这三样处理启动项。
    预期结果：启动项清单只剩你自己认识的程序。
    失败怎么办？
    卸载后出现异常 → 用系统还原回到卸载前的时间点。
