电脑开机一直转圈 / 卡在品牌 Logo 进不去系统

⚠️ 需谨慎：本文会修改启动设置、检查磁盘并可能重置系统，请按步骤顺序做，不要跳步。
⛔ 有数据风险：步骤 4（chkdsk 磁盘检查）和步骤 8（重置此电脑）可能影响数据。动手前先把重要文件备份到 U 盘或网盘；如果系统已经完全进不去，优先考虑拆下硬盘接到别的电脑上拷数据。

💡 一句话结论

卡 Logo 或无限转圈，绝大多数是启动阶段的软件问题：更新没装完、系统文件或启动配置损坏、外接设备与快速启动捣乱。先等够 30 分钟、拔掉外设，再进「自动修复」做启动修复和卸载更新。

⚡ 30 秒快速排查（先试这个）

  1. 先等，别断电。 正在安装更新的机器会在这个界面停 10-30 分钟，硬盘灯或风扇有动静就继续等。期间可以拔掉网线，缩短卡在联网检查的时间。
  2. 断网 + 拔掉所有 USB 设备（U 盘、移动硬盘、打印机、扩展坞、读卡器），再开机。外接设备导致的卡 Logo 非常常见。
  3. 看到开机画面立刻长按电源键 10 秒关机，连续 3 次，第 4 次正常开机，系统会自动进入「自动修复」→「高级选项」。

适用 / 不适用

适用：

  • 开机停在品牌 Logo 或 Windows 徽标，一直转圈，十几分钟没动静
  • 转圈后自动重启，反复循环
  • 卡在「正在准备 Windows」「正在配置更新」不动
  • 进系统前反复进入「正在准备自动修复」

不适用（请转对应文章）：

  • 变成蓝底 + 哭脸 + 错误代码 → 电脑蓝屏了怎么办：先学会读蓝屏代码
  • 转圈之后黑屏只剩鼠标指针 → 电脑开机黑屏只有鼠标指针，怎么救回来
  • 反复卡在「正在配置更新 30%」这类更新步骤 → Windows 更新卡在 0% / 一直失败，怎么强制修好
  • 完全黑屏无信号、风扇也不转 → 属供电或硬件问题，见「还是不行？」
  • 屏幕要求输入 BitLocker 恢复密钥 → 先去找密钥，别继续操作

开始前确认

  • 手边有手机或另一台电脑可以查资料
  • 记得本机登录密码（进恢复环境的部分操作要验证）
  • 回忆故障前做过什么：装更新、换内存硬盘、改 BIOS、装新驱动
  • 重要数据已有备份；没有的话，先按步骤 8 的说明处理，不要急着重置
  • 笔记本插上电源，保证电量充足
  • 大致知道这台机器是 UEFI + GPT 还是 Legacy + MBR（固件设置里能看到，不确定就先记下来）

怎么确认修好了

正常关机再开机，能在 1-3 分钟内稳定进入桌面；连续开关机 3 次都不再卡在 Logo；并且「事件查看器 → Windows 日志 → 系统」里没有新的 41 号（Kernel-Power）意外关机记录。

还是不行？

  • 转圈之后变成蓝屏并给出错误代码 → 电脑蓝屏了怎么办：先学会读蓝屏代码
  • 转圈之后黑屏只剩鼠标指针 → 电脑开机黑屏只有鼠标指针，怎么救回来
  • 反复卡在「正在配置更新」并重启 → Windows 更新卡在 0% / 一直失败，怎么强制修好
  • 进系统后频繁蓝屏、文件无故损坏、硬盘有异响 → 硬件故障，先备份数据再送修
  • 公司电脑、开了 BitLocker 或提示输入恢复密钥 → 联系公司 IT，不要自行重置
  • 已经折腾 2 小时以上且有重要数据 → 直接找专业维修或数据恢复，动手越少越有救

预防

  1. 装更新前接好电源、腾出至少 20 GB 空间，更新过程中不要强制关机。
  2. 每季度创建一次系统还原点，重要文件定期备份到移动硬盘和网盘。
  3. 不要在开机状态下拔插硬盘、内存，装硬件前先断电。
  4. 不用的外设（扩展坞、读卡器、老打印机）用完就拔，别留在开机前。
  5. 还用机械硬盘当系统盘的机器，尽早换 SSD，这类启动故障会明显减少。

分步骤

  1. 先排除「其实正在正常工作」

    目的：避免在系统正常安装更新时断电，把可修的问题变成进不去系统。

    操作：

    1. 观察机箱或笔记本的硬盘指示灯是否闪烁，听风扇转速是否有变化。
    2. 保持通电，等待 15-30 分钟。
    3. 拔掉网线或关闭路由的 Wi-Fi（避免反复重试联网检查）。
    预期结果：一段时间后自动进入桌面，或进度条继续前进。
    失败怎么办？
    超过 30 分钟毫无变化 → 做步骤 2。

  2. 拔掉外设并进入 Windows 恢复环境

    目的：恢复环境（WinRE）是后面所有修复的入口，先把入口打开。

    操作：

    1. 长按电源键 10 秒关机，拔掉除键盘鼠标外的所有外接设备。
    2. 开机，看到品牌 Logo 就长按电源键关机，重复 3 次，第 4 次正常开机。
    3. 屏幕会显示「正在准备自动修复」，随后进入蓝色恢复界面。
    4. 选择「高级选项」。
    预期结果：看到「疑难解答 / 高级选项」菜单。
    失败怎么办？
    三次强制关机也进不去 → 用另一台电脑到微软官网「下载 Windows 11」页面下载媒体创建工具，制作安装 U 盘，从 U 盘启动后选「修复计算机」。

  3. 启动修复 + 卸载最近的更新

    目的：启动记录损坏和最近更新装坏，是卡 Logo 的两大主因，这两项操作基本无损。

    操作：

    1. 「高级选项」→「疑难解答」→「启动修复」，等它跑完并自动重启。
    2. 仍不行，回到「高级选项」→「卸载更新」→ 先卸载「最新质量更新」。
    3. 还不行，再卸载「最新功能更新」。
    预期结果：重启后能进入桌面，或至少能进入登录界面。
    失败怎么办？
    两项都无法卸载或报错 → 继续步骤 4。

  4. 检查磁盘错误（chkdsk）

    目的：硬盘存在坏道或文件系统损坏时，系统会卡在启动阶段。

    ⛔
    ⛔ 有数据风险：如果硬盘已经有物理故障征兆（异响、掉盘），chkdsk 可能让数据更难恢复，请先备份。

    操作：

    1. 「高级选项」→「命令提示符」。
    2. 先确认系统盘盘符。执行下面的命令，看 osdevice 指向哪个盘（恢复环境里系统盘不一定是 C:）：
    bcdedit
    1. 假设系统盘是 C:，执行：
    chkdsk C: /f
    1. 需要连坏道一起扫描时加 /r（很慢，可能几小时）：
    chkdsk C: /f /r
    预期结果：报告「Windows 已扫描文件系统并且没有发现问题」，或提示已修复若干错误。
    失败怎么办？
    提示「无法锁定驱动器」→ 输入 Y 同意下次启动时检查；提示「坏扇区」「设备未就绪」或反复出现同一批错误 → 大概率硬盘要坏了，停止反复修复，先想办法备份数据。

  5. 修复系统文件与组件存储

    目的：系统文件损坏导致启动失败时，DISM 负责修组件存储，sfc 负责修系统文件。

    操作：

    1. 在恢复环境的命令提示符里执行（假设 Windows 装在 D:\Windows，请按步骤 4 查到的实际盘符替换）：
    DISM /Image:D:\ /Cleanup-Image /RestoreHealth
sfc /scannow /offbootdir=D:\ /offwindir=D:\Windows
    1. 如果系统还能进桌面，直接用在线方式，管理员命令提示符中执行：
    DISM /Online /Cleanup-Image /RestoreHealth
sfc /scannow
    预期结果：DISM 报告「操作成功完成」；sfc 报告「未找到完整性冲突」或「已成功修复」。
    失败怎么办？
    DISM 报 0x800f081f → 缺修复源，需要用安装镜像做 /Source；离线修复时盘符写错会直接报错，先用 bcdedit 核对。

  6. 检查 BIOS / UEFI 与启动顺序

    目的：换过主板、加过硬盘、清过 CMOS 之后，启动模式与原系统不匹配也会卡住或找不到系统。

    操作：开机按 Del、F2 或 F10 进入固件设置，逐项检查：

    • 启动模式：UEFI 还是 Legacy/CSM，必须和系统安装时一致
    • 启动顺序：装系统的硬盘排在第一
    • Secure Boot：改动过就注意，装某些系统或 Linux 双系统时会用到
    • 是否误开了网络启动（PXE），把它调到硬盘之后

    改完按 F10 保存退出。

    预期结果：保存后能正常进入系统。
    失败怎么办？
    不确定该选哪种模式 → 现在的默认组合一般是 UEFI + GPT；改错会提示「找不到引导设备」，把刚才改的项改回去即可。

  7. 安全模式 + 干净启动 + 关闭快速启动

    目的：判断是不是第三方驱动、软件或快速启动导致的卡顿，并把元凶揪出来。

    操作：

    1. 进安全模式：「高级选项」→「启动设置」→「重启」→ 按 4。
    2. 如果能进安全模式：回到正常模式，按 Win+R 输入 msconfig →「服务」标签 → 勾选「隐藏所有 Microsoft 服务」→ 全部禁用 → 重启。
    3. 正常后再逐批启用服务，找出导致卡顿的那一个。
    4. 能进桌面后关闭快速启动：控制面板 →「电源选项」→「选择电源按钮的功能」→「更改当前不可用的设置」→ 取消勾选「启用快速启动」→ 保存。
    预期结果：安全模式能正常进入；关闭快速启动或禁用可疑服务后，开机不再卡在 Logo。
    失败怎么办？
    安全模式同样卡住 → 继续步骤 8。

  8. 备份数据，然后重置系统

    目的：前面都无效时，重置是最后的软件手段，但必须先保数据。

    ⛔
    ⛔ 有数据风险：重置时选择「删除所有内容」会清空系统盘，务必先备份。

    操作：

    1. 最稳的做法：关机断电，把硬盘拆下来接到另一台电脑上，拷出重要文件。
    2. 也可以用 U 盘启动到 PE 环境，把文件拷到移动硬盘。
    3. 数据安全后：用安装 U 盘启动 →「修复计算机」→「疑难解答」→「重置此电脑」→ 选择「保留我的文件」。
    预期结果：重置完成后能正常进入桌面。
    失败怎么办？
    重置过程中报错或反复失败 → 硬盘或主板可能存在硬件问题，联系维修点，不要再继续折腾。
