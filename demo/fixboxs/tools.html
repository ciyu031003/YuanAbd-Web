命令速查

这里只放只读或可安全回滚的命令。每一条都可以直接复制到「命令提示符 / PowerShell」（Windows）或「终端」（macOS）里执行。不确定的命令不要凭空尝试。

✅
安全：本页命令均为查询类操作，不会修改系统设置、不会删除数据。

网络四步定位法

按顺序执行，哪一步失败，问题就在那一层——这是最省时间的排查顺序。

步骤目的Windows 命令macOS 命令
1本机 IP 是否正常ipconfigifconfig
2能否连到路由器ping 192.168.1.1ping 192.168.1.1
3能否连到外网（绕过 DNS）ping 223.5.5.5ping 223.5.5.5
4DNS 解析是否正常nslookup www.baidu.comdig www.baidu.com

判读：第 2 步不通 → 查本机网卡与网段；第 3 步不通 → 查路由器/宽带；第 4 步不通但第 3 步通 → DNS 问题。

Windows 常用命令

查看完整网络配置（找 IP、网关、DNS）

ipconfig /all

刷新 DNS 缓存

ipconfig /flushdns

释放并重新获取 IP（DHCP）

ipconfig /release
ipconfig /renew

查看路由表默认网关

route print

查看本机 ARP 表（排查 IP 冲突/蹭网）

arp -a

测试连通性与 DNS 解析

ping 223.5.5.5
nslookup www.baidu.com

查看当前系统代理设置

reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings"

检查系统文件完整性（需管理员）

sfc /scannow

检查并修复系统映像（需管理员）

DISM /Online /Cleanup-Image /RestoreHealth

macOS 常用命令

查看网络接口与 IP

ifconfig

查看 Wi-Fi 详情（信道、速率、信号）

system_profiler SPAirPortDataType

查看当前 DNS 配置

scutil --dns

查看默认路由（网关）

netstat -rn | grep default

刷新 DNS 缓存

sudo dscacheutil -flushcache
sudo killall -HUP mDNSResponder

查看系统代理设置

scutil --proxy

查看磁盘空间与挂载情况

df -h

查看电池健康与循环次数

system_profiler SPPowerDataType
⚠
需谨慎：带 sudo 或需要管理员权限的命令会修改系统状态。执行前请确认你理解它的作用，并参考对应教程。
